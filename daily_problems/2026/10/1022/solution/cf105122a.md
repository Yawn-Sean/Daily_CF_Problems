**提示 1：** 标记再选 / 分类。

方法一：满足条件的 $(x,y)$ 对总共有 $\binom{k+1}{2}$ 个，我们从 $1\sim\binom{k+1}{2}$ 中选一个数，再输出字典序第 $i$ 大的二元组即可。

方法二：两位相等的概率是 $\frac{k}{\binom{k+1}{2}}$ ，因此在随机在这个范围内只需输出某个 $x\ x$ 即可。否则只需保证任何一组不同的元素以相同的概率输出即可，为此可以不断进行拒绝采样，即 $x\geq y$ 时就重新生成。这样显然就满足要求了。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    k = II()
    n = II()
    
    outs = []
    
    for _ in range(n):
        if random.randint(1, k * (k + 1) // 2) <= k:
            x = random.randint(1, k)
            outs.append(f'{x} {x}')
        else:
            while True:
                x = random.randint(1, k)
                y = random.randint(1, k)
                if x != y: break
            if x > y: x, y = y, x
            outs.append(f'{x} {y}')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	mt19937 rng(random_device{}());

	int k, n;
	cin >> k >> n;

	uniform_int_distribution<long long> gen1(1, 1ll * k * (k + 1) / 2);
	uniform_int_distribution<int> gen(1, k);

	while (n --) {
		if (gen1(rng) <= k) {
			int x = gen(rng);
			cout << x << ' ' << x << '\n';
		}
		else {
			while (true) {
				int x = gen(rng);
				int y = gen(rng);
				if (x < y) {
					cout << x << ' ' << y << '\n';
					break;
				}
			}
		}
	}

	return 0;
}
```
