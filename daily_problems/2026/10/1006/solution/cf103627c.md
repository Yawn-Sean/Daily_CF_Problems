**提示 1：** 考虑任意一组解，其实可以构造出更简单的形式。

我们将下标视为 $0\sim n-1$ 的集合的子集，则与和或分别表示交集和并集。

设交集为 $A$ ， $i,j$ 非交集的元素形成的集合分别设为 $B,C$ 。则我们要求：

$f(A+B)+f(A+C)\lt f(A)+f(A+B+C)$

这里用加号表示并集。

移项后，有：

$f(A+B)-f(A)\lt f(A+B+C)-f(A+C)$ 

我们设函数 $g(x)=f(B+x)-f(x)$ 。则 $g(A)\lt g(A+C)$ ，

设 $C=\{c_1,c_2,\dots\}$ ，因为我们考虑序列 $g(A),g(A+\{c_1\}),g(A+\{c_1,c_2\}),\ldots,g(A+C)$ ，开头一项小于最后一项，所以我们可以保证其中存在相邻两项满足递增关系，设为 $g(A+\{c_1,c_2,\ldots,c_i\}),g(A+\{c_1,c_2,\ldots,c_{i+1}\})$ ，则将 $A$ 重新定义为 $A+\{c_1,c_2,\ldots,c_i\}$ ， $C$ 重新定义为 $\{c_{i+1}\}$ ，上述不等式仍然成立。

类似地，你可以把 $B$ 也变成一元集。

因此，你只需枚举 $A$ 和一元集 $B,C$ 即可。总枚举量足够小。

时间复杂度为 $\mathcal{O}(n^2 2^n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    
    for i in range(1 << n):
        bit1 = [1 << j for j in range(n) if i >> j & 1]
        bit2 = [1 << j for j in range(n) if not i >> j & 1]
        
        for b1 in bit1:
            for b2 in bit2:
                if nums[i - b1] + nums[i + b2] > nums[i] + nums[i - b1 + b2]:
                    print(i, i - b1 + b2)
                    exit()
    
    print(-1)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	vector<int> nums(1 << n);
	for (auto &x: nums) cin >> x;

	for (int i = 0; i < 1 << n; i ++) {
		vector<int> v1, v2;
		for (int j = 0; j < n; j ++) {
			if (i >> j & 1) v1.emplace_back(1 << j);
			else v2.emplace_back(1 << j);
		}

		for (auto &x1: v1) {
			for (auto &x2: v2) {
				if (nums[i - x1] + nums[i + x2] > nums[i] + nums[i - x1 + x2]) {
					cout << i << ' ' << i - x1 + x2 << '\n';
					return 0;
				}
			}
		}
	}

	cout << -1;

	return 0;
}
```
