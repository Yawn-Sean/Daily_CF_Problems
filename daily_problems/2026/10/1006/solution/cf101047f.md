**提示 1：** 如果我们已经确定了要进攻的敌人，我们应该按照什么顺序呢？

**提示 2：** 一开始我们按照这个逻辑排序，最后就只要求一个子序列了。

先看提示 1 。

此时对于我们应该先处理那些 $y_i\gt x_i$ 的敌人，因为先处理其余人只会减少血量。

而对于 $y_i\gt x_i$ 的，我们应该按照 $x_i$ 升序排列，因为这样可以在前期血量更少的情况下也能赚血量。

对于 $y_i\leq x_i$ 的，我们应该按照 $y_i$ 升序排列，因为最终的血量固定，把整个过程反向考虑，就是理解为从最终血量出发，不断先减去 $y_i$ 再加上 $x_i$ ，问能否到初始血量，发现是跟前面完全对称的，所以此时应该关于 $y_i$ 降序排列（为啥降序？从后往前的升序就是从前往后的降序）。

而如果我们一开始把所有敌人按照这个顺序排列，我们选取的 $n-k$ 个要处理的敌人一定形成这个序列的子序列。接下来问题就变简单了：原序列是否存在一个删去 $k$ 个元素的子序列，使得 $H$ 血量能够处理？

于是，只需维护前 $i$ 项删去 $j$ 项的情况下的最多血量 $dp[i][j]$ 即可。这个动态规划是很好做的，只需枚举新的一项是否要处理即可。

时间复杂度为 $\mathcal{O}(nk)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n, h, k = MII()
        
        xs = []
        ys = []
        
        adds = []
        minus = []
        
        for i in range(n):
            x, y = MII()
            xs.append(x)
            ys.append(y)
            
            if y >= x: adds.append(i)
            else: minus.append(i)
        
        adds.sort(key=lambda x: xs[x])
        minus.sort(key=lambda x: -ys[x])
        
        total = adds + minus
        
        dp = [-1] * (k + 1)
        dp[0] = h
        
        for i in total:
            x, y = xs[i], ys[i]
            ndp = [-1] * (k + 1)
            
            for j in range(k + 1):
                if dp[j] > x:
                    ndp[j] = fmax(ndp[j], dp[j] - x + y)
    
            for j in range(k):
                ndp[j + 1] = fmax(ndp[j + 1], dp[j])
            
            dp = ndp
        
        outs.append('Y' if max(dp) >= 0 else 'N')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n, h, k;
		cin >> n >> h >> k;

		vector<pair<int, int>> pos, neg;

		for (int i = 0; i < n; i ++) {
			int x, y;
			cin >> x >> y;

			if (y >= x) pos.emplace_back(x, y);
			else neg.emplace_back(x, y);
		}

		sort(pos.begin(), pos.end(), [&] (pair<int, int> &x, pair<int, int> &y) {
			return x.first < y.first;
		});

		sort(neg.begin(), neg.end(), [&] (pair<int, int> &x, pair<int, int> &y) {
			return x.second > y.second;
		});

		vector<long long> dp(k + 1, -1);
		dp[0] = h;

		for (auto &[x, y]: pos) {
			vector<long long> ndp(k + 1, -1);

			for (int i = 0; i <= k; i ++) {
				if (dp[i] > x) {
					ndp[i] = max(ndp[i], dp[i] - x + y);
				}
			}

			for (int i = 0; i < k; i ++) {
				ndp[i + 1] = max(ndp[i + 1], dp[i]);
			}
			
			dp.swap(ndp);
		}

		for (auto &[x, y]: neg) {
			vector<long long> ndp(k + 1, -1);

			for (int i = 0; i <= k; i ++) {
				if (dp[i] > x) {
					ndp[i] = max(ndp[i], dp[i] - x + y);
				}
			}

			for (int i = 0; i < k; i ++) {
				ndp[i + 1] = max(ndp[i + 1], dp[i]);
			}
			
			dp.swap(ndp);
		}

		cout << (*max_element(dp.begin(), dp.end()) >= 0 ? 'Y' : 'N') << '\n';
	}

	return 0;
}
```
