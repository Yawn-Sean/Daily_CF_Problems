**提示 1：** 每一位是独立的。

**提示 2：** 考虑 $a_i⊕b_j$ 在答案中出现多少次。

先看提示 2 ，任何一组 $a_i⊕b_j$ 在答案中的出现次数都是 $(n-1)!$ ，相当于钦定了 $p_j=i$ 的排列的个数。

所以我们只需求 $\sum\limits_i\sum\limits_j a_i⊕b_j$ 即可。

考虑每一位的贡献进行加总。假设考虑第 $i$ 位，就要求得到 $1$ 的方案数，无非就是第一个数组取 $1$ 第二个数组取 $0$ ，或者第一个数组取 $0$ 第二个数组取 $1$ ，加总即方案数，乘以 $2^i$ 就是这一位的贡献。

对所有位求和即可。

时间复杂度为 $\mathcal{O}(n\log M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    v1 = LII()
    v2 = LII()
    
    c1 = [0] * 20
    c2 = [0] * 20
    
    for i in range(n):
        for j in range(20):
            if v1[i] >> j & 1: c1[j] += 1
            if v2[i] >> j & 1: c2[j] += 1
    
    ans = 0
    mod = 10 ** 9 + 7
    
    for i in range(20):
        ans += (c1[i] * (n - c2[i]) + c2[i] * (n - c1[i])) % mod * (1 << i) % mod
        ans %= mod
    
    for i in range(1, n):
        ans = ans * i % mod
    
    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	vector<int> c1(20, 0), c2(20, 0);

	for (int i = 0; i < n; i ++) {
		int x; cin >> x;
		for (int j = 0; j < 20; j ++) {
			c1[j] += x >> j & 1;
		}
	}

	for (int i = 0; i < n; i ++) {
		int x; cin >> x;
		for (int j = 0; j < 20; j ++) {
			c2[j] += x >> j & 1;
		}
	}

	int ans = 0, mod = 1e9 + 7;

	for (int i = 0; i < 20; i ++) {
		ans += (1ll * c1[i] * (n - c2[i]) + 1ll * c2[i] * (n - c1[i])) % mod * (1 << i) % mod;
		ans %= mod;
	}
	
	for (int i = 1; i < n; i ++) ans = 1ll * ans * i % mod;

	cout << ans;

	return 0;
}
```
