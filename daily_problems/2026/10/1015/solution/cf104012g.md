**提示 1：** 数对数量并不多，想办法找到所有的。

可以打表看每个 $n$ 对应的数对个数，发现增长的并不快。因此考虑预处理所有的合法数对。

为此直接枚举 $x,y$ 肯定不行。

我们枚举 $y$ ，则 $x$ 根据 $\lfloor x/y\rfloor$ 的数值分为若干类，这些类的错误的 $gcd$ 数值我们都可以求出来，也就得出了合法的 $x,y$ 得是哪个数的倍数。

于是我们就要求，在 $g$ 是 $y$ 的因子的情况下，找出 $\lfloor x/y\rfloor$ 等于目标数值的所有 $g$ 的倍数，检查这些元素是否满足和 $y$ 的最大公约数是 $g$ 。

而数对求完之后可以用基数排序确认字典序关系，就可以少一个 $\log$ 因子了。

时间复杂度我好像真的不知道啊可恶。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, q = MII()
    
    def f(x, y):
        return x if y == 0 else f(y, x // y)
    
    tmp = [[] for _ in range(n + 1)]
    
    for i in range(2, n + 1):
        for j in range(1, n // i + 1):
            g = f(i, j)
            
            if i % g == 0:
                l = i * j
                r = fmin(i * (j + 1), n + 1)
                
                for v in range(((l - 1) // g + 1) * g, r, g):
                    if math.gcd(v, i) == g:
                        tmp[v].append(i)
    
    res = []
    
    for i in range(n + 1):
        for j in tmp[i]:
            res.append(i * (n + 1) + j)
    
    outs = []
    
    for _ in range(q):
        p = II()
        
        if p <= len(res):
            x, y = divmod(res[p - 1], n + 1)
            outs.append(f'{x} {y}')
        else:
            outs.append('-1 -1')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int f(int x, int y) {return y ? f(y, x / y) : x;}

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, q;
	cin >> n >> q;

	vector<vector<int>> tmp(n + 1);

	for (int i = 2; i <= n; i ++) {
		for (int j = 1; j <= n / i; j ++) {
			int g = f(i, j);

			if (i % g == 0) {
				int l = i * j;
				int r = min(i * (j + 1), n + 1);

				for (int v = ((l - 1) / g + 1) * g; v < r; v += g) {
					if (gcd(v, i) == g) {
						tmp[v].emplace_back(i);
					}
				}
			}
		}
	}

	vector<pair<int, int>> res;

	for (int i = 1; i <= n; i ++) {
		for (auto &j: tmp[i]) {
			res.emplace_back(i, j);
		}
	}

	while (q --) {
		long long p;
		cin >> p;

		if (p <= res.size()) cout << res[p - 1].first << ' ' << res[p - 1].second << '\n';
		else cout << "-1 -1\n";
	}

	return 0;
}
```
