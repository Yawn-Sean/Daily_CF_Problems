**提示 1：** 有很多做法。可以考虑离线。可以考虑在线。

**提示 2：** 离线——往下走，每个结点对应了哪些查询？

**提示 3：** 在线——考虑所有可以走到的结点，我们要求哪个？

我们这里给出两种做法。

**方法 1：** 离线。

此时，考虑 DFS 的过程中分配查询。

对于每个结点，其根据和子结点的边的边权，将查询分配给子结点——或者停留在自己这边。

具体而言，假设到子结点的边的边权分别是 $w_1,w_2,w_3,\dots$ ，而 $x∈[l,r]$ 时可以走到该结点，则在 $[0,w_1),[w_1,w_2),\dots$ 之类的区间和 $[l,r]$ 取交集，就是走到各个子结点的查询们；剩余部分最多只能留在当前节点。

这样每个结点就可以有一个对应的区间。数值落到哪个区间就可以查到对应的结点。这可以先将查询排序后再离线做，也可以二分找对应区间。

**方法 2：** 在线。

我们先不管走的是哪个结点，只要边权小于 $x$ 我们都认为可以走。我们定义每个结点的权值是 $1$ 到 $i$ 结点的路径上权值的最大值，权值比 $x$ 小的点就是 $x$ 系数下可达的点。

那我们要找的是其中哪个点呢？我们先将邻接表的所有边按照边权排序。此时要找的点就是 DFS 序中最靠后的结点。

因此我们先求 DFS 序和 DFS 序下各个节点的权值。我们要找的就是最后一个小于 $x$ 的数值的位置。为此，可以求这个序列的后缀最小值，这样就可以二分找到了。

时间复杂度为 $\mathcal{O}(n+m\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n, q = MII()
        path = [[] for _ in range(n)]
    
        for _ in range(n - 1):
            u, v, w = MII()
            u -= 1
            v -= 1
            path[u].append(w * n + v)
            path[v].append(w * n + u)
    
        for i in range(n): path[i].sort(reverse=True)
        
        parent = [-1] * n
        vals = [0] * n
    
        tmp_vals = []    
        order = []
        stk = [0]
        
        while stk:
            u = stk.pop()
            
            tmp_vals.append(vals[u])
            order.append(u)
            
            for msk in path[u]:
                w, v = divmod(msk, n)
                if parent[u] != v:
                    parent[v] = u
                    vals[v] = fmax(vals[u], w)
                    stk.append(v)
        
        for i in range(n - 1, 0, -1):
            tmp_vals[i - 1] = fmin(tmp_vals[i - 1], tmp_vals[i])
        
        ans = 0
        for v in MII():
            ans += order[bisect.bisect_left(tmp_vals, v) - 1] + 1
        
        outs.append(f'{ans}')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n, q;
		cin >> n >> q;

		vector<vector<pair<int, int>>> path(n);
		
		for (int i = 0; i < n - 1; i ++) {
			int u, v, w;
			cin >> u >> v >> w;
			u --, v --;
			path[u].emplace_back(w, v);
			path[v].emplace_back(w, u);
		}

		vector<int> vals, order;

		auto dfs = [&] (auto &self, int u, int p, int cur) -> void {
			vals.emplace_back(cur);
			order.emplace_back(u);

			sort(path[u].begin(), path[u].end());

			for (auto &[w, v]: path[u]) {
				if (v != p) {
					self(self, v, u, max(cur, w));
				}
			}
		};

		dfs(dfs, 0, -1, 0);

		for (int i = n - 2; i >= 0; i --) vals[i] = min(vals[i], vals[i + 1]);

		long long ans = 0;

		while (q --) {
			int x; cin >> x;
			int p = lower_bound(vals.begin(), vals.end(), x) - vals.begin();
			ans += order[p - 1] + 1;
		}

		cout << ans << '\n';
	}

	return 0;
}
```
