**提示 1：** 实际上组数并不多。为啥？

考虑 $x\lt y, x=F_a,y=F_b$ ，则 $F_a\geq F_{b+1}-F_b=F_{b-1}$ ，所以 $F_a=F_{b-1}$ 。

所以，如果 $b\geq 3$ ，则 $a=b-1$ ，否则 $a$ 可以选取任何一个等于 $1$ 的位置。

因此我们相当于对于 $b\geq 3$ ，我们只需找相邻的奇偶性不同的元素（当然，这里还需要用到相邻元素一定互质，辗转相除法可以推）。而奇偶性是三个一循环的，所以答案就呼之欲出了。

最后注意最开头的边界情况。时间复杂度为 $\mathcal{O}(1)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        outs.append(n - (n + 1) // 3 if n >= 3 else 0)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);
 
	int t;
	cin >> t;
 
	while (t --) {
		int n;
		cin >> n;
		cout << (n < 3 ? 0 : n - (n + 1) / 3) << '\n';
	}
 
	return 0;
}
```
