**提示 1：** 考虑每次操作会对当前的分数和有啥影响。

**提示 2：** 交换相邻两次操作会如何改变这个结果？

最小值和最大值是完全对称的，只要你把所有的 $x$ 换成 $n+1-x$ 就求出来了。我们下面求最大值。

假设初始情况下分数和为 $V$ ，评论者数量为 $cnt$ ，如果评论者的类型是 S ，则对结果进行 $+k$ 操作；如果类型是 D，则将 $V$ 更新为 $\max(V+1,\min(V+n,cnt\times k))$ 。称 $\max(B,\min(A,x))$ 操作为 $clip(x,A,B)$ 。

假设某两个操作相邻，则：

- 如果两个评论者都是 S 类型的，则不会改变最终结果。

- 如果是 S, D 类型的，设数值分别为 $x_1,x_2$ ，两种操作的方式的结果分别是 $clip((cnt+1)\times x_2,x+x_1+1,x+x_2+n)$ 和 $clip(cnt\times x_2,x+1,x+n)+x_1=clip(cnt\times x_2+x_1,x+x_1+1,x+x_1+n)$ ，两者之间的大小关系只取决于 $x_1,x_2$ 的大小关系。

- 如果是两个 D 类型的，设数值分别为 $x_1,x_2$ ，也应当把小数值放前面（可以自行验证，直接用式子描述比较复杂，直观上是先把容易让数值变小的操作先做掉，后面的限制更小，且后面的数值更大在 $cnt$ 更大的时候效果更好）。

所以综上，只需把 $x$ 较大的操作放后面做就行。按照这点排序即可。而 $x$ 数值相同的任意调换顺序是不影响答案的。

时间复杂度为 $\mathcal{O}(n\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, m = MII()
    
    types = []
    score = []
    
    for _ in range(m):
        t, x = LI()
        types.append(1 if t == 'S' else 0)
        score.append(int(x))
    
    def solve():
        cnt = 0
        cur = 0
        for i in sorted(range(m), key=lambda x: score[x]):
            cnt += 1
            if types[i]: cur += score[i]
            else: cur = fmin(cur + n, fmax(cur + 1, score[i] * cnt))
        return cur / cnt
    
    mx = solve()
    
    for i in range(m):
        score[i] = n + 1 - score[i]
    
    mn = n + 1 - solve()
    
    print(f'{mn:.15f} {mx:.15f}')
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, k;
	cin >> n >> k;

	vector<pair<char, int>> readers(k);
	for (auto &[t, x]: readers) cin >> t >> x;

	sort(readers.begin(), readers.end(), [&] (pair<char, int> &x, pair<char, int> &y) {
		return x.second < y.second;
	});

	auto f = [&] () -> long double {
		long long tot = 0, cnt = 0;
		for (auto &[t, x]: readers) {
			cnt ++;
			if (t == 'S') tot += x;
			else tot = max(tot + 1, min(tot + n, cnt * x));
		}
		return (long double)tot / cnt;
	};

	auto mx = f();

	reverse(readers.begin(), readers.end());
	for (auto &[t, x]: readers) x = n + 1 - x;

	auto mn = f();
	mn = n + 1 - mn;

	cout << fixed << setprecision(15) << mn << ' ' << mx;

	return 0;
}
```
