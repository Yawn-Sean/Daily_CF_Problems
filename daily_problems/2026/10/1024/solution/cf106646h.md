**提示 1：** 考虑基准。赚分的位置需要满足什么条件？

我们先假设所有的扣分都执行，这样我们只需调整一些变成加分的就行。

加分的位置需要满足：前 $1$ 个位置有 $1$ 个，前 $3$ 个位置中有 $2$ 个，……，前 $2n-1$ 个位置中有 $n$ 个。而每次加分的实际收益是 $a_i+b_i$ 。

所以我们只需用大顶堆维护当前可以赚分的数值，在 $1,3,\dots,2n-1$ 的位置弹出当前能选的最大元素即可。

时间复杂度为 $\mathcal{O}(n\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    v1 = LII()
    v2 = LII()
    
    ans = 0
    pq = []
    
    for i in range(2 * n):
        ans -= v2[i]
        heappush(pq, -(v1[i] + v2[i]))
        if i % 2 == 0: ans -= heappop(pq)
    
    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	vector<int> v1(2 * n), v2(2 * n);
	for (auto &x: v1) cin >> x;
	for (auto &x: v2) cin >> x;

	long long ans = 0;
	priority_queue<int> pq;

	for (int i = 0; i < 2 * n; i ++) {
		ans -= v2[i];
		pq.push(v1[i] + v2[i]);
		if (i % 2 == 0) {
			ans += pq.top();
			pq.pop();
		}
	}

	cout << ans;

	return 0;
}
```
