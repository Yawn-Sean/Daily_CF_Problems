**提示 1：** 考虑 $T$ 时刻形成了矩形，四个角是怎么产生的？

**提示 2：** 上述得到的条件够了吗？

考虑得到的矩形，四个角一定往里缩 $T$ 个单位，因此这四个位置一定有点（可以重合），分别对应于原图形的左上角、右上角、左下角、右下角（不可能有超过这个范围的点，否则 $T$ 单位事件后会在矩形外面多出来一块）。

所以我们只需找到横纵坐标的最值，看四个角上有没有点就行。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        xs = []
        ys = []
        
        for _ in range(n):
            x, y = MII()
            xs.append(x)
            ys.append(y)
        
        mnx, mxx = min(xs), max(xs)
        mny, mxy = min(ys), max(ys)
        
        def check(x, y):
            for i in range(n):
                if xs[i] == x and ys[i] == y:
                    return True
            return False
    
        if check(mnx, mny) and check(mnx, mxy) and check(mxx, mny) and check(mxx, mxy):
            outs.append('YES')
        else:
            outs.append('NO')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int t, inf = 2e9;
	cin >> t;

	while (t --) {
		int n;
		cin >> n;

		int mnx = inf, mxx = -inf;
		int mny = inf, mxy = -inf;

		vector<pair<int, int>> pts(n);

		for (auto &[x, y]: pts) {
			cin >> x >> y;
			mnx = min(mnx, x), mxx = max(mxx, x);
			mny = min(mny, y), mxy = max(mxy, y);
		}

		auto check = [&] (int vx, int vy) -> bool {
			for (auto &[x, y]: pts) {
				if (x == vx && y == vy) {
					return true;
				}
			}
			return false;
		};

		if (check(mnx, mny) && check(mnx, mxy) && check(mxx, mny) && check(mxx, mxy)) cout << "YES\n";
		else cout << "NO\n";
	}

	return 0;
}
```
