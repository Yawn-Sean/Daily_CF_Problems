**提示 1：** 把相似的路径用一条代表路径表示。

**提示 2：** 代表路径的特点？如何计数？

操作相当于每次找一个折角换个方向折，要求选的任意两个路径无法这样得到（中间不能出现非法路径）。

那两条路径的转化一定是相互的，所以我们只需考虑有多少个不能相互转化的类就好。

对于每一类，我们找一条代表的路径。这个还是很好想的——要么尽可能往右走，要么尽可能往下走，任何一个逻辑都可以唯一确定一个类内的一条路径，且都可以统计。

我们以尽可能往下走的代表元为例——所有 RD 的位置一定刚好绕过了一个 `#` —— 不然你一定可以把这个 RD 换成 DR ，不满足前面尽可能往下走的条件。

所以我们定义 $dp_0[x][y],dp_1[x][y]$ 分别是最后一步往下走和最后一步往右走，走到 $(x,y)$ 的方案数，则 $dp_1[x][y]$ 转移到 $dp_0[x+1][y]$ 当且仅当 $(x+1,y-1)$ 走不了（前一段提到了），而 $dp_0[x][y]$ 没有这个限制。

同时 $dp_1[x][y]=dp_0[x][y-1]+dp_1[x][y-1]$ ，因为 DR 转角没有限制。

而起始状态下我们可以认为前一步是往下走的，因为下一步是可以任选转移的，所以初态是 $dp_0[1][1]=1$ 。

当然还得注意起点是 `#` 的情况。

时间复杂度为 $\mathcal{O}(nm)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    mod = 998244353
    
    for _ in range(t):
        n, m = MII()
        grid = [[1 if c == '.' else 0 for c in I()] for _ in range(n)]
        
        dp0 = [[0] * m for _ in range(n)]
        dp1 = [[0] * m for _ in range(n)]
        
        dp0[0][0] = 1 if grid[0][0] else 0
    
        for i in range(n):
            for j in range(m):
                if grid[i][j]:
                    if i: dp0[i][j] = dp0[i - 1][j]
                    if j:
                        if i and grid[i][j - 1] == 0:
                            dp0[i][j] += dp1[i - 1][j]
                        dp1[i][j] = dp0[i][j - 1] + dp1[i][j - 1]
                    dp0[i][j] %= mod
                    dp1[i][j] %= mod
        
        outs.append((dp0[-1][-1] + dp1[-1][-1]) % mod)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int t, mod = 998244353;
	cin >> t;

	while (t --) {
		int n, m;
		cin >> n >> m;

		vector<string> grid(n);
		for (auto &s: grid) cin >> s;

		vector<vector<int>> dp0(n, vector<int>(m, 0));
		vector<vector<int>> dp1(n, vector<int>(m, 0));
		dp0[0][0] = (grid[0][0] == '.' ? 1 : 0);

		for (int i = 0; i < n; i ++) {
			for (int j = 0; j < m; j ++) {
				if (grid[i][j] == '.') {
					if (i) dp0[i][j] += dp0[i - 1][j];
					if (j) {
						if (i && grid[i][j - 1] == '#') dp0[i][j] += dp1[i - 1][j];
						dp1[i][j] = dp0[i][j - 1] + dp1[i][j - 1];
					}
					dp0[i][j] %= mod;
					dp1[i][j] %= mod;
				}
			}
		}

		cout << (dp0[n - 1][m - 1] + dp1[n - 1][m - 1]) % mod << '\n';
	}

	return 0;
}
```
