**提示 2：** 根据上面那件事儿，进行构造。

条件：正面朝上的数量是奇数。你可以手动玩一下 $n$ 比较小的情况。

怎么证明呢？

用数学归纳法。

考虑最后一次操作的位置。

- 如果在端点，则后面这一段因为可以自己操作，总共有奇数个正面。且恰好会翻转端点一次，因此这个端点目前是反面朝上——总正面朝上的个数仍然是奇数。

- 如果在中间，则前后两段都可以自己操作，因此都有奇数个正面，总正面个数是偶数。同时，最后一次操作的位置被操作了 $2$ 次，因此这个位置只能是正面朝上。加起来，总正面朝上的个数仍然是奇数。

接下来如何构造呢？

我们只需找到第一个正面朝上的位置，操作它——前缀的部分直接往前不断操作，是合法的。接下来的位置形成了一个规模更小的子问题。

为此只需维护当前尚未操作的最后一个位置，然后从下一个 $1$ 操作到它即可。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        s = [1 if c == 'D' else 0 for c in I()]
        
        if sum(s) % 2 == 0: outs.append('N')
        else:
            ans = []
            l = 0
            for i in range(n):
                if s[i]:
                    for j in range(i, l - 1, -1):
                        ans.append(j)
                    l = i + 1
                    if i + 1 < n:
                        s[i + 1] ^= 1
            
            outs.append('Y')
            outs.append(' '.join(str(x + 1) for x in ans))
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n;
		string s;
		cin >> n >> s;

		vector<int> ops;
		int l = 0;

		for (int i = 0; i < n; i ++) {
			if (s[i] == 'D') {
				for (int j = i; j >= l; j --) ops.emplace_back(j);
				l = i + 1;
				if (i + 1 < n) s[i + 1] = s[i + 1] == 'B' ? 'D' : 'B';
			}
		}

		if (ops.size() == n) {
			cout << "Y\n";
			for (int i = 0; i < n; i ++) cout << ops[i] + 1 << " \n"[i == n - 1];
		}
		else cout << "N\n";
	}

	return 0;
}
```
