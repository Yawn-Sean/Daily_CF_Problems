**提示 1：** 整体逻辑上是要找足够远的点，可以想到什么？

**提示 2：** 基于想到的东西进行讨论。

关于足够远的点，容易想到的是直径。

因为我们要找策略，而博弈策略往往涉及一一对应，所以考虑直径上的对称性。

于是考虑直径上的中点（可能在某一条边的中点上）。

如果一开始的位置在这个中点上，则无论先手作何操作，都可以在另外的分支找到距中点同样距离的点——一定能保证找到对应的操作且满足要求。

同样的，如果不在中点，先手可以先找对称的位置；接下来不断对应操作，也是必胜的。

所以只需判断 $k$ 是否是直径中点。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n, k = MII()
        k -= 1
        
        path = [[] for _ in range(n)]
        
        for _ in range(n - 1):
            u, v = GMI()
            path[u].append(v)
            path[v].append(u)
        
        def get_dis(u):
            que = [u]
            dis = [-1] * n
            dis[u] = 0
            
            for u in que:
                for v in path[u]:
                    if dis[v] == -1:
                        dis[v] = dis[u] + 1
                        que.append(v)
            
            return dis
        
        d0 = get_dis(0)
        
        rt1 = d0.index(max(d0))
        d1 = get_dis(rt1)
        
        rt2 = d1.index(max(d1))
        d2 = get_dis(rt2)
        
        mx = max(d1)
        
        outs.append('Bob' if d1[k] == d2[k] and d1[k] + d2[k] == mx else 'Alice')
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int t;
	cin >> t;

	while (t --) {
		int n, k;
		cin >> n >> k;
		k --;

		vector<vector<int>> path(n);

		for (int i = 0; i < n - 1; i ++) {
			int u, v;
			cin >> u >> v;
			u --, v --;
			path[u].emplace_back(v);
			path[v].emplace_back(u);
		}

		auto get_dis = [&] (int u) -> vector<int> {
			vector<int> dis(n, -1);
			queue<int> q; q.push(u);
			dis[u] = 0;

			while (!q.empty()) {
				int u = q.front();
				q.pop();

				for (auto &v: path[u]) {
					if (dis[v] == -1) {
						dis[v] = dis[u] + 1;
						q.push(v);
					}
				}
			}

			return dis;
		};

		auto d0 = get_dis(0);

		int rt1 = max_element(d0.begin(), d0.end()) - d0.begin();
		auto d1 = get_dis(rt1);

		int rt2 = max_element(d1.begin(), d1.end()) - d1.begin();
		auto d2 = get_dis(rt2);

		int mx = *max_element(d2.begin(), d2.end());

		cout << (d1[k] == d2[k] && d1[k] + d2[k] == mx ? "Bob" : "Alice") << '\n';
	}

	return 0;
}
```
