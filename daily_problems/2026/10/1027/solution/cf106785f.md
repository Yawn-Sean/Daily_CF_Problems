**提示 1：** 在删到长度为 $i$ 前，小于等于 $i$ 的元素的子序列实际上从来没变过——不变量。

**提示 2：** 整体操作流程如何？

先看提示 1 。

所以一旦我们找到了最大的 $x$ ，使得两个排列的不超过 $x$ 的元素形成的子序列相等，则我们可以先删到 $x$ 长度，再加回第二个序列。

这个 $x$ 可以二分找到。同时这个步骤一定也是最少的——因为你无论如何最小长度不可能大于 $x$ ，否则 $1\sim x+1$ 形成的子序列将永远不一致。

最终答案就是 $n+m-2x$ 。

时间复杂度为 $\mathcal{O}(n\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n, m = MII()
        p = LII()
        q = LII()
        
        l, r = 0, fmin(n, m)
        
        while l <= r:
            mid = (l + r) // 2
            
            if [x for x in p if x <= mid] == [x for x in q if x <= mid]: l = mid + 1
            else: r = mid - 1
        
        outs.append(n + m - r * 2)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int t;
	cin >> t;

	while (t --) {
		int n, m;
		cin >> n >> m;

		vector<int> p(n), q(m);
		for (auto &x: p) cin >> x;
		for (auto &x: q) cin >> x;

		int l = 0, r = min(n, m);

		while (l <= r) {
			int mid = (l + r) / 2;
			vector<int> v1, v2;

			for (auto &x: p) if (x <= mid) v1.emplace_back(x);
			for (auto &x: q) if (x <= mid) v2.emplace_back(x);

			if (v1 == v2) l = mid + 1;
			else r = mid - 1;
		}

		cout << n + m - r * 2 << '\n';
	}

	return 0;
}
```
