**提示 1：** 暴力，为啥呢？

这里的规律很诡异：每一次的下一轮游戏的位置会隔开一个越来越大的长度。

但这也意味着：总共进行的轮次数 $x$ 满足 $1+2+3+\dots+(x-1)\leq n-1$ ，所以 $x$ 最大是 $\mathcal{O}(\sqrt{n})$ 量级的。

所以直接暴力遍历每一种可能的情况即可（枚举游戏起点与进行的轮次）。注意模拟时，不允许财富数值小于 $0$ 。

时间复杂度为 $\mathcal{O}(n\sqrt{n})$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n, k = MII()
        nums = LII()
        
        ans = k
        
        for i in range(n):
            cur = k
            cur_idx = i
            
            for x in range(1, n + 1):
                cur += nums[cur_idx]
                ans = fmax(cur, ans)
                cur_idx += x
    
                if cur < 0 or cur_idx >= n: break
        
        outs.append(ans)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n, k;
		cin >> n >> k;

		vector<int> nums(n);
		for (auto &x: nums) cin >> x;

		long long ans = k;

		for (int i = 0; i < n; i ++) {
			long long cur = k, cur_idx = i;

			for (int j = 1; j <= n && cur_idx < n && cur >= 0; j ++) {
				cur += nums[cur_idx];
				ans = max(ans, cur);
				cur_idx += j;
			}
		}

		cout << ans << '\n';
	}

	return 0;
}
```
