**提示 1：** 直接做即使 $\mathcal{O}(lh)$ 复杂度都不够，所以考虑预处理。

**提示 2：** 如何预处理 DP 使得总复杂度不超标？

首先，这题不能每次查询来了之后再做，否则 $\mathcal{O}(lh)$ 都不够用。所以考虑预处理。

有至少两种方式——

解法 1 ：考虑到第 $i$ 个位置最大值为 $x$ 且当前数值为 $y$ 的情况下的方案数。则从 $(i,x,y)$ 可以变为 $(i+1,x,y-1)$ （ $y\geq 1$ 时）或 $(i+1,\max(x,y+1),y+1)$ 状态之一，而我们只需存储其中的 $(i,2k,0)$ 的状态即可。

解法 2 ：容斥。考虑最大值不超过 $v$ 的方案数，只需当前长度为 $i$ 且当前数值为 $j$ 的方案数，则这个转移就是 $(i+1,j±1)$ 即可。最后用不超过 $v$ 的方案数减去不超过 $v-1$ 的方案数即可。 

时间复杂度为 $\mathcal{O}(L^3)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    mod = 1000000007
    saved = [[0] * 201 for _ in range(201)]
    
    for mx_val in range(1, 201):
        dp = [0] * (mx_val + 1)
        dp[0] = 1
        
        for i in range(400):
            ndp = [0] * (mx_val + 1)
            
            for j in range(mx_val + 1):
                if j: ndp[j] += dp[j - 1]
                if j < mx_val: ndp[j] += dp[j + 1]
                ndp[j] %= mod
            
            dp = ndp
            if i % 2: saved[mx_val][(i + 1) // 2] = dp[0]
    
    for i in range(200, 0, -1):
        for j in range(201):
            saved[i][j] -= saved[i - 1][j]
            saved[i][j] %= mod
    
    t = II()
    outs = []
    
    for _ in range(t):
        l, h = MII()
        outs.append(saved[h][l])
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int mod = 1000000007;

	auto add = [&] (int &x, int y) -> void {
		x += y;
		if (x >= mod) x -= mod;
	};

	vector<vector<int>> saved(201, vector<int>(201, 0));

	for (int mx_val = 1; mx_val <= 200; mx_val ++) {
		vector<int> dp(mx_val + 1, 0);
		dp[0] = 1;

		for (int i = 1; i <= 400; i ++) {
			vector<int> ndp(mx_val + 1, 0);

			for (int j = 0; j <= mx_val; j ++) {
				if (j) add(ndp[j], dp[j - 1]);
				if (j < mx_val) add(ndp[j], dp[j + 1]);
			}

			dp.swap(ndp);
			if (i % 2 == 0) saved[mx_val][i / 2] = dp[0];
		}
	}

	for (int i = 200; i >= 1; i --) {
		for (int j = 0; j <= 200; j ++) {
			add(saved[i][j], mod - saved[i - 1][j]);
		}
	}

	int t;
	cin >> t;

	while (t --) {
		int l, h;
		cin >> l >> h;
		cout << saved[h][l] << '\n';
	}

	return 0;
}
```
