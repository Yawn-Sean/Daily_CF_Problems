**提示 1：** 数值越大越难达到。

**提示 2：** 如果缺了，怎么补？

首先越大的数值越难达到，所以可以二分找到能达到的最大数值。

而我们接下来就要看某个数值是否可以达到。

考虑每一位差了多少，依次解决。

从左往右遍历，如果 $i$ 位置还缺少 $x$ 的数值怎么办呢？

我们应该选取一个左端点不超过 $x$ ，且右端点最大的操作，进行对应的次数。这样的效果是最好的。

所以不断进行这样的贪心操作，看次数是否超过 $k$ 即可。

时间复杂度为 $\mathcal{O}(n\log M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, k = MII()
    nums = LII()
    radius = LII()
    
    farthest = [0] * n
    
    for i in range(n):
        l = fmax(0, i - radius[i])
        r = fmin(n - 1, i + radius[i])
        farthest[l] = fmax(farthest[l], r)
    
    for i in range(1, n):
        farthest[i] = fmax(farthest[i], farthest[i - 1])
    
    diff = [0] * (n + 1)
    
    l, r = 1, 2 * 10 ** 9
    
    while l <= r:
        mid = (l + r) // 2
        
        cur = 0
        total = 0
        flg = True
        
        for i in range(n):
            cur += diff[i]
            v = fmax(mid - (nums[i] + cur), 0)
            
            diff[farthest[i] + 1] -= v
            cur += v
            total += v
            
            if total > k:
                flg = False
                break
        
        for i in range(n + 1):
            diff[i] = 0
        
        if flg: l = mid + 1
        else: r = mid - 1
    
    print(r)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, k;
	cin >> n >> k;

	vector<int> scores(n), farthest(n, 0);

	for (auto &x: scores) cin >> x;

	for (int i = 0; i < n; i ++) {
		int radius; cin >> radius;
		int l = max(0, i - radius);
		int r = min(n - 1, i + radius);
		farthest[l] = max(farthest[l], r);
	}

	for (int i = 1; i < n; i ++) farthest[i] = max(farthest[i], farthest[i - 1]);

	int l = 1, r = 1e9 + 2e5;
	vector<int> diff(n + 1, 0);

	while (l <= r) {
		int mid = (l + r) / 2;

		int cur = 0, total = 0;
		bool flg = true;

		for (int i = 0; i < n; i ++) {
			cur += diff[i];
			int v = max(mid - (scores[i] + cur), 0);

			diff[farthest[i] + 1] -= v;
			cur += v, total += v;

			if (total > k) {
				flg = false;
				break;
			}
		}

		for (int i = 0; i <= n; i ++) diff[i] = 0;

		if (flg) l = mid + 1;
		else r = mid - 1;
	}

	cout << r;

	return 0;
}
```
