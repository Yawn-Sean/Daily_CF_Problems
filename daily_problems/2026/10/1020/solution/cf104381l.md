**提示 1：** 本质上只需考虑 $d$ 累计到多少，根据这个分层图。

先看提示 1 ，我们考虑 $dis[d][x]$ 是 $d$ 为 $0,1,2,\dots$ 的情况下从 $1$ 出发到 $x$ 的最小成本。

这样，同一层之间只可能用边权为 $0$ 的边，本质上可以直接使用并查集等手段在同一个连通块内更新。

而一旦走了一条带权边，就进入下一层。这里层数单调不减，因此可以写成 DP 的形式。

具体地，可以把所有用无权边相连的点看成一个点，接下来就没有无权边的事儿了，再用 DP 进行不同 $d$ 之间的状态转移。

注意这里 $d$ 最大只有 $n-1$ ，因为你最多只能用这么多边，不然一定成环了。

时间复杂度为 $\mathcal{O}(n(n+m))$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, m, T = MII()
    T -= 1
    
    uf = UnionFind(n)
    edges = []
    
    for _ in range(m):
        u, v, x = MII()
        u -= 1
        v -= 1
        if x == 0: uf.merge(u, v)
        else: edges.append((u, v, x))
    
    dp = [[inf] * n for _ in range(n)]
    dp[0][uf.find(0)] = 0
    
    ans = inf
    
    for i in range(n - 1):
        for u, v, x in edges:
            u = uf.find(u)
            v = uf.find(v)
            dp[i + 1][v] = fmin(dp[i + 1][v], dp[i][u] + i * x)
            dp[i + 1][u] = fmin(dp[i + 1][u], dp[i][v] + i * x)
    
    for i in range(n):
        ans = fmin(ans, dp[i][uf.find(T)])
    
    print(ans if ans < inf else -1)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, m, t;
	cin >> n >> m >> t;
	t --;

	atcoder::dsu uf(n);
	vector<array<int, 3>> edges;

	while (m --) {
		int u, v, x;
		cin >> u >> v >> x;
		u --, v --;
		if (!x) uf.merge(u, v);
		else edges.push_back({u, v, x});
	}

	int inf = 1e9, ans = inf;
	vector<vector<int>> dp(n, vector<int>(n, inf));

	dp[0][uf.leader(0)] = 0;

	for (int i = 0; i < n - 1; i ++) {
		for (auto [u, v, x]: edges) {
			u = uf.leader(u), v = uf.leader(v);
			dp[i + 1][v] = min(dp[i + 1][v], dp[i][u] + i * x);
			dp[i + 1][u] = min(dp[i + 1][u], dp[i][v] + i * x);
		}
	}

	for (auto &v: dp) ans = min(ans, v[uf.leader(t)]);

	cout << (ans < inf ? ans : -1);

	return 0;
}
```
