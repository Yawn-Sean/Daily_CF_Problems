**提示 1：** 看看哪个数据范围足够小。

发现 $r-l$ 很小，而等差数列又递增，所以考虑枚举公差。

在公差为 $x$ 时，项数有 $\mathcal{O}(\frac{r-l}{x})$ 种不同可能性。

枚举这些可能性，则总枚举量是 $\mathcal{O}(\sum\frac{r-l}{x})=\mathcal{O}((r-l)\log (r-l))$ 的。

接下来只需根据这两个变量就能求出序列首项，进而判断是否每个元素都在 $[l,r]$ 内且 $a$ 在序列中出现。

最后，别忘了序列长度为 $1$ 的情况。

时间复杂度为 $\mathcal{O}((r-l)\log(r-l))$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    a, s, l, r = MII()
    
    ans = 0
    
    for diff in range(1, r - l + 1):
        for length in range(1, (r - l) // diff + 1):
            k = length + 1
            if s * 2 % k: continue
            
            v = s * 2 // k - length * diff
            if v % 2 == 0:
                vl = v // 2
                vr = vl + length * diff
                
                if vl >= l and vr <= r and vl <= a <= vr and (a - vl) % diff == 0:
                    ans += 1
    
    if s == a: ans += 1
    
    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	long long a, s, l, r;
	cin >> a >> s >> l >> r;

	int ans = 0;

	for (int diff = 1; diff <= r - l; diff ++) {
		for (int length = 1; length * diff <= r - l; length ++) {
			int k = length + 1;
			if (s * 2 % k) continue;

			long long v = s * 2 / k - length * diff;

			if (v % 2 == 0) {
				long long vl = v / 2;
				long long vr = vl + length * diff;

				if (vl >= l && vr <= r && a >= vl && a <= vr && (a - vl) % diff == 0) ans ++;
			}
		}
	}

	if (s == a) ans ++;

	cout << ans;

	return 0;
}
```
