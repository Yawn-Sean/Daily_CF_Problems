**提示 1：** 如果从一个位置出发，走一样的距离能到达两个加油站，你一定选 $p$ 更大的那个，借此你可以排除掉一些。

**提示 2：** 状态转移——实际上是转到一个区间。

考虑 $dp[i]$ 表示走到一个加油站时，最少的浪费的距离（也就是多走的那些 $\sum a_i$ ）。为了方便处理，我们定义 $p_0=0,a_0=0$ 。

假设从 $i$ 出发，转移到 $j$ ，则 $j$ 需要满足 $p_j-p_i+a_i/2+a_j/2\leq l$ 。

于是需要 $p_j+a_j/2$ 不超过某一个界。但这里转移的 $j$ 是不连续的，所以会不好处理。

怎么办呢？我们发现，如果 $p_j$ 本身数值更小，而 $p_j+a_j/2$ 却更大了，那么这个 $j$ 没必要走——因为无论如何浪费了更多的 $a_j$ ，且只到达了一个 $p_j$ 更小的位置。

所以我们可以单调栈，去除这些 $j$ ，接下来的状态转移就是从一个点到一段连续区间了，因为更大的 $p_j$ 一定对应更大的 $p_j+a_j/2$ ，这就很好处理了。

从左到右遍历 $i$ ，将 $dp[i]+a_i$ 的数值更新到 $[i+1,j]$ 中，其中 $j$ 是最远的能到达位置。接下来每个 $dp[x]$ 的位置的最小成本就是这里更新的结果的最大值加上 $a_x$ 。

事件复杂度为 $\mathcal{O}(n\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    total = II()
    gas = II()
    
    n = II()
    ps = [0]
    ds = [0]
    
    for _ in range(n):
        p, d = MII()
        
        while 2 * p + d <= 2 * ps[-1] + ds[-1]:
            ps.pop()
            ds.pop()
        
        ps.append(p)
        ds.append(d)
    
    n = len(ps)
    ans = inf
    
    seg = SegTree(fmin, inf, n)
    seg.set(0, 0)
    
    for i in range(n):
        v = seg.prod(i, n)
        
        if v < inf:
            nv = v + ds[i]
            
            if 2 * (total - ps[i]) + ds[i] <= 2 * gas:
                ans = fmin(ans, total + nv)
            
            l, r = i, n - 1
            while l <= r:
                mid = (l + r) // 2
                
                if 2 * (ps[mid] - ps[i]) + ds[i] + ds[mid] <= 2 * gas:
                    l = mid + 1
                else:
                    r = mid - 1
            
            seg.set(r, fmin(seg.get(r), nv))
    
    print(ans if ans < inf else -1)
```

C++ 做法如下——

```cpp []
const long long inf = 1e18;

long long e() {return inf;}

long long op(long long x, long long y) {return min(x, y);}

int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int total, gas, n;
	cin >> total >> gas >> n;

	vector<pair<int, int>> stations;
	stations.emplace_back(0, 0);

	for (int i = 0; i < n; i ++) {
		int p, d;
		cin >> p >> d;

		while (2 * p + d <= 2 * stations.back().first + stations.back().second)
			stations.pop_back();

		stations.emplace_back(p, d);
	}

	n = stations.size();

	long long ans = inf;
	atcoder::segtree<long long, op, e> seg(n);

	seg.set(0, 0);

	for (int i = 0; i < n; i ++) {
		auto v = seg.prod(i, n);

		if (v < inf) {
			long long nv = v + stations[i].second;

			if (2 * (total - stations[i].first) + stations[i].second <= 2 * gas)
				ans = min(ans, total + nv);

			int l = i, r = n - 1;

			while (l <= r) {
				int mid = (l + r) / 2;

				auto [p1, d1] = stations[i];
				auto [p2, d2] = stations[mid];

				if (2 * (p2 - p1) + d1 + d2 <= 2 * gas) l = mid + 1;
				else r = mid - 1;
			}

			seg.set(r, min(seg.get(r), nv));
		}
	}

	cout << (ans < inf ? ans : -1);

	return 0;
}
```
