**提示 1：** 认为同一轮拿回来的是一批，每一批结果如何？

**提示 2：** 大的距离要少跑。

我们称从起点到回到起点为一批，则一批中最多拿了 $c$ 个文件，跑的距离最小为这几个文件中的最大距离的两倍。

而为了最大距离的和越小越好，应该让远距离的打包，这样可以消灭掉更多的大距离。所以从后往前遍历 $c$ 个 $c$ 个打包就好。注意如果 $nums[i]\geq c$ ，则把一堆同个位置的文件一起打包。

事件复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n, c = MII()
    nums = LII()
    
    ans = 0
    cur = 0
    
    for i in range(n - 1, -1, -1):
        if nums[i] > cur:
            nums[i] -= cur
            
            w = (nums[i] + c - 1) // c
            ans += w * (i + 1)
            
            cur = c * w - nums[i]
        else:
            cur -= nums[i]
    
    print(ans * 2)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, c;
	cin >> n >> c;

	vector<int> nums(n);
	for (auto &x: nums) cin >> x;

	int cur = 0;
	long long ans = 0;

	for (int i = n - 1; i >= 0; i --) {
		if (nums[i] <= cur) cur -= nums[i];
		else {
			nums[i] -= cur;
			int w = (nums[i] + c - 1) / c;
			ans += 2ll * w * (i + 1);
			cur = w * c - nums[i];
		}
	}

	cout << ans;

	return 0;
}
```
