**提示 1：** 只需考虑用质数覆盖整个集合。

**提示 2：** 大的质数好像只能查漏补缺。

考虑每一个集合，取集合最大公约数的一个质因子，这样就相当于我们要找最少的质因子个数，使得每个数至少是其中一个质因子的倍数。

但质数还是很多，怎么办？

考虑一个元素的质因数分解，则其中最多只有一个质因子是超过 50 的，其余都不超过 $50$ ，所以后者是相对密集的。

我们考虑枚举不超过 $50$ 的质数，我们选取其子集。则对于剩余元素，我们将不得不选取其大于 $50$ 的因子。

因为不超过 $50$ 的质数只有 $15$ 个，所以枚举 $2^{15}$ 个子集并不会太糟糕。同时，也可以利用二进制数标记每个元素能被哪些不超过 $50$ 的质数整除，用位运算即可得到该元素是否需要取大于 $50$ 的因子。

对于那些不得不取大于 $50$ 的质因子的元素，我们可以用数组维护要选取多少个数（如果这些数既需要取因子，又没有大于 $50$ 的质因子，则应当跳过这个子集）。

最后对各个子集取最小结果即可。

时间复杂度为 $\mathcal{O}(2^kn)$ ，其中 $k=15$ 是不超过 $\sqrt{M}$ 的质数的个数。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    prs = []
    
    for i in range(2, 51):
        for j in range(2, i):
            if i % j == 0: break
        else:
            prs.append(i)
    
    k = len(prs)
    
    tag = [0] * 2501
    big = [0] * 2501
    
    for i in range(1, 2501):
        msk = 0
        cur = i
        
        for j in range(k):
            while cur % prs[j] == 0:
                msk |= 1 << j
                cur //= prs[j]
        
        tag[i] = msk
        if cur >= 50: big[i] = cur
    
    vis = [0] * 2501
    
    n = II()
    nums = LII()
    
    res = [0] * n
    
    ans = n
    
    for i in range(1 << k):
        cur = i.bit_count()
        for j in range(n):
            res[j] = 1 if tag[nums[j]] & i == 0 else 0
        
        flg = True
        
        for j in range(n):
            if res[j]:
                if big[nums[j]] == 0: flg = False
                else:
                    if vis[big[nums[j]]] == 0:
                        vis[big[nums[j]]] = 1
                        cur += 1
        
        if flg:
            ans = fmin(ans, cur)
        
        for j in range(n):
            vis[big[nums[j]]] = 0
    
    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	vector<int> prs;

	for (int i = 2; i <= 50; i ++) {
		bool flg = true;

		for (int j = 2; j < i; j ++) {
			if (i % j == 0) {
				flg = false;
			}
		}

		if (flg) prs.emplace_back(i);
	}

	int k = prs.size();

	int M = 2501;

	vector<int> tag(M, 0), big(M, 0);

	for (int i = 1; i < M; i ++) {
		int msk = 0, cur = i;

		for (int j = 0; j < k; j ++) {
			while (cur % prs[j] == 0) {
				msk |= 1 << j;
				cur /= prs[j];
			}
		}

		tag[i] = msk;
		if (cur >= 50) big[i] = cur;
	}

	int n;
	cin >> n;

	vector<int> nums(n);
	for (auto &x: nums) cin >> x;

	vector<int> vis(M, 0);
	int ans = n;

	for (int i = 0; i < (1 << k); i ++) {
		int cur = __popcount(i);
		bool flg = true;

		for (auto &v: nums) {
			if (tag[v] & i) continue;
			if (big[v]) {
				if (!vis[big[v]]) {
					vis[big[v]] = 1;
					cur ++;
				}
			}
			else flg = false;
		}

		if (flg) ans = min(ans, cur);

		for (auto &v: nums) vis[big[v]] = 0;
	}

	cout << ans;

	return 0;
}
```
