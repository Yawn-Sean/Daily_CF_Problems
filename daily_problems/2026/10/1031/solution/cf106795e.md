**提示 1：** $M$ 需要满足什么条件？直接分别考虑即可。

相当于 $t_ir\equiv c_i\pmod M$ ，所以 $t_ir-c_i$ 关于 $M$ 同余，于是任意两个作差都是 $M$ 的倍数。（事实上只要每一项减去第一项就行，只要这些满足条件，则任意两个都同余了）

所以只需作差求最大公约数，则 $M$ 必须是其约数。

同时 $M$ 需要比任何一个 $c_i$ 大，因为 $c_i$ 本质上是余数。

所以我们只需找最大公约数的最小的比 $\max c_i$ 大的因子即可。我们枚举较小的因子，即可快速找到所有的因子。

时间复杂度为 $\mathcal{O}(n+\sqrt{rM})$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n, r = MII()
    
    t, c = MII()
    
    g = 0
    mx = c
    
    for _ in range(n - 1):
        nt, nc = MII()
        
        g = math.gcd(g, (nt - t) * r - (nc - c))
        mx = max(mx, nc)
    
    if g == 0: print(mx + 1)
    else:
        ans = inf
        for i in range(1, 10 ** 6 + 5):
            if g % i == 0:
                if i > mx: ans = fmin(ans, i)
                if g // i > mx: ans = fmin(ans, g // i)
        
        print(ans if ans < inf else -1)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, r;
	cin >> n >> r;

	int t, c;
	cin >> t >> c;

	long long g = 0;
	int mx = c;

	for (int i = 0; i < n - 1; i ++) {
		int nt, nc;
		cin >> nt >> nc;

		g = gcd(g, abs(1ll * (nt - t) * r - (nc - c)));
		mx = max(mx, nc);
	}

	if (!g) cout << mx + 1;
	else {
		long long inf = 1e18;
		long long ans = inf;

		for (long long i = 1; i <= 1'000'005; i ++) {
			if (g % i == 0) {
				if (i > mx) ans = min(ans, i);
				if (g / i > mx) ans = min(ans, g / i);
			}
		}

		cout << (ans < inf ? ans : -1);
	}

	return 0;
}
```
