**提示 1：** 实际上，一旦你能操作，你几乎总能一直持续下去……

**提示 2：** 最终状态？

先看提示 1 。

首先，我们判断当前字符串能否进行操作，如果不能，直接输出 $n$ 。

否则，几乎总能不断进行操作。为啥呢？

- 如果此时只有一段相同字符——我们操作最边缘，这样操作后如果长度 >= 3 ，我们仍然能继续操作。

- 如果至少有两段相同字符——我们操作某两段相邻的边界部分（ $VVG$ / $GGV$ 一类），这样操作后仍然能保证下一个字符串能操作。

在这种情况下，字符串可以不断缩短，除非长度小于等于 $2$ 。

那答案到底是 $1$ 还是 $2$ 呢？

考虑不变量。将 $G$ 替换为 $1$ ， $V$ 替换为 $2$ ，发现操作不改变整个序列的和关于 $3$ 的取模。

所以计算这个数，如果是 $0$ ，则答案是 $2$ ，否则答案是 $1$ 。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n = II()
    s = I()
    
    if all(s[i] != s[i - 1] for i in range(1, n)): print(n)
    else:
        cur = 0
        
        for x in s:
            if x == 'G': cur += 1
            else: cur += 2
            cur %= 3
        
        print(1 if cur else 2)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	string s;

	cin >> n >> s;

	bool flg = false;

	for (int i = 1; i < n; i ++) flg |= (s[i] == s[i - 1]);

	if (!flg) cout << n;
	else {
		int cur = 0;

		for (auto &c: s) {
			if (c == 'G') cur += 1;
			else cur += 2;
		}

		cout << (cur % 3 == 0 ? 2 : 1);
	}

	return 0;
}
```
