**提示 1：** 叶子——越来越深往下走就行。

不妨以 $1$ 为根，找一个叶子。一开始定为 $2$ 。

接下来，如果 $2$ 不是叶子，应该往哪里走呢？应该往 $2$ 子树的更深处走——不然你也不知道是不是更接近叶子了。

所以不断查询当前认为是叶子结点的点是否在 $1$ 到新结点的路径上，如果是，则叶子结点更新为新节点。即对于 $i=3,\dots,n$ 查询 $1,leaf,i$ ，并借此不断更新 $leaf$ 。

查询次数为 $n-2$ 次。

这题测试样例较弱。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    leaf = 2
    
    for i in range(3, n + 1):
        print('?', 1, leaf, i, flush=True)
        if II(): leaf = i
    
    print('!', leaf)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	int leaf = 2;

	for (int i = 3; i <= n; i ++) {
		cout << "? " << 1 << ' ' << leaf << ' ' << i << endl;
		int x; cin >> x;
		if (x) leaf = i;
	}

	cout << "! " << leaf;

	return 0;
}
```
