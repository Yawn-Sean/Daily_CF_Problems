**提示 1：** 答案最大长度是多少？

**提示 2：** 利用前面的结果构造。

选取 $i$ 长度时，不同的方案数是 $2^i$ ，所以最大长度不过是 $2^1+2^2+\dots+2^n=2^{n+1}-2$ 。

我们只要能构造就一定是最优的了。

直接构造肯定比较难，考虑基于前一轮的构造。

前一轮的构造长度乘以 $2$ 之后加两个元素就等于新的序列长度。而出现 $2$ 次的元素就只有 $1$ 。

所以我们考虑用 $x-1$ 的答案每一项加一，得到 $A(x-1)$ ，再用 $A(x-1)+[1]+A(x-1)+[1]$ 得到 $x$ 的答案。容易验证这个做法是对的，两个 $1$ 相对而言调整了 $1$ 元素的状态。

主要思路来源是用前一轮的构造。

时间复杂度为 $\mathcal{O}(2^n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    
    def solve(n):
        if n == 0: return []
        tmp = [x + 1 for x in solve(n - 1)] + [1]
        return tmp * 2
    
    ans = solve(n)
    
    print(len(ans))
    print(' '.join(map(str, ans)))
```

C++ 做法如下——

```cpp []
int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	cout << (1 << n + 1) - 2 << '\n';

	auto solve = [&] (auto &self, int x) -> void {
		if (x > n) return ;
		self(self, x + 1);
		cout << x << ' ';
		self(self, x + 1);
		cout << x << ' ';
	};

	solve(solve, 1);

	return 0;
}
```
