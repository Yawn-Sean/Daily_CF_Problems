**提示 1：** 先确定 $\max C_i$ 再凑和。

首先 $\max C_i\times(1+2+\dots+K)$ 至少应该大于等于 $N$ ，所以我们先找到满足条件的最小的 $\max C_i$ 。

接下来会多出来一个小于 $\frac{K(K+1)}{2}$ 的数，我们把多出来的这部分去掉（也可以直接凑 $N$ ，都行）。

这里相当于物品权值特别稠密的背包，贪心是对的（因为小的数总能补足）。从 $K$ 到 $1$ 依次来凑就好。注意数量不能超过 $\max C_i$ 。

时间复杂度为 $\mathcal{O}(k)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, k = MII()
    
    v = k * (k + 1) // 2
    mx = (n + v - 1) // v
    
    ans = [mx] * k
    resid = mx * v - n
    
    for i in range(k - 1, -1, -1):
        x = fmin(resid // (i + 1), mx)
        ans[i] -= x
        resid -= (i + 1) * x
    
    print(' '.join(map(str, ans)))

```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	long long n, k;
	cin >> n >> k;

	long long total = k * (k + 1) / 2;
	long long base = (n - 1) / total + 1;

	vector<long long> ans(k, base);
	long long resid = base * total - n;

	for (int i = k - 1; i >= 0; i --) {
		long long v = min(base, resid / (i + 1));
		ans[i] -= v;
		resid -= (i + 1) * v;
	}

	for (int i = 0; i < k; i ++) cout << ans[i] << " \n"[i == k - 1];

	return 0;
}
```
