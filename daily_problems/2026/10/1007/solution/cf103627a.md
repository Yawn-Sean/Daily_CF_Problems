**提示 1：** 简化下 $\max(u_x+v_x,u_y+v_y)$ 的判断。

**提示 2：** 如何让上面这件事儿方便进行合并？

$\max(u_x+v_x,u_y+v_y)$ 取哪一项，取决于 $u_x+v_x, u_y+v_y$ 的大小关系。

$u_x+v_x\lt u_y+v_y$ 等价于 $u_x-u_y\lt v_y-v_x$ 。

这两个式子形式还是很相像的，且各自取自一个集合。

为了减少这个判断以简化最优化的过程，我们按照 $U$ 中的元素的 $u_x-u_y$ 和 $V$ 中元素的 $v_y-v_x$ 升序排序。

这样，我们就去掉了这里的 $\max$ ，只需解决一个 $\min$ 的问题。在上述排序下，要么取前面的元素的 $u_x$ 加上后面的元素的 $v_x$ ，要么取前面的元素的 $v_y$ 加上后面的元素的 $u_y$ 。

这件事儿就可以用线段树维护了。每个点维护区间的最优答案，区间最小的 $u_x,u_y,v_x,v_y$ 。左右子树的合并先合并答案，再看上述 $u_x,v_x$ 及 $v_y,u_x$ 的和也合并进答案，最小值的合并是明显的。

时间复杂度为 $\mathcal{O}(q\log q)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    q = II()
    
    queries = []
    tmp = []
    
    for _ in range(q):
        t, s, x, y = MII()
        queries.append((t, s, x, y))
        diff = x - y if s == 1 else y - x
        tmp.append((diff, s, x, y))
    
    tmp.sort()
    
    cnt = [0] * q
    
    def e():
        return (inf, inf, inf, inf, inf)
    
    def op(x, y):
        return (fmin(fmin(x[0], y[0]), fmin(x[2] + y[4], x[3] + y[1])), fmin(x[1], y[1]), fmin(x[2], y[2]), fmin(x[3], y[3]), fmin(x[4], y[4]))
    
    seg = SegTree(op, e(), q)
    outs = []
    
    for t, s, x, y in queries:
        diff = x - y if s == 1 else y - x
        p = bisect.bisect_left(tmp, (diff, s, x, y))
        if t == 1:
            if cnt[p] == 0:
                if s == 1: seg.set(p, (inf, x, y, inf, inf))
                else: seg.set(p, (inf, inf, inf, x, y))
            cnt[p] += 1
        else:
            cnt[p] -= 1
            if cnt[p] == 0:
                seg.set(p, (inf, inf, inf, inf, inf))
        
        ans = seg.all_prod()[0]
        outs.append(ans if ans < inf else -1)
    
    print('\n'.join(map(str, outs)))

```

C++ 做法如下——

```cpp []
typedef array<int, 5> node;

const int inf = 1e9;

node e() {return {inf, inf, inf, inf, inf};}

node op(node x, node y) {
	return {min({x[0], y[0], x[2] + y[4], x[3] + y[1]}), min(x[1], y[1]), min(x[2], y[2]), min(x[3], y[3]), min(x[4], y[4])};
}

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int q;
	cin >> q;

	vector<array<int, 4>> queries, pts;

	for (int i = 0; i < q; i ++) {
		int t, s, x, y;
		cin >> t >> s >> x >> y;
		queries.push_back({t, s, x, y});
		int diff = (s == 1 ? x - y : y - x);
		pts.push_back({diff, s, x, y});
	}

	sort(pts.begin(), pts.end());

	vector<int> cnt(q);

	atcoder::segtree<node, op, e> seg(q);

	for (auto &[t, s, x, y]: queries) {
		int diff = (s == 1 ? x - y : y - x);
		array<int, 4> tmp = {diff, s, x, y};
		int p = lower_bound(pts.begin(), pts.end(), tmp) - pts.begin();
		if (t == 1) {
			if (cnt[p] == 0) {
				if (s == 1) seg.set(p, {inf, x, y, inf, inf});
				else seg.set(p, {inf, inf, inf, x, y});
			}
			cnt[p] ++;
		}
		else {
			cnt[p] --;
			if (cnt[p] == 0) seg.set(p, e());
		}

		int ans = seg.all_prod()[0];
		cout << (ans < inf ? ans : -1) << '\n';
	}

	return 0;
}
```
