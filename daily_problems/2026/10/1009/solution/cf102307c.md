**提示 1：** 求 LCS ，这个 DP 怎么做？

**提示 2：** 需要维护完整的信息吗？

本题就是要求最长公共子序列的长度至少是 $0.99n$ 。

如何求最长公共子序列呢？用 $dp[i][j]$ 表示第一个字符串的前 $i$ 项和第二个字符串的前 $j$ 项形成的最长公共子序列长度。

则 $dp[i][j]=\max(dp[i-1][j], dp[i][j-1], dp[i-1][j-1] + (s_1[i]=s_2[j]))$ 。

直接这么做，复杂度是 $\mathcal{O}(n^2)$ 的。

这题的特点是，判断最长公共子序列是否长度足够长，所以很多状态其实是不必要的。

比如说，如果 $|x-y|\gt 0.01n$ ，则此时已经有超过 $0.01n$ 的位置没有匹配上，此时已经不构成答案。

综上，只需维护 $|x-y|\leq 0.01n$ 部分的状态即可。注意你不能开 $\mathcal{O}(n^2)$ 的空间，可以滚动数组实现。

时间复杂度为 $\mathcal{O}(n^2(1-p))$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    s1 = [ord(c) for c in I()]
    s2 = [ord(c) for c in I()]
    
    n = len(s1)
    bound = n // 100
    
    dp = [0] * (n + 1)
    
    for i in range(n):
        l = fmax(0, i - bound)
        r = fmin(n - 1, i + bound)
        
        for j in range(r, l - 1, -1):
            if s1[i] == s2[j]:
                dp[j + 1] = dp[j] + 1
        
        for j in range(l, r + 1):
            dp[j + 1] = fmax(dp[j + 1], dp[j])
    
    print('Long lost brothers D:' if dp[n] >= n - bound else 'Not brothers :(')
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	string s1, s2;
	cin >> s1 >> s2;

	int n = s1.size(), bound = n / 100;

	vector<int> dp(n + 1, 0);

	for (int i = 0; i < n; i ++) {
		int l = max(0, i - bound), r = min(n - 1, i + bound);

		for (int j = r; j >= l; j --) {
			if (s1[i] == s2[j]) {
				dp[j + 1] = dp[j] + 1;
			}
		}

		for (int j = l; j <= r; j ++) {
			dp[j + 1] = max(dp[j + 1], dp[j]);
		}
	}

	cout << (dp[n] >= n - bound ? "Long lost brothers D:" : "Not brothers :(");

	return 0;
}
```
