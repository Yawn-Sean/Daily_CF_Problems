**提示 1：** 直接按照位置考虑是不方便的，考虑按照值考虑。则交换操作意味着什么？

考虑到第 $i$ 个位置的最优解 $dp_i$ 。

如果我们顺序遍历，则我们需要往前两位的 DP 结果，有点混乱。但如果我们按照值考虑就简单多了：

我们相当于下标是递增 / 减去 $1$ 的，求最长的子序列。注意不能连续两次下标减 $1$ 。

这件事可以 DP 完成。从数值小的下标遍历到数值大的下标，并用 $dp_0,dp_1$ 分别标记最后一次下标是否是递减的。

则 $dp_0$ 应当用更小的下标的各种 $dp$ 结果的最大值加一更新 $dp_1$ 直接用下一个下标进行尝试更新即可。这里要更新并查询前缀最大值，所以使用树状数组就完事了。

时间复杂度为 $\mathcal{O}(n\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        nums = LII()
        
        pos = [0] * (n + 1)
        for i in range(n):
            pos[nums[i]] = i
        
        dp0 = [0] * n
        
        seg = SegTree(fmax, 0, n)
        
        for i in range(1, n + 1):
            p = pos[i]
            
            dp0[p] = seg.prod(0, p) + 1
            
            v = dp0[p]
            if p + 1 < n and nums[p] > nums[p + 1]:
                v = fmax(v, dp0[p + 1] + 1)
            
            seg.set(p, v)
        
        outs.append(f'{seg.all_prod()}')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int op(int x, int y) {return max(x, y);}

int e() {return 0;}

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n;
		cin >> n;

		vector<int> nums(n), pos(n + 1);

		for (int i = 0; i < n; i ++) {
			cin >> nums[i];
			pos[nums[i]] = i;
		}

		vector<int> dp0(n, 0);
		atcoder::segtree<int, op, e> seg(n);

		for (int i = 1; i <= n; i ++) {
			int p = pos[i];
			dp0[p] = seg.prod(0, p) + 1;
			
			int v = dp0[p];
			if (p + 1 < n && nums[p] > nums[p + 1]) v = max(v, dp0[p + 1] + 1);
			seg.set(p, v);
		}

		cout << seg.all_prod() << '\n';
	}

	return 0;
}
```
