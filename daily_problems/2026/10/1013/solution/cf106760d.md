**提示 1：** 找到必要的边，它们够用了吗？

首先，距离为 $1,2$ 的点在新图中的距离仍然是 $1$ ，所以这些边必须留下。

这些边就够了。因为原来的最短路一定可以通过两步并作一步走，在 $\lceil d/2\rceil$ 步后走到终点。

同时，在新图中距离为 $x$ 的点，在原图中的最短路长度不会超过 $2x$ ，因为最多只能将距离砍半。

综上，一定恰好是 $\lceil d/2\rceil$ 。

时间复杂度为 $\mathcal{O}(m^2)$ ，因为相当于要枚举有公共点的两条边。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n, m = MII()
        path = [[] for _ in range(n)]
        
        for _ in range(m):
            u, v = GMI()
            path[u].append(v)
            path[v].append(u)
        
        vis = [[0] * n for _ in range(n)]
        
        for i in range(n):
            for j in path[i]:
                vis[i][j] = 1
            for j1 in path[i]:
                for j2 in path[i]:
                    vis[j1][j2] = 1
        
        out = []
        for i in range(n):
            for j in range(i + 1, n):
                if vis[i][j]:
                    out.append(f'{i + 1} {j + 1}')
        
        outs.append(f'{len(out)}')
        outs.extend(out)
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n, m;
		cin >> n >> m;

		vector<vector<int>> path(n);

		while (m --) {
			int u, v;
			cin >> u >> v;
			u --, v --;
			path[u].emplace_back(v);
			path[v].emplace_back(u);
		}

		vector<vector<int>> vis(n, vector<int>(n, 0));

		for (int u = 0; u < n; u ++) {
			for (auto &v: path[u]) vis[u][v] = 1;
			for (auto &v1: path[u]) {
				for (auto &v2: path[u]) {
					vis[v1][v2] = 1;
				}
			}
		}

		vector<pair<int, int>> ans;
		for (int i = 0; i < n; i ++) {
			for (int j = i + 1; j < n; j ++) {
				if (vis[i][j]) ans.emplace_back(i, j);
			}
		}

		cout << ans.size() << '\n';
		for (auto &[x, y]: ans) cout << x + 1 << ' ' << y + 1 << '\n';
	}

	return 0;
}
```
