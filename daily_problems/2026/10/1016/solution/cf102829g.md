**提示 1：** 一个子数组就是个朴素的背包问题。

**提示 2：** 子数组之间的重合会使得整体更好算。

如果只有一个子数组就求解一个背包的方案数问题就行，如果不会可以自行搜索。

那这里每个子数组都要做怎么办呢？

依旧使用原问题，就是 $1,-1$ 赋权，使得数组和是 $0$ 。则不同子数组的差别无非是开始的位置和结束的位置不一样。

想下对应的逻辑：开始时，加入物品；结束时，统计方案。

所以我们进行如下步骤就行：

- 遍历 $i=1\sim n$ 。对于每一个 $i$ 执行以下操作——

- 对于当前的 $dp$ 结果，从 $v$ 状态，转移到 $v+nums[i], v-nums[i]$ 。

- 计入当前位置开始的子数组，所以直接插入 $nums[i], -nums[i]$ 两个状态。

- 统计当前的 $0$ 状态的总方案数。最后对这个数值加总。

这样每个子数组的各个方案都被统计过了。

时间复杂度为 $\mathcal{O}(nM)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    
    ans = 0
    
    M = 10 ** 4
    mod = 10 ** 9 + 7
    
    dp = [0] * (M + 1)
    ndp = [0] * (M + 1)
    
    for i in range(n):
        x = nums[i]
        dp[M // 2] += 1
        
        for j in range(M + 1):
            if j + x <= M: ndp[j + x] += dp[j]
            if j - x >= 0: ndp[j - x] += dp[j]
        
        for j in range(M + 1):
            dp[j] = ndp[j] % mod
            ndp[j] = 0
        
        ans += dp[M // 2]
    
    print(ans % mod)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, mod = 1e9 + 7, M = 1e4;
	vector<int> dp(M + 1, 0), ndp(M + 1, 0);

	cin >> n;

	int ans = 0;

	while (n --) {
		int x;
		cin >> x;

		dp[M / 2] += 1;

		for (int i = 0; i <= M; i ++) {
			if (i >= x) ndp[i - x] += dp[i];
			if (i + x <= M) ndp[i + x] += dp[i];
		}

		for (int i = 0; i <= M; i ++) {
			dp[i] = ndp[i] % mod;
			ndp[i] = 0;
		}

		ans = (ans + dp[M / 2]) % mod;
	}

	cout << ans;

	return 0;
}
```
