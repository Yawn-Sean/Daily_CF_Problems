**提示 2：** 枚举终点，求和式化简。

因为距离不超过 $\sqrt{2}$ ，因此只能恰好是 $1$ 。同时只能往朝 $(0,0)$ 的两个方向之一走。

比方把点映射到第一象限，这并不影响答案。当最终到达的位置是 $(i,j)$ 时，方案数是 $x-i$ 次向左和 $y-j$ 次向下操作的组合，也就是 $\binom{x-i+y-j}{x-i}$ 种。 $x-i$ 取遍 $0\sim x$ 数值， $y-j$ 取遍 $0\sim y$ 数值。

于是，总方案数是 $\sum\limits_{i=0}^x\sum\limits_{j=0}^y\binom{i+j}{i}$ 。

而 $\sum\limits_{j=0}^y\binom{i+j}{i}=\sum\limits_{j=0}^y\left(\binom{i+j+1}{i+1}-\binom{i+j}{i+1}\right)=\binom{i+y+1}{i+1}-\binom{i}{i+1}=\binom{i+y+1}{i+1}$ 。

原式就等于 $\sum\limits_{i=0}^x\binom{i+y+1}{i+1}=\sum\limits_{i=0}^x\binom{i+y+1}{y}=\sum\limits_{i=0}^x\left(\binom{i+y+2}{y+1}-\binom{i+y+1}{y+1}\right)=\binom{x+y+2}{y+1}-\binom{y+1}{y+1}=\binom{x+y+2}{y+1}-1$ 。

这里用到的重要恒等式（就是那步拆成两个和的一步）就是 $\binom{a}{b}=\binom{a-1}{b}+\binom{a-1}{b-1}$ ，可以理解为从 $a$ 个物品里取 $b$ 个的方案数。左边显然等于它，右边：我们枚举第一个物品要不要，如果要，剩余 $a-1$ 个物品里选 $b-1$ 个，方案数是 $\binom{a-1}{b-1}$ ，如果不要，剩余 $a-1$ 个物品里选 $b$ 个，方案数是 $\binom{a-1}{b}$ 。同一个方案数，两种计数结果相同。

你也可以用通分等手段证明。

时间复杂度为 $\mathcal{O}(M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    mod = 10 ** 9 + 7
    f = Factorial(2 * 10 ** 6 + 5, mod)
    
    t = II()
    outs = []
    
    for _ in range(t):
        x, y = MII()
        x = abs(x) + 1
        y = abs(y) + 1
        outs.append(f.combi(x + y, x) - 1)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int M = 2e6 + 5, mod = 1e9 + 7;
	vector<int> f(M), g(M);

	f[0] = 1;
	for (int i = 1; i < M; i ++) f[i] = 1ll * i * f[i - 1] % mod;
	g[M - 1] = quickPow(f[M - 1], mod - 2, mod);
	for (int i = M - 1; i >= 1; i --) g[i - 1] = 1ll * i * g[i] % mod;

	int t;
	cin >> t;

	while (t --) {
		int x, y;
		cin >> x >> y;
		x = abs(x) + 1;
		y = abs(y) + 1;
		cout << 1ll * f[x + y] * g[x] % mod * g[y] % mod - 1 << '\n';
	}

	return 0;
}
```
