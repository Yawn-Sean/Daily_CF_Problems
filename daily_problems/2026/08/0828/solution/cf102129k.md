**提示 1：** 本题的本质求值是什么？

如果把最后的表达式写成 $a_1±a_2±\dots±a_n$ ，则可以发现对于 $a_i\ (i\geq 3)$ ，其前面是加号和减号的概率是完全一致的，因为对于一个操作序列，你可以找到一一对应的序列，使得后面的符号完全反转（即把对 $a_1,a_2$ 操作前面的操作和后面的操作交换即可）。

于是后面的贡献是 $0$ ，输出 $a_1-a_2$ 即可。注意本题需要取模，不要输出负数。

时间复杂度为 $\mathcal{O}(1)$ ，因为你甚至不需要读入整个数组。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    mod = 10 ** 9 + 7
    
    print((nums[0] - nums[1] + mod) % mod)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, x1, x2, mod = 1e9 + 7;
	cin >> n >> x1 >> x2;
	cout << (x1 - x2 + mod) % mod;

	return 0;
}
```
