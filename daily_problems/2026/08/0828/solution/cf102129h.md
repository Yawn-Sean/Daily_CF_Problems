**提示 1：** 写成 DP 的形式。

假设 $dp[x]$ 表示 $x$ 轮后的，要抛骰子的人的最优结果。

假设 $x+1$ 轮扔出了 $k$ ，则最优选择是 $\max(k-dp[x],dp[x]-k)$ 分别表示是否换手。

所以 $dp[x+1]=\frac{1}{m}\sum\limits_{k=1}^m |dp[x]-k|$ 。

两侧同时关于 $x$ 取趋于无穷的极限，设 $dp[x]$ 极限是 $V$ ，即有：

$mV=\sum\limits_{k=1}^m |V-k|$

可以考虑 $V$ 和 $V$ 下取整是大致同个量级的。因此可以将右侧关于 $\lfloor V\rfloor$ 展开。有：

$mV=\sum\limits_{k=1}^{\lfloor V\rfloor}(V-k)+\sum\limits_{k=\lfloor V\rfloor+1}^m(k-V)$

两个等差数列都可以求出来。然后你可以利用 $V$ 和 $\lfloor V\rfloor$ 很接近，用二次方程估计出 $\lfloor V\rfloor$ 的数值，最后求出 $V$ 进行验证。

时间复杂度为 $\mathcal{O}(\log M)$ ，因为你不得不求逆元。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    mod = 10 ** 9 + 7
    
    for _ in range(t):
        m = II()
        v = (2 * m + 1 - math.isqrt(2 * m * m + 2 * m + 1)) // 2
        
        for k in range(v - 1, v + 1):
            if k == m: continue
            A = m * m + m - 2 * (k * k + k)
            B = 4 * (m - k)
            
            if A // B == k:
                outs.append(A * pow(B, -1, mod) % mod)
                break
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
long long quickPow(long long base, long long power, long long mod) {
	if (power == 0) return 1 % mod;
	long long cur = quickPow(base, power / 2, mod);
	return power & 1 ? base * cur % mod * cur % mod : cur * cur % mod; 
}

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t, mod = 1e9 + 7;
	cin >> t;

	auto sqrt_int = [&] (long long val) -> long long {
		long long l = 0, r = 2e9;
		while (l <= r) {
			long long mid = (l + r) / 2;
			if (mid * mid <= val) l = mid + 1;
			else r = mid - 1;
		}
		return r;
	};

	while (t --) {
		long long m;
		cin >> m;
		long long v = (2 * m + 1 - sqrt_int(2 * m * m + 2 * m + 1)) / 2;

		for (long long k = v - 1; k <= v; k ++) {
			if (k == m) continue;
			long long A = m * m + m - 2 * (k * k + k);
			long long B = 4 * (m - k);
			if (A / B == k) {
				A %= mod;
				B %= mod;
				cout << A * quickPow(B, mod - 2, mod) % mod << '\n';
				break;
			}
		}
	}

	return 0;
}
```
