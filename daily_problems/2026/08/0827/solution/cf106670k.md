**提示 1：** 看看有哪些不同的情况需要考虑。

也就是用行和列使得左上角和右下角连通，即可以用行和列覆盖一条从左上角到右下角的路径。

考虑覆盖 $(1,1),(n,n)$ 的两条线的方向。

- 如果已经不同了，则已经连通了。这两个情况进入备选。

- 否则，不妨设选的是两行（两列的情况是对称的）。接下来要让两行连通，可以有以下方式：

    - 任意选一列。显然选成本最小的一列。

    - 一列都不选，这样你就只能选每一行了。

这样，分类讨论就是完整的了。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        v1 = LII()
        v2 = LII()
        
        outs.append(min(
            v1[0] + v2[n - 1],
            v2[0] + v1[n - 1],
            sum(v1),
            sum(v2),
            v1[0] + v1[n - 1] + min(v2),
            v2[0] + v2[n - 1] + min(v1)
        ))
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n;
		cin >> n;

		vector<long long> v1(n), v2(n);
		long long w1 = 0, w2 = 0;

		for (auto &x: v1) cin >> x, w1 += x;
		for (auto &x: v2) cin >> x, w2 += x;

		long long ans = min(w1, w2);
		ans = min(ans, min(v1[0] + v2[n - 1], v1[n - 1] + v2[0]));
		ans = min(ans, min(
			v1[0] + v1[n - 1] + *min_element(v2.begin(), v2.end()),
			v2[0] + v2[n - 1] + *min_element(v1.begin(), v1.end())
		));

		cout << ans << '\n';
	}

	return 0;
}
```
