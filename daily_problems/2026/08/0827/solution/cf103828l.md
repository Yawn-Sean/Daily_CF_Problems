**提示 1：** 实则可以拆成一维的问题。

**提示 2：** 一维问题可以拆解为范围更小的问题。

首先，我们可以把 $1\sim n, n+1\sim 2n,...$ 分别分配到一行，这样同一行的问题可以同时解决（整体就是每个元素加个 $n$ ，不是等差数列的加了仍然不是等差数列）。

同时，假设 $1\sim n$ 在第一行的排列结果为 $a_1,\dots, a_n$ ，则第 $i$ 行放包含 $a_i\times n$ 的那个序列，这样竖着的第 $i$ 和第 $i+1$ 两项的差恰好是横着的第 $i$ 项和第 $i+1$ 项的差的 $n$ 倍。

更直接地说，如果我们构造出了一行的由 $1\sim n$ 构成的结果 $a_1,\dots, a_n$ ，则第 $i$ 行第 $j$ 列输出 $(a_i-1)\times n+a_j$ 即可。

这样，我们只需考虑一维的问题即可。

如果我们把所有奇数放前面，所有偶数放后面，则前后两段之间无法形成等差数列。

这样我们只需分别处理前面奇数的部分的构造和后面偶数的部分的构造。

而此时我们可以把奇数部分加一除以二，偶数部分除以二，这样就都刚好等价于更小规模的原问题，所以就这么不断分治，直到最终长度为 $1$ 时，输出 $[1]$ 即可。

时间复杂度为 $\mathcal{O}(n^2)$ 。

这题的一维部分在力扣有原题（932）：https://leetcode.cn/problems/beautiful-array/description/。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    def f(x):
        if x == 1: return [0]
        return [2 * v for v in f(x - x // 2)] + [2 * v + 1 for v in f(x // 2)]
    
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        v = f(n)
        
        for i in range(n):
            outs.append(' '.join(str(v[i] * n + v[j] + 1) for j in range(n)))
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	auto f = [&] (auto &self, int n) -> vector<int> {
		if (n == 1) return {0};
		vector<int> ans;
		for (auto &x: self(self, n - n / 2)) ans.emplace_back(2 * x);
		for (auto &x: self(self, n / 2)) ans.emplace_back(2 * x + 1);
		return ans;
	};

	int t;
	cin >> t;

	while (t --) {
		int n;
		cin >> n;

		auto res = f(f, n);

		for (int i = 0; i < n; i ++) {
			for (int j = 0; j < n; j ++) {
				cout << res[i] * n + res[j] + 1 << " \n"[j == n - 1];
			}
		}
	}

	return 0;
}
```
