**提示 1：** 枚举 $r_1$ 。

考虑将整体式子整理成 $(r_1-l_1+1)x+(r_2-l_2+1)y+(l_2-r_1-1)z$ ，也就是匹配前前缀、中间、匹配后缀三段的单位长度权值分别是 $x,z,y$ ，其中前后缀非空。

接下来考虑枚举 $r_1$ ，此时其对应的最优的 $l_1$ 就是这个位置结尾的最长匹配真前缀，可以用 KMP 解决。

如果 $l_2$ 确定了， $r_2$ 显然也取最长的，即从这个位置开始的字符串能匹配的最长的真后缀。

而从大到小枚举 $r_1$ 的过程中，我们可以顺便把大于 $l_2$ 的后缀的左端点也考虑进来。具体而言，假设我们已经考虑了 $l_2\geq L$ 的情况，则 $l_2=L-1$ 时，首先可以由 $l_2\geq L$ 的情况 $+z$ 得到权值，再多考虑上 $L-1$ 的最长匹配长度乘以 $y$ 两者取最大值即可。 

注意前后缀的段需要非空，因此只有匹配长度大于 $0$ 时，才更新最值。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    def prep(p):
        pi = [0] * len(p)
        j = 0
        for i in range(1, len(p)):
            while j != 0 and p[j] != p[i]:
                j = pi[j - 1]
            if p[j] == p[i]:
                j += 1
            pi[i] = j
        return pi
    
    n, x, y, z = MII()
    s = [ord(c) for c in I()]
    
    v1 = prep(s)
    
    s.reverse()
    v2 = prep(s)
    v2.reverse()
    
    ans = 0
    cur = -inf
    
    for i in range(n - 2, -1, -1):
        cur += z
        if v2[i + 1] > 0:
            cur = fmax(cur, y * v2[i + 1])
        if v1[i] > 0:
            ans = fmax(ans, cur + x * v1[i])
    
    print(ans)
```

C++ 做法如下——

```cpp []
template <typename T>
std::vector<int> prep(const T& p) {
	int n = static_cast<int>(p.size());
	std::vector<int> pi(n, 0);
	int j = 0;
	for (int i = 1; i < n; ++i) {
		while (j != 0 && p[j] != p[i]) {
			j = pi[j - 1];
		}
		if (p[j] == p[i]) {
			++j;
		}
		pi[i] = j;
	}
	return pi;
}

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, x, y, z;
	cin >> n >> x >> y >> z;

	string s;
	cin >> s;

	auto v1 = prep(s);

	reverse(s.begin(), s.end());
	auto v2 = prep(s);
	reverse(v2.begin(), v2.end());

	long long ans = 0, cur = -3e18;

	for (int i = n - 2; i >= 0; i --) {
		cur += z;
		if (v2[i + 1] > 0) cur = max(cur, 1ll * y * v2[i + 1]);
		if (v1[i] > 0) ans = max(ans, cur + 1ll * x * v1[i]);
	}

	cout << ans;

	return 0;
}
```
