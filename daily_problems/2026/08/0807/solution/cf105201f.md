**提示 1：** 考虑 Manacher 的过程。有些端点的合并。

**提示 2：** 这些端点的合并是充分的吗？

一个字符串的回文串问题，先考虑 Manacher 算法（当然为了考虑长度为偶数的回文串，你需要在相邻字符之间插入相同的无关字符）。

则每当 Manacher 扩展中心长度的时候，我们在其端点之间连一条边（因为对应的都是回文串，当然建立在端点都是字符的基础上）。

每次这样扩展的时候，新增的边都会遍历到一个尚未经过的下标，所以必然不可能成环。

同时，每个回文串的端点要么是加边的时候出现的，此时已经连通；要么是根据前面对称而来的，因此只要前面的时候那两点连通，则新的两点也已经连通。也就可以归纳法证明，任意一个回文串的端点都已经在同一个连通块内。（因为更短的前缀满足条件可以推出当前前缀满足条件）

综上我们连接的结构是个森林。连通块数量就等于点数减去边数。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    s = [ord(c) for c in I()]
    n = len(s)
    
    tmp = []
    for i in range(n):
        if i: tmp.append(-1)
        tmp.append(s[i])
    
    ans = n
    wing = [0] * (2 * n - 1)
    j = 0
    
    for i in range(2 * n - 1):
        if j + wing[j] >= i:
            wing[i] = fmin(j + wing[j] - i, wing[2 * j - i])
        
        while i - wing[i] - 1 >= 0 and i + wing[i] + 1 < 2 * n - 1 and tmp[i - wing[i] - 1] == tmp[i + wing[i] + 1]:
            wing[i] += 1
            if (i - wing[i]) % 2 == 0:
                ans -= 1
        
        if i + wing[i] > j + wing[j]:
            j = i
    
    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	string s;
	cin >> s;

	int n = s.size();

	string tmp;
	for (int i = 0; i < n; i ++) {
		if (i) tmp += '|';
		tmp += s[i];
	}

	int ans = n, j = 0;
	vector<int> wing(2 * n - 1, 0);

	for (int i = 0; i < 2 * n - 1; i ++) {
		if (j + wing[j] >= i) wing[i] = min(j + wing[j] - i, wing[2 * j - i]);
		while (i - wing[i] - 1 >= 0 && i + wing[i] + 1 < 2 * n - 1 && tmp[i - wing[i] - 1] == tmp[i + wing[i] + 1]) {
			wing[i] ++;
			if ((i - wing[i]) % 2 == 0) ans --;
		}
		if (i + wing[i] > j + wing[j]) j = i;
	}

	cout << ans;

	return 0;
}
```
