**提示 1：** DP，如何转移？

首先，很明显，我们存第 $i$ 个位置结束的子序列的最大权值为 $dp[i]$ ，如何进行状态转移呢？

肯定是考虑前缀的某个位置 $i'$ 转移过来，也就是 $dp[i']+\mathrm{gcd}(nums[i'],nums[i])$ 转移过来。

但 $i'$ 太多了，枚举不过来。所以考虑枚举 $\mathrm{gcd}(nums[i'],nums[i])$ 。

这个数值只可能是 $nums[i]$ 的因子。我们考虑枚举因子 $g$ ，其作为因子最晚出现在 $i'$ ，则我们只将 $nums[i']+g$ 转移到 $nums[i]$ ，如果 $i-i'\leq k$ 。

为啥这样做就够了呢？

首先，从 DP 数值的角度，同一个最大公约数肯定取下标越大的越好，因为下标更小的子序列可以直接加上这个更大的下标对应的元素，对应的子序列的总数值最大。

同时越靠近 $i$ 的位置，越容易满足 $i-i'\leq k$ 。

而即使 $\mathrm{gcd}(nums[i], nums[i'])\gt g$ ，这个 DP 结果也一定大于了最大公约数恰好等于 $g$ 的结果，因为可以在恰好等于 $g$ 的那个子序列末尾加上 $nums[i']$ ，所以选那个子序列一定不优。同时每个最大公约数都被考虑过了，因此覆盖了所有情况。

时间复杂度为 $\mathcal{O}(\sum d(a_i))$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    M = 4 * 10 ** 5 + 5
    
    pr = list(range(M))
    
    for i in range(2, M):
        if pr[i] == i:
            for j in range(i, M, i):
                pr[j] = i
    
    def factors(x):
        ans = [1]
        
        while x > 1:
            p = pr[x]
            c = 0
            
            while x % p == 0:
                x //= p
                c += 1
            
            l = len(ans)
            
            for _ in range(l * c):
                ans.append(ans[-l] * p)
        
        return ans
    
    last_pos = [-inf] * M
    
    for _ in range(t):
        n, k = MII()
        nums = LII()
        
        dp = [0] * n
        
        for i in range(n):
            for f in factors(nums[i]):
                if i - last_pos[f] <= k:
                    dp[i] = fmax(dp[i], dp[last_pos[f]] + f)
                last_pos[f] = i
        
        outs.append(max(dp))
        
        for i in range(M):
            last_pos[i] = -inf
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int M = 4e5 + 5;
	vector<int> pr(M);

	iota(pr.begin(), pr.end(), 0);
	for (int i = 2; i < M; i ++) {
		if (pr[i] == i) {
			for (int j = i; j < M; j += i) {
				pr[j] = i;
			}
		}
	}

	auto factors = [&] (int x) -> vector<int> {
		vector<int> ans = {1};
		while (x > 1) {
			int p = pr[x], c = 0;
			while (x % p == 0) x /= p, c ++;
			int l = ans.size();
			for (int i = 0; i < l * c; i ++) ans.emplace_back(ans.end()[-l] * p);
		}
		return ans;
	};

	int inf = 1e9;
	vector<int> saved_pos(M, -inf);

	int t;
	cin >> t;

	while (t --) {
		int n, k;
		cin >> n >> k;

		vector<long long> dp(n, 0);
		long long ans = 0;

		for (int i = 0; i < n; i ++) {
			int x;
			cin >> x;

			for (auto &f: factors(x)) {
				if (i - saved_pos[f] <= k) dp[i] = max(dp[i], dp[saved_pos[f]] + f);
				saved_pos[f] = i;
			}

			ans = max(ans, dp[i]);
		}

		for (int i = 0; i < M; i ++) saved_pos[i] = -inf;

		cout << ans << '\n';
	}

	return 0;
}
```
