**提示 1：** 枚举 $\min(x)$ 。我们最多选多少点？

从大到小枚举 $\min(x)$ ，这样我们考虑的点集就是逐渐增大的。

我们最多能取多少点呢？我们考虑下当前点集的形态。

只可能由一些链 / 环组成。

一条有 $l$ 个点的链最多取 $\lceil\frac{l}{2}\rceil$ 个点，而一个有 $l$ 个点的环最多取 $\lfloor\frac{l}{2}\rfloor$ 个点。

而这些信息在新增点时，用并查集都很容易维护（只要你顺便记录下当前每个点集对应的连通块的大小就够了，是否成环也可以很方便做出）。

时间复杂度为 $\mathcal{O}(n\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    
    p = LGMI()
    path = [[] for _ in range(n)]
    
    for i in range(n):
        path[p[i]].append(i)
        path[i].append(p[i])
    
    ans = 0
    cur = 0
    
    uf = UnionFind(n)
    vis = [0] * n
    
    for i in sorted(range(n), key=lambda x: -nums[x]):
        vis[i] = 1
        cur += 1
        
        for j in path[i]:
            if vis[j]:
                if uf.find(i) != uf.find(j):
                    cur -= (uf.getSize(i) + 1) // 2
                    cur -= (uf.getSize(j) + 1) // 2
                    uf.merge(i, j)
                    cur += (uf.getSize(i) + 1) // 2
                else:
                    cur -= uf.getSize(i) % 2
        
        ans = fmax(ans, cur * nums[i])
    
    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	vector<int> nums(n);
	for (auto &x: nums) cin >> x;

	vector<vector<int>> path(n);
	for (int i = 0; i < n; i ++) {
		int x;
		cin >> x;
		x --;
		path[i].emplace_back(x);
		path[x].emplace_back(i);
	}

	long long ans = 0;
	int cur = 0;

	atcoder::dsu uf(n);
	vector<int> vis(n, 0), order(n);

	iota(order.begin(), order.end(), 0);
	sort(order.begin(), order.end(), [&] (int i, int j) {return nums[i] > nums[j];});

	for (auto &i: order) {
		vis[i] = 1;
		cur ++;

		for (auto &j: path[i]) {
			if (vis[j]) {
				if (uf.leader(i) != uf.leader(j)) {
					cur -= (uf.size(i) + 1) / 2;
					cur -= (uf.size(j) + 1) / 2;
					uf.merge(i, j);
					cur += (uf.size(i) + 1) / 2;
				}
				else cur -= uf.size(i) % 2;
			}
		}

		ans = max(ans, 1ll * cur * nums[i]);
	}

	cout << ans;

	return 0;
}
```
