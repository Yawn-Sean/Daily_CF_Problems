**提示 2：** 更新的总复杂度？

首先，这里的 $step$ 可以变为 $g=\mathrm{gcd}(step, n)$ ，这两者在 $\bmod n$ 意义下遍历的位置是等价的。

同时 $first-1$ 也可以理解为 $(first-1)\bmod g$ 。

这样我们就得到了一系列需要更新的 $g$ 以及对应的取模结果的位置。

我们遍历不同的 $g$ ，其数量不超过 $n$ 的因子数。接下来，遍历一遍 $n$ 个不同的位置，更新上对应取模结果位置需要更新的总数值即可。

时间复杂度为 $\mathcal{O}(nd(n)+q\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, q = MII()
    updates = [[] for _ in range(n + 1)]
    
    for _ in range(q):
        f, s, c = MII()
        s = math.gcd(s, n)
        if len(updates[s]) == 0:
            updates[s] = [0] * s
        updates[s][(f - 1) % s] += c
    
    ans = [0] * n
    
    for i in range(n + 1):
        if updates[i]:
            for j in range(i):
                for k in range(j, n, i):
                    ans[k] += updates[i][j]
    
    print(ans.index(max(ans)) + 1)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, q;
	cin >> n >> q;

	vector<vector<long long>> updates(n + 1);

	while (q --) {
		int f, s, c;
		cin >> f >> s >> c;

		s = gcd(s, n);
		if (updates[s].empty())
			updates[s] = vector<long long>(s, 0);
		updates[s][(f - 1) % s] += c;
	}

	vector<long long> ans(n, 0);

	for (int i = 0; i <= n; i ++) {
		if (!updates[i].empty()) {
			for (int j = 0; j < i; j ++) {
				for (int k = j; k < n; k += i) {
					ans[k] += updates[i][j];
				}
			}
		}
	}

	cout << max_element(ans.begin(), ans.end()) - ans.begin() + 1;

	return 0;
}
```
