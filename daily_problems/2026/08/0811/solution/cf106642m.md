**提示 2：** 重复统计？

分类讨论：

- $a_i-a_j=b_i-b_j$ 可以推出 $a_i-b_i=a_j-b_j$ 。

- $a_i-a_j=-(b_i-b_j)$ 可以推出 $a_i+b_i=a_j+b_j$ 。

因此，我们只需统计满足 $a_i-b_i=a_j-b_j$ 或 $a_i+b_i=a_j+b_j$ 的元素对数量即可。

分别统计满足其中一个条件的元素对数量。这样会多算两个都满足的，两个都满足的情况下 $a_i=a_j,b_i=b_j$ ，再统计一下这个元素对数量减掉就好。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    rnd = random.getrandbits(30)
    
    for _ in range(t):
        n = II()
        v1 = LII()
        v2 = LII()
        
        ans = 0
        
        cnt = Counter()
        
        for i in range(n):
            ans += cnt[(v1[i] - v2[i]) ^ rnd]
            cnt[(v1[i] - v2[i]) ^ rnd] += 1
        
        cnt = Counter()
        
        for i in range(n):
            ans += cnt[(v1[i] + v2[i]) ^ rnd]
            cnt[(v1[i] + v2[i]) ^ rnd] += 1
        
        cnt = Counter()
        
        for i in range(n):
            ans -= cnt[(v1[i], v2[i])]
            cnt[(v1[i], v2[i])] += 1
        
        outs.append(ans)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n;
		cin >> n;

		vector<int> v1(n), v2(n);
		for (auto &x: v1) cin >> x;
		for (auto &x: v2) cin >> x;

		long long ans = 0;

		{
			map<int, int> cnt;
			for (int i = 0; i < n; i ++) {
				ans += cnt[v1[i] - v2[i]];
				cnt[v1[i] - v2[i]] ++;
			}
		}

		{
			map<int, int> cnt;
			for (int i = 0; i < n; i ++) {
				ans += cnt[v1[i] + v2[i]];
				cnt[v1[i] + v2[i]] ++;
			}
		}

		{
			map<pair<int, int>, int> cnt;
			for (int i = 0; i < n; i ++) {
				ans -= cnt[{v1[i], v2[i]}];
				cnt[{v1[i], v2[i]}] ++;
			}
		}

		cout << ans << '\n';
	}

	return 0;
}
```
