**提示 1：** 考虑最适合放另一个球的位置。

**提示 2：** 二分。

考虑最适合放另一个球的位置。如果当前球球心最接近某个长方形的顶点，则另一个球应该贴着另一个角放。

此时半径如何确定呢？可以二分，找和初始圆相切的半径。

当然，新球的半径不能超过 $\min(x,y,z)/2$ ，所以需要跟这个取上界。同时你二分的右端点不能过大，不然的话可能你的球都超过了整个长方形，此时不交没意义。所以直接让二分右端点是 $\min(x,y,z)/2$ 即可。

检查的时候只需判圆心距离是否超过两者半径之和即可。

时间复杂度为 $\mathcal{O}(\log\epsilon^{-1})$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    x, y, z = MII()
    tx, ty, tz = LFI()
    R = LFI()[0]
    
    tx = fmax(tx, x - tx)
    ty = fmax(ty, y - ty)
    tz = fmax(tz, z - tz)
    
    l, r = 0, min(x, y, z) / 2
    
    for _ in range(100):
        mid = (l + r) / 2
        if math.hypot(tx - mid, ty - mid, tz - mid) >= R + mid:
            l = mid
        else:
            r = mid
    
    print((l + r) / 2)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	long double x, y, z, tx, ty, tz, R;
	cin >> x >> y >> z >> tx >> ty >> tz >> R;

	tx = max(tx, x - tx), ty = max(ty, y - ty), tz = max(tz, z - tz);

	long double l = 0, r = min({x, y, z}) / 2;

	for (int i = 0; i < 100; i ++) {
		long double mid = (l + r) / 2;

		if ((tx - mid) * (tx - mid) + (ty - mid) * (ty - mid) + (tz - mid) * (tz - mid) >= (mid + R) * (mid + R)) l = mid;
		else r = mid;
	}

	cout << setprecision(15) << fixed << (l + r) / 2 << endl;

	return 0;
}
```
