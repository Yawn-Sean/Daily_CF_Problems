**提示 1：** 考虑不合法的情况。

**提示 2：** 合法情况，先满足 $k$ 的条件，再把别的填上。

首先，如果 $k\gt\min(r,c)$ ，那么我可以用 $\min(r,c)$ 次操作解决问题，也就一定不合法。

如果 $m\lt k$ ，则显然最多只需要在有士兵的行操作即可，不可能要 $k$ 次，也不合法。

最后，考虑 $k$ 次操作最多能干掉 $k\max(r,c)$ 个人，所以 $m$ 也不能超过这个上界。

那剩余情况如何构造呢？

我们先找一个长度为 $k$ 的对角线。这样就至少需要 $k$ 次操作了。

接下来我们在这几个士兵对应的行 / 列上填，填到 $m$ 个即可。如果 $r$ 更大就竖着填，如果 $c$ 攻打就横着填。

时间复杂度为 $\mathcal{O}(rc)$ 。

可以想想这题的 checker 怎么写。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        r, c, m, k = MII()
        
        if k > fmin(r, c): outs.append('NO')
        elif m < k or m > fmax(r, c) * k: outs.append('NO')
        else:
            grid = [[0] * c for _ in range(r)]
            
            for i in range(k):
                grid[i][i] = 1
                m -= 1
    
            for i in range(k if r < c else r):
                for j in range(k if c < r else c):
                    if m and grid[i][j] == 0:
                        grid[i][j] = 1
                        m -= 1
            
            outs.append('YES')
            outs.append('\n'.join(''.join('.#'[v] for v in x) for x in grid))
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int r, c, m, k;
		cin >> r >> c >> m >> k;

		if (k > min(r, c)) cout << "NO\n";
		else if (m < k || m > 1ll * max(r, c) * k) cout << "NO\n";
		else {
			vector<string> grid(r, string(c, '.'));
			for (int i = 0; i < k; i ++) grid[i][i] = '#', m --;

			for (int i = 0; i < (r < c ? k : r); i ++) {
				for (int j = 0; j < (c < r ? k : c); j ++) {
					if (m && grid[i][j] == '.') {
						grid[i][j] = '#';
						m --;
					}
				}
			}

			cout << "YES\n";
			for (auto &x: grid) cout << x << '\n';
		}
	}

	return 0;
}
```
