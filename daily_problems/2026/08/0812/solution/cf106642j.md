**提示 1：** 枚举右端点。不同段落部分的答案怎么更新？

固定右端点，此时对应的各个数组的最小值形成一个单调栈，单调栈中相邻元素之间就是一段平台的元素。

我们考虑维护这些平台，以及平台上最小值出现奇数次的子数组的个数。

在使用单调栈的过程中，我们先不断 pop，直到栈顶元素不超过当前元素。

如果栈顶元素更小，那么以 $nums[r]$ 为最小值的数组的左端点就只能从栈顶的后一位到当前位，这些数组的最小值都出现奇数次，直接更新即可。

否则，栈顶元素与当前元素相同，设这个位置为 $idx$ ，则可以通过栈内存的信息得到 $idx$ 结尾以 $nums[idx]$ 为最小值且出现偶数次的有 $x$ 个，奇数次的有 $y$ 个。

而此时考虑的子数组右端点为 $r$ ， $r$ 位置相当于对这些数组新增了一个 $nums[idx]$ ，因此，原本出现的次数的奇偶性得互换。同时 $[idx+1,r]$ 为左端点， $r$ 为右端点的子数组也得更新进来。最后这部分全部推回栈上。

在上面更新的过程中，我们可以顺便维护栈中所有平台中长度为奇数的子数组的个数，只需在对栈操作的时候更新即可。每遍历一次 $r$ ，将答案加上这个结果即可。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        nums = LII()
        
        ans = 0
        cur = 0
    
        stk = [(-inf, -1, 0, 0)]
        
        for i in range(n):
            while stk[-1][0] > nums[i]:
                cur -= stk[-1][2]
                stk.pop()
            
            if stk[-1][0] != nums[i]:
                stk.append((nums[i], i, i - stk[-1][1], 0))
            else:
                val, idx, dp1, dp2 = stk.pop()
                cur -= dp1
                stk.append((nums[i], i, dp2 + i - idx, dp1))
            
            cur += stk[-1][2]
            ans += cur
        
        outs.append(ans)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n;
		cin >> n;

		vector<int> nums(n);
		for (auto &x: nums) cin >> x;

		long long ans = 0, cur = 0;
		vector<array<int, 4>> stk;
		stk.push_back({-1, -1, 0, 0});

		for (int i = 0; i < n; i ++) {
			while (stk.back()[0] > nums[i]) {
				cur -= stk.back()[2];
				stk.pop_back();
			}

			if (stk.back()[0] != nums[i]) {
				stk.push_back({nums[i], i, i - stk.back()[1], 0});
			}
			else {
				auto [val, idx, dp1, dp2] = stk.back(); stk.pop_back();
				cur -= dp1;
				stk.push_back({nums[i], i, dp2 + i - idx, dp1});
			}

			cur += stk.back()[2];
			ans += cur;
		}

		cout << ans << '\n';
	}

	return 0;
}
```
