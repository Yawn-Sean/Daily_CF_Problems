**提示 1：** 最短路，为啥可以用？边权如何？实现如何？

考虑整条路径。包含三个部分：从海岸线到第一个伞，从伞到伞（可能很多次），从伞到路边。

第一部分，只要我们知道用的是哪个圆，则相当于求圆内任意一点到直线的距离。分情况：如果有公共点，即圆心到直线的距离不超过半径，这个答案是 $0$ ；否则答案是圆心到直线的距离减去半径。

从伞到路边的过程也是类似的。

中间伞之间的路径，假设有一段是从一个圆到另一个圆，则最优的走法是沿着圆心的连线走。这是因为如果两圆形有公共点，则这部分权值为 $0$ ，否则距离不小于两个圆心的距离减去两个半径，因为圆心之间的距离小于等于圆上两点的距离加上两个半径（两点之间线段最短）。

当然，如果重新规划的路径经过了别的圆，我们就继续优化新的分割出来的路，最后走的一定是圆心之间连线的路。

于是我们得到了一个完全图——所有伞之间的边权完全确定，海到伞、伞到路的边权也确定，在这个稠密图上跑最短路就好。

稠密图使用堆优化的 Dijkstra 会多一个 log 复杂度，不带堆优化可以复杂度更优，实在不清楚可以看后面的代码。

时间复杂度为 $\mathcal{O}(n^2)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, h = MII()
    
    if n == 0: print(h)
    else:
        xs = []
        ys = []
        rs = []
    
        for _ in range(n):
            x, y, r = MII()
            xs.append(x)
            ys.append(y)
            rs.append(r)
    
        dis = [fmax(ys[i] - rs[i], 0) for i in range(n)]
        vis = [0] * n
    
        def f(i, j):
            return math.sqrt((xs[i] - xs[j]) * (xs[i] - xs[j]) + (ys[i] - ys[j]) * (ys[i] - ys[j]))
    
        for _ in range(n):
            chosen = -1
            for idx in range(n):
                if vis[idx] == 0 and (chosen == -1 or dis[idx] < dis[chosen]):
                    chosen = idx
            
            vis[chosen] = 1
            for i in range(n):
                dis[i] = fmin(dis[i], dis[chosen] + fmax(0, f(chosen, i) - rs[chosen] - rs[i]))
    
        ans = min(dis[i] + fmax(0, h - ys[i] - rs[i]) for i in range(n))
        print(f'{ans:.15f}')
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, h;
	cin >> n >> h;

	if (!n) return cout << h, 0;

	vector<array<int, 3>> circles(n);

	for (auto &[x, y, r]: circles) cin >> x >> y >> r;

	vector<long double> dis(n);

	for (int i = 0; i < n; i ++) {
		auto [x, y, r] = circles[i];
		dis[i] = max(0, y - r);
	}

	vector<bool> vis(n, false);

	for (int i = 0; i < n; i ++) {
		int chosen = -1;
		for (int j = 0; j < n; j ++) {
			if (!vis[j] && (chosen == -1 || dis[j] < dis[chosen])) {
				chosen = j;
			}
		}

		vis[chosen] = 1;

		for (int j = 0; j < n; j ++) {
			auto [x1, y1, r1] = circles[chosen];
			auto [x2, y2, r2] = circles[j];
			dis[j] = min(dis[j], dis[chosen] + max((long double)0, hypotl(x1 - x2, y1 - y2) - r1 - r2));
		}
	}

	long double ans = h;

	for (int i = 0; i < n; i ++) {
		auto [x, y, r] = circles[i];
		ans = min(ans, dis[i] + max(0, h - (y + r)));
	}

	cout << fixed << setprecision(15) << ans;

	return 0;
}
```
