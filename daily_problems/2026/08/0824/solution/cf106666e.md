**提示 1：** DP，转移并不多。

考虑某一段结尾是 $i$ 的序列有 $dp[i]$ 个。如何计算它呢？

考虑最后一段的长度，只可能是 $2^0,2^1,2^2,\dots$ ，而这个序列增长很快，所以最后一段的长度总共只有 $\mathcal{O}(\log n)$ 种选择，将对应 $dp[i-len]$ 个方案转移过来就好。

注意 $dp[0]=2$ ，因为开头可以是两种情况的任何一种。

时间复杂度为 $\mathcal{O}(n\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    mod = 10 ** 9 + 7
    
    dp = [0] * (n + 1)
    dp[0] = 2
    
    for i in range(1, n + 1):
        v = 1
        while i >= v:
            dp[i] += dp[i - v]
            v *= 2
        dp[i] %= mod
    
    print(dp[n])
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, mod = 1e9 + 7;
	cin >> n;

	vector<int> dp(n + 1, 0);
	dp[0] = 2;

	for (int i = 1; i <= n; i ++) {
		for (int j = 1; j <= i; j <<= 1) {
			dp[i] = (dp[i] + dp[i - j]) % mod;
		}
	}

	cout << dp[n];

	return 0;
}
```
