**提示 1：** 利用空的槽。

这题给的次数不算多，同时给的空槽很多。

我们可以这样：先把顶部元素在空的槽中依次排开，再堆起来。这样，有 $x$ 个槽的时候，我们就可以把最顶部的 $x$ 个元素全部放到某一个槽里，同时让槽少一个。

利用这个操作，我们可以把 $n$ 个元素排成 $k-1$ 个槽。其中最大值唯一占据一个槽。

此时将最大值转移到目标位置。接下来，我们要将元素从大到小依次放入目标位置，因此应该分别处理大小为 $2,3,\dots,k-1$ 的槽。

当我们处理大小为 $x$ 的槽的时候，我们有 $x-1$ 个空槽，分别可以用来放上面的 $x-1$ 个元素。然后把最大的元素放到目标位置，再把这 $x-1$ 个元素也放过去就行。

这题给的分数不低，主要是写起来实在是有点丑陋。思路上并不是太新奇。

时间复杂度为 $\mathcal{O}(k^2)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    k, s, e = MII()
    
    emptys = [i for i in range(1, k + 1) if i != s and i != e]
    
    outs = []
    
    for i in range(k - 1, 0, -1):
        outs.append(f'{s} {e}')
        
        for j in range(i - 1):
            outs.append(f'{s} {emptys[k - 3 - j]}')
        
        for j in range(i - 3, -1, -1):
            outs.append(f'{emptys[k - 3 - j]} {emptys[k - 1 - i]}')
        
        if i > 1:
            outs.append(f'{e} {emptys[k - 1 - i]}')
    
    for i in range(k - 3, -1, -1):
        outs.append(f'{emptys[i]} {s}')
        
        for j in range(k - 3, i, -1):
            outs.append(f'{emptys[i]} {emptys[j]}')
        
        outs.append(f'{emptys[i]} {e}')
        
        for j in range(i + 1, k - 2):
            outs.append(f'{emptys[j]} {e}')
        
        outs.append(f'{s} {e}')
    
    print(2 * (k - 1) * (k - 1) - 1)
    print('\n'.join(outs))
```
