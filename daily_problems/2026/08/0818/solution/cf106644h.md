**提示 1：** 简单博弈论。 $n$ 为偶数更简单。

对于 $n$ 为偶数：

- 如果中间两项中存在一个是 $B$ ，先手可以先操作一次，让 $B$ 变成整个字符串的正中间。这样后手操作一次，先手只要在另一端再操作一次，这样最后剩下的一定是中间字符，就必胜了。

- 否则，无论先手如何操作，后手对称操作，最后一定剩下中间的两个字符，此时先手无论如何操作，最后剩下的都一定是 $R$ 了。

$n$ 为计数的情况可以转化为 $n$ 为偶数的情况：

可以枚举第一个人的操作，只要有一种操作使得他能必胜即可。

如果操作一次后，中间两个元素中有 $R$ ，后手模仿 $n$ 为偶数的情况下的先手操作即可，此时后手必胜。

否则，先手可以模仿 $n$ 为偶数情况下的后手操作。

整体思路是，找到容易分析的情况，再把剩余情况转化过去。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        s = I()
        
        if n % 2:
            outs.append('Doludu' if s[n // 2 - 1:n // 2 + 1] == 'BB' or s[n // 2:n // 2 + 2] == 'BB' else 'DoIudu')
        else:
            outs.append('Doludu' if 'B' in s[n // 2 - 1:n // 2 + 1] else 'DoIudu')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n;
		string s;
		cin >> n >> s;

		if (n & 1) cout << (s[n / 2] == 'B' && (s[n / 2 - 1] == 'B' || s[n / 2 + 1] == 'B') ? "Doludu" : "DoIudu") << '\n';
		else cout << (s[n / 2 - 1] == 'B' || s[n / 2] == 'B' ? "Doludu" : "DoIudu") << '\n';
	}

	return 0;
}
```
