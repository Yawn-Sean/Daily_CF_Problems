**提示 1：** 找到能使得 $G(1)$ 最小的系数分配。

首先，我们可以找到 $b$ 的 $a+1$ 进制表示，此时各个系数之和是最小的，也就使得 $G(1)$ 最小。

如果此时， $G(1)$ 不等于 $a$ ，那么我如果要微调系数，只能将 $G(a+1)$ 中的若干个 $1\times (a+1)^t$ 替换为 $(a+1)\times (a+1)^t$ ，系数会增加 $a$ 。而初始系数和为正，所以加了若干个 $a$ 后大于等于 $ka+1$ ，也就大于 $a$ 了。

因此做进一步拆分一定不会更优。

所以直接求 $a+1$ 进制表示并逆序输出即可。

时间复杂度为 $\mathcal{O}(\log_{a+1}b)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    a, b = MII()
    a += 1
    
    ans = []
    while b:
        ans.append(b % a)
        b //= a
    
    print(len(ans))
    print(' '.join(map(str, ans)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	long long a, b;
	cin >> a >> b;

	vector<int> ans;
	a ++;

	while (b) {
		ans.emplace_back(b % a);
		b /= a;
	}

	cout << ans.size() << '\n';
	for (int i = 0; i < ans.size(); i ++) cout << ans[i] << " \n"[i + 1 == ans.size()];

	return 0;
}
```
