**提示 1：** 找到条件。说明是足够的。

首先，数组中最大值最小值的位置一定只能是 $2,0$ ，所以数组中必须得有 $0$ 或 $2$ 。

同时，两个 $0$ 或者两个 $2$ 也不能挨在一起，因为这两者一定一个比另一个大 / 小，就违背了这个条件。注意首尾也得判一下，虽然好像这题没有这样的测试样例。

这足够吗？也就是说满足这个条件的数组就一定满足要求了吗？还不够。相邻的两个 $2$ 之间一定有 $0$ ，因为 $2$ 意味着是一个峰， $0$ 意味着一个谷。

反之也是。所以可以把 $0,2$ 拎出来看是否交替排列，同时长度为偶数。

构造也很容易，把小数填到谷，大数填到峰，剩余元素在中间顺序 / 倒序排列就行。

但这题的样例很弱，所以随便写写都是能通过的，我们谴责一下出题人。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    a, b = MII()
    a += 1
    
    ans = []
    while b:
        ans.append(b % a)
        b //= a
    
    print(len(ans))
    print(' '.join(map(str, ans)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	long long a, b;
	cin >> a >> b;

	vector<int> ans;
	a ++;

	while (b) {
		ans.emplace_back(b % a);
		b /= a;
	}

	cout << ans.size() << '\n';
	for (int i = 0; i < ans.size(); i ++) cout << ans[i] << " \n"[i + 1 == ans.size()];

	return 0;
}
```
