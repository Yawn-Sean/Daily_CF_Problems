**提示 1：** 拆贡献，每一部分贡献如何？

首先，一个数组的段落数，等于 $1$ 加上相邻两项不同的出现次数。

于是只需求相邻两项不同的期望次数。

如果 $k\gt 0$ ，则任意一组相邻元素都至少有一个是随机出来的，因此不同的概率总是 $\frac{x-1}{x}$ ，而为了算出相邻两项不同的总出现次数，可以用期望可加性，用总数乘以这个概率。

每次间隔数量刚好乘 $2$ ，所以最后有 $(n-1)\times 2^k$ 个间隔，乘以对应概率就是这部分答案。

当然，相对容易忽略的 $k=0$ 的情况，此时数组不变，统计一下就行。

时间复杂度为 $\mathcal{O}(n)$ 或 $\mathcal{O}(\log k)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, x, k = MII()
    nums = LII()
    
    mod = 10 ** 9 + 7
    
    if k:
        total = (n - 1) * pow(2, k, mod) % mod
        print((total + 1 - total * pow(x, -1, mod)) % mod)
    
    else:
        print(sum(nums[i] != nums[i - 1] for i in range(1, n)) + 1)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, x, k;
	cin >> n >> x >> k;

	vector<int> nums(n);

	for (auto &v: nums) cin >> v;

	int mod = 1e9 + 7;

	if (k) {
		int total = (n - 1) * quickPow(2, k, mod) % mod;
		cout << ((x - 1) * quickPow(x, mod - 2, mod) % mod * total % mod + 1) % mod;
	}
	else {
		int ans = 1;
		for (int i = 1; i < n; i ++) ans += (nums[i] != nums[i - 1]);
		cout << ans;
	}

	return 0;
}
```
