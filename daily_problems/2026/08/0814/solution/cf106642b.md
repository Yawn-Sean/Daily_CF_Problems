**提示 1：** 如何计算成本？

**提示 2：** 依次确定每一位。

首先，每次操作相当于对前缀和选择其中的一位，对其执行 $+1/-1$ 的操作。

所以总成本就是前缀和数组中的元素的绝对值之和。

而对前缀和数组的要求就是：

- 绝对值之和不超过 $x$ 。

- 相邻两项之差在 $[-k,k]$ 内。

- 最后一项为 $0$ 。

- 字典序最小（原数组字典序最小意味着前缀和数组字典序最小）。

于是，尝试一位位确定答案（这也是字典序提醒我们的）。

假设当前前面的 $k$ 项都决定好了，接下来要确定第 $k+1$ 项。

关于二分上下界，可以根据前一项 $-k/+k$ 得到，同时要给定一个 $0$ 的上界，以及到最后需要恢复为 $0$ ，因此这个数值也不能太小，从后往前推即可得到这个下界。

检查过程中唯一需要检查的新条件就是成本，所以假定当前元素为 $mid$ ，后面每一项只能是 $mid+k,mid+2k,\dots$ 直到超过 $0$ ，这些元素的绝对值的和就是这一项取 $mid$ 时的最小成本，将其和目标成本比较即可判断是否合法。

$1$ 到 $n$ 位依次确定即可，时间复杂度为 $\mathcal{O}(n\log M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n, k, x = MII()
    
        acc = [0] * (n + 1)
        
        for i in range(1, n + 1):
            l, r = fmax(-(n - i) * k, acc[i - 1] - k), fmax(0, acc[i - 1] + k)
            
            while l <= r:
                mid = (l + r) // 2
                
                start = -mid
                step = start // k
                
                if (start + start + step * (-k)) * (step + 1) // 2 <= x:
                    r = mid - 1
                else:
                    l = mid + 1
            
            acc[i] = l
            x += l
        
        outs.append(' '.join(str(acc[i + 1] - acc[i]) for i in range(n)))
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n, k;
		long long x;
		cin >> n >> k >> x;

		vector<long long> acc(n + 1, 0);

		for (int i = 1; i <= n; i ++) {
			long long l = max(-1ll * (n - i) * k, acc[i - 1] - k);
			long long r = max(0ll, acc[i - 1] + k);

			while (l <= r) {
				long long mid = (l + r) / 2;
				long long start = -mid, step = start / k;
				if ((start + start + step * (-k)) * (step + 1) / 2 <= x) r = mid - 1;
				else l = mid + 1;
			}

			acc[i] = l; x += l;
		}

		for (int i = 1; i <= n; i ++) cout << acc[i] - acc[i - 1] << " \n"[i == n];
	}

	return 0;
}
```
