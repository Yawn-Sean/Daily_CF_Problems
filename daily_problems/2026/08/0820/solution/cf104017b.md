**提示 1：** 找到特征。

这题，很神秘。这个观察非常简单又不太容易观察到。

假设一个矩形上，四个点朝与其同行 / 同列的点连边，小数值向大数值连边。

则你可以发现前两大的数值在对角线的时候，整个矩形内没有长度为 $3$ 的链。而长度为 $3$ 的链存在时，一定恰好是两条。

所以我们只需数这样的链的个数。枚举中点，找这一行 / 列有多少个数比它小 / 大，行小配列大，行大配列小即可。

时间复杂度为 $\mathcal{O}(n^2)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    
    pos = [0] * (n * n + 1)
    
    for i in range(n):
        nums = LII()
        for j in range(n):
            pos[nums[j]] = (i, j)
    
    ans = 0
    
    c_row = [0] * n
    c_col = [0] * n
    
    for i in range(1, n * n + 1):
        x, y = pos[i]
        
        ans += c_row[x] * (n - 1 - c_col[y])
        ans += c_col[y] * (n - 1 - c_row[x])
        
        c_row[x] += 1
        c_col[y] += 1
    
    print(ans // 2)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	vector<pair<int, int>> pos(n * n + 1);

	for (int i = 0; i < n; i ++) {
		for (int j = 0; j < n; j ++) {
			int x;
			cin >> x;
			pos[x] = {i, j};
		}
	}

	vector<int> c_row(n, 0), c_col(n, 0);

	long long ans = 0;

	for (int i = 1; i <= n * n; i ++) {
		auto [x, y] = pos[i];
		ans += c_row[x] * (n - 1 - c_col[y]);
		ans += c_col[y] * (n - 1 - c_row[x]);
		c_row[x] ++, c_col[y] ++;
	}

	cout << ans / 2;

	return 0;
}
```
