首先，很明显，每次操作不改变 ABC 的个数的奇偶性。

但足够吗？最后一个样例告诉你 ABC 和 CBA 不能一起，为啥呢？

发现可能是一些交换操作无法实现。

而：

$$
AB\to AABABB\to BABB\to BA
$$

所以 AB 可交换，同理 BC 可交换。

所以可以直接把所有 B 放在开头，再把多余的删掉，因此 B 的部分已经充要了。

而剩余的 AC 部分可以任意删除某个元素的连续两次出现，因此可以用栈来维护这一部分，将其删得尽可能短，这样的结果是唯一的。

这个结果必须完全匹配，因为各个操作都不影响这个结果。

综上，我们需要 B 个数的奇偶性一致， AC 进行括号匹配后剩余序列一致。

时间复杂度为 $\mathcal{O}(|u|+|v|)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    def f(x):
        cb = 0
        stk = []
        
        for c in x:
            if c == 'B': cb ^= 1
            elif stk and stk[-1] == c: stk.pop()
            else: stk.append(c)
        
        return cb, stk
    
    for _ in range(t):
        outs.append('YES' if f(I()) == f(I()) else 'NO')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		string s1, s2;
		cin >> s1 >> s2;

		auto f = [&] (string &s) -> pair<bool, vector<char>> {
			bool flg = false;
			vector<char> stk;

			for (auto &c: s) {
				if (c == 'B') flg ^= 1;
				else if (!stk.empty() && stk.back() == c) stk.pop_back();
				else stk.emplace_back(c);
			}

			return {flg, stk};
		};

		cout << (f(s1) == f(s2) ? "YES" : "NO") << '\n';
	}

	return 0;
}
```
