**提示 1：** 如果我们可以拆成若干直着的段，则答案需要满足什么要求？

**提示 2：** 拆法有限。

如果给定的是一系列的线段，则我们的答案就是这些线段的长度的最大公约数的因子。

但这里不是一堆线段，怎么办？

只需考虑四个角落分别属于哪一段即可。枚举 $2^4$ 的情况是最稳妥的选择，否则你最好分类讨论完整（不然容易漏掉 $2$ 是必然可行的）。

时间复杂度为 $\mathcal{O}(\sqrt{M})$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    inf = 10 ** 6
    
    for _ in range(t):
        n, a, b = MII()
        nums = LII()
        
        a -= 1
        b -= 1
        
        dp = [inf] * n
        dp[a] = 0
        
        flg = True
        
        while flg:
            flg = False
            
            def solve():
                global flg
                
                seg = SegTree(fmin, inf, n)
                updates = [[] for _ in range(n)]
                
                for i in range(n):
                    for x in updates[i]:
                        seg.set(x, inf)
                    
                    v = seg.prod(fmax(0, i - nums[i]), i)
                    if v + 1 < dp[i]:
                        flg = True
                        dp[i] = v + 1
                    
                    seg.set(i, dp[i])
                    
                    if i + nums[i] + 1 < n:
                        updates[i + nums[i] + 1].append(i)
            
            for _ in range(2):
                solve()
                nums.reverse()
                dp.reverse()
        
        outs.append(dp[b])
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int w, l;
		cin >> w >> l;

		set<int> st = {2};

		for (auto &x: {gcd(w, l - 2), gcd(w - 2, l), gcd(w - 1, l - 1)}) {
			for (int i = 1; i <= 100000; i ++) {
				if (i * i > x) break;
				if (x % i == 0) st.insert(i), st.insert(x / i);
			}
		}

		cout << st.size();
		for (auto &v: st) cout << ' ' << v; cout << '\n';
	}

	return 0;
}
```
