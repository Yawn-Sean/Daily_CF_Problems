**提示 2：** 如果有掉头，有啥性质？

如果只允许 $i\lt j$ 的转移怎么做呢？

这样整体就是单向转移，无后效性了，考虑到第 $i$ 个位置的最小步数为 $dp[i]$ 。

则在考虑 $dp[j]$ 时，我们首先要考虑 $i+p_i\geq j$ 的那些 $i$ ，一旦这个条件不满足，对应的 $i$ 的位置就直接清空不讨论。

而真正能转移的 $i$ 还需要满足 $i\geq j-p_j$ ，这是一段连续的区间，我们要求这一部分的最小值，可以用线段树维护。

综上，大体步骤是：

- 从左到右遍历 $j$ 。

- 遍历过程中，在线段树上，将当前 $i+p_i\lt j$ 的那些 $i$ 位置设为无穷大。为此我们可以在 $i+p_i$ 位置记录对应所有的 $i$ ，同时处理它们。

- 查询 $[j-p_j, j]$ 部分的转移。

但这题可能来回走，怎么办？

假设你从 $x$ 位置出发，走到了 $y$ 位置后第一次折返且走到 $z$ ，则首先， $x$ 在 $y,z$ 之间，不然可以直接走到 $z$ 。

若 $x$ 后的第一步长度 $V$ 一定严格小于 $|x-z|$ ，不然可以直接从 $x$ 走到 $z$ 了

同时， $|x-y|\geq V$ ，所以 $|y-z|=|x-y|+|x-z|\gt V+V=2V$ 。

所以考虑调转方向后的第一次步长，每次至少翻两倍，所以最多只需要折返 $\mathcal{O}(\log n)$ 次。

因此可以不断反转方向进行 DP，反转 $\mathcal{O}(\log n)$ 次后即可得到正确的最短路结果。

时间复杂度为 $\mathcal{O}(n\log^2n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    inf = 10 ** 6
    
    for _ in range(t):
        n, a, b = MII()
        nums = LII()
        
        a -= 1
        b -= 1
        
        dp = [inf] * n
        dp[a] = 0
        
        flg = True
        
        while flg:
            flg = False
            
            def solve():
                global flg
                
                seg = SegTree(fmin, inf, n)
                updates = [[] for _ in range(n)]
                
                for i in range(n):
                    for x in updates[i]:
                        seg.set(x, inf)
                    
                    v = seg.prod(fmax(0, i - nums[i]), i)
                    if v + 1 < dp[i]:
                        flg = True
                        dp[i] = v + 1
                    
                    seg.set(i, dp[i])
                    
                    if i + nums[i] + 1 < n:
                        updates[i + nums[i] + 1].append(i)
            
            for _ in range(2):
                solve()
                nums.reverse()
                dp.reverse()
        
        outs.append(dp[b])
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int op(int x, int y) {return min(x, y);}
int e() {return (int)1e9;}

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n, a, b;
		cin >> n >> a >> b, a --, b --;

		vector<int> nums(n);
		for (auto &x: nums) cin >> x;

		vector<int> dp(n, e());
		dp[a] = 0;

		bool flg = true;

		while (flg) {
			flg = false;

			auto solve = [&] () -> void {
				atcoder::segtree<int, op, e> seg(n);
				vector<vector<int>> updates(n);

				for (int i = 0; i < n; i ++) {
					for (auto &x: updates[i]) seg.set(x, e());

					int v = seg.prod(max(0, i - nums[i]), i);
					if (v + 1 < dp[i]) {
						flg = true;
						dp[i] = v + 1;
					}
					seg.set(i, dp[i]);

					if (i + nums[i] + 1 < n) updates[i + nums[i] + 1].emplace_back(i);
				}
			};

			for (int i = 0; i < 2; i ++) {
				solve();
				reverse(nums.begin(), nums.end());
				reverse(dp.begin(), dp.end());
			}
		}

		cout << dp[b] << '\n';
	}

	return 0;
}
```
