**提示 1：** 考虑清楚一些情况。

首先 $b_1=1$ ，因为长度为 $1$ 的总是回文。

如果 $b_2=1$ ，则任意相邻两项都相等，整个 $b$ 只能有 $1$ ，此时输出纯 $a$ 字符串即可。

否则 $b_2=0$ 。

- 如果 $b_3=1$ ，则如果存在一组相邻的字符相等，则因为所有长度为 $3$ 的都是回文串，可以得到所有字符都相等，矛盾。因此任意一组相邻的字符都不相等，同时隔一个字符相等一次。综上，只能形如 $abab...$ 了，对应的 $b=1010...$ 。

- 如果 $b_3=0$ ，此时如果我们找到大于 $2$ 的使得 $b_k=1$ 的 $k$ 。

    - 如果 $k\lt n$ ，则由于 $s_1\dots s_k$ 和 $s_2\dots s_{k+1}$ 都是回文串，则 $s_1=s_k$ （第一个串）， $s_k=s_3$ （第二个串）， $s_3=s_{k-2}$ ，……，类似的不断推，可以得到整个字符串的奇数位置的数值相同，此时应该有 $b_3=1$ ，矛盾了。

    - 所以中间部分的 $b_i=0$ ，因此只需考虑 $b_n=0$ 或者 $b_n=1$ 两种情况。

    - 如果 $b_n=0$ 证明整个字符串也非回文串，此时构造直接 $n-1$ 个 $a$ 和 $b$ 拼接即可。

    - 如果 $b_n=1$ 证明整体是回文串，字典序最小的那个全 $a$ 不满足要求，所以把中间的部分改成 $b$ ，发现符合要求。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        s = I()
        
        if s == '1' * n: outs.append('a' * n)
        elif s == ''.join('1' if i % 2 == 0 else '0' for i in range(n)):
            outs.append(''.join('a' if i % 2 == 0 else 'b' for i in range(n)))
        elif s == '1' + '0' * (n - 1):
            outs.append('a' * (n - 1) + 'b')
        elif n >= 2 and s == '1' + '0' * (n - 2) + '1':
            outs.append('a' * ((n - 1) // 2) + 'b' * (n - (n - 1) // 2 * 2) + 'a' * ((n - 1) // 2))
        else:
            outs.append('-1')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n;
		string s;
		cin >> n >> s;

		auto check1 = [&] () -> bool {
			for (auto &c: s) if (c == '0') return false;
			return true;
		};

		auto check2 = [&] () -> bool {
			for (int i = 0; i < n; i ++) {
				if (s[i] - '0' == i % 2) {
					return false;
				}
			}
			return true;
		};

		auto check3 = [&] () -> bool {
			if (s[0] == '0') return false;
			for (int i = 1; i < n; i ++)
				if (s[i] == '1') return false;
			return true;
		};

		auto check4 = [&] () -> bool {
			if (s[0] == '0' || s[n - 1] == '0') return false;
			for (int i = 1; i < n - 1; i ++)
				if (s[i] == '1') return false;
			return true;
		};

		if (check1()) cout << string(n, 'a') << '\n';
		else if (check2()) {
			for (int i = 0; i < n; i ++)
				cout << (i % 2 ? 'b' : 'a');
			cout << '\n';
		}
		else if (check3()) cout << string(n - 1, 'a') << 'b' << '\n';
		else if (check4()) cout << string((n - 1) / 2, 'a') << string(n - (n - 1) / 2 * 2, 'b') << string((n - 1) / 2, 'a') << '\n';
		else cout << "-1\n";
	}

	return 0;
}
```
