**提示 1：** 如果 $p^\alpha$ 能构造出来，那所有数都能构造出来了。

首先，如果所有质数的幂次都能称出来，那么其余的合数可以拆为若干个质数的幂次的乘积，因此也就完成了所有的数。

所以我们只需考虑所有质数的幂次最少需要多少个才能称出来。（当然你得多补上一个 $1$ ）。

各个质数互不影响，所以分别考虑即可。

对于 $p^1,p^2,p^3,\dots$ ，最优凑法如何呢？实际上可以取对数后考虑，也就是次数加法。因此存 $p,p^2,p^4,p^8,\dots$ 这些就行。

于是在这些数上打标记，最后统计 $1$ 到 $m$ 上的标记数，直接取前缀和即可。

时间复杂度为 $\mathcal{O}(M\log\log M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    M = 10 ** 6 + 1
    isPrime = [1] * M
    cnt = [0] * M
    
    isPrime[0] = 0
    isPrime[1] = 0
    
    cnt[1] = 1
    
    for i in range(2, M):
        if isPrime[i]:
            for j in range(i * 2, M, i):
                isPrime[j] = 0
            
            v = i
            cur = 1
            
            while v < M:
                if cur & -cur == cur:
                    cnt[v] = 1
                v *= i
                cur += 1
    
    for i in range(1, M):
        cnt[i] += cnt[i - 1]
    
    t = II()
    outs = []
    
    for _ in range(t):
        outs.append(cnt[II()])
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int M = 1e6 + 5;
	vector<int> isPrime(M, 1), cnt(M, 0);

	isPrime[0] = 0, isPrime[1] = 0;
	cnt[1] = 1;

	for (int i = 2; i < M; i ++) {
		if (isPrime[i]) {
			for (int j = i * 2; j < M; j += i)
				isPrime[j] = 0;
			
			int cur = i, c = 1;
			while (true) {
				if (__popcount(c) == 1) cnt[cur] = 1;
				if (cur > (M - 1) / i) break;
				cur *= i, c ++;
			}
		}
	}

	for (int i = 1; i < M; i ++) cnt[i] += cnt[i - 1];

	int t; cin >> t;

	while (t --) {
		int n; cin >> n;
		cout << cnt[n] << '\n';
	}

	return 0;
}
```
