**提示 1：** 考虑如何计算 MST 。第 $i$ 条边加入时，其最小是第几小的边，最大时第几小的边？

首先，这题最小值很容易确定，直接拿 $n-1$ 条边搭成一棵树，剩余任意填就行。

否则，考虑 Prim 算法的，第 $k$ 条边加入时，最多加了多少边呢？假设此时各个连通块大小为 $sz_1,sz_2,\dots,sz_i$ ，则 $(sz_1-1)+(sz_2-1)+\dots+(sz_i-1)=k-1$ ，因为这就是添加的边数。

而此时总边数不超过 $C_{sz_1}^2+C_{sz_2}^2+\dots+C_{sz_k}^2$ ，发现把 $sz_i,sz_j$ 合并成 $sz_i+sz_j-1$ 大小的连通块数值单调递增，所以边数最多的结果就是只有一个连通块，即 $C_k^2$ 条边。

综上，MST 的第 $k$ 条边最大只能是完全图中第 $C_k^2+1$ 大的边。

而这边的最大值可以同时取到，我们只需归纳构造，把前 $C_{k-1}^2$ 条边分给前面 $k-1$ 个点构成的完全图，接下来剩余边连给第 $k$ 个点就行。

整体只需排序后将对应位置求和输出即可。时间复杂度为 $\mathcal{O}(n^2\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    
    nums.sort()
    
    mn = sum(nums[:n - 1])
    mx = 0
    
    for i in range(1, n):
        mx += nums[i * (i - 1) // 2]
    
    print(mn, mx)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	vector<int> nums(n * (n - 1) / 2);

	for (auto &x: nums) cin >> x;

	sort(nums.begin(), nums.end());

	long long mn = 0, mx = 0;

	for (int i = 1; i < n; i ++) {
		mn += nums[i - 1];
		mx += nums[i * (i - 1) / 2];
	}

	cout << mn << ' ' << mx << '\n';

	return 0;
}
```
