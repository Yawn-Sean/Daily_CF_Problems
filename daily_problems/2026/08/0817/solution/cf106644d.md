**提示 1：** 如果一个 $k$ 不能作为答案，需要满足什么条件？怎么判断？

我们先忽略 $j-i\lt k$ 。

此时我们这个集合就跟 $k$ 无关了。此时这个集合有哪些元素呢？

因为只要求存在 $a_i\neq a_j$ 就可以把 $j-i$ 算入集合内，这样的元素对太多了，所以不太好考虑。

但如果 $v=j-i$ 不在集合内，则意味着任意隔开 $v$ 距离的两个位置都相等——这就意味着有长度为 $v$ 的循环节，这就好办多了。

这等价于从第 $v+1$ 开头的子串是原串的前缀。这件事儿可以用 z 函数 / KMP 算法等，找到所有的 $v$ 。

而找到非集合内的元素就可以取补集确定原集合。接下来对每一个 $k$ 依次输出不超过 $k$ 的最大元素即可。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    
    z = z_algorithm(nums)
    
    outs = []
    cur = -1
    
    for i in range(1, n):
        if z[i] != n - i:
            cur = i
        outs.append(cur)
    
    print(' '.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
template <typename T>
std::vector<int> z_algorithm(const T& s) {
	int n = static_cast<int>(s.size());
	if (n == 0) {
		return {};
	}

	std::vector<int> z(n, 0);
	int j = 0;
	for (int i = 1; i < n; ++i) {
		z[i] = (j + z[j] <= i) ? 0 : std::min(j + z[j] - i, z[i - j]);
		while (i + z[i] < n && s[z[i]] == s[i + z[i]]) {
			++z[i];
		}
		if (j + z[j] < i + z[i]) {
			j = i;
		}
	}
	z[0] = n;

	return z;
}

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	vector<int> nums(n);
	for (auto &x: nums) cin >> x;

	auto z = z_algorithm(nums);

	int cur = -1;
	for (int i = 1; i < n; i ++) {
		if (z[i] != n - i) cur = i;
		cout << cur << " \n"[i == n - 1];
	}

	return 0;
}
```
