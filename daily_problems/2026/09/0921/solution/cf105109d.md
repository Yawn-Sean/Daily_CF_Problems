**提示 1：** 考虑将最后的答案表示成 $f(1),f(2),\dots,f(n)$ 的幂次的乘积。

看提示 1。

我们用 $f(n-1),f(n-2),\dots,f(n-k)$ 的幂次来计算 $f(n)$ 的幂次。

此时我们发现 $f(n)$ 的幂次可以用前面的各个幂次线性表示。所以整个递推可以使用矩阵表示。

但需要注意的是，这里矩阵快速幂的取模需要使用 $mod-1$ ，因为 $x^{mod-1}\equiv 1\pmod{mod}$ ，这样才能保证幂次取模后，底下计算的结果不变。

最后快速幂把 $f(1)^{a_1}$ 一类的项全部计算出来再相乘即可。

时间复杂度为 $\mathcal{O}(n^3\log k)$ 。当然线性递推有更快的算法，但这里是不必要的。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, k = MII()
    nums = LII()

    if k <= n:
        print(nums[k - 1])
    else:
        mod = 10 ** 9 + 6

        grid = [[0] * n for _ in range(n)]

        grid[0] = nums

        for i in range(1, n):
            grid[i][i - 1] = 1

        res = matrix_pow(grid, k - n)[0]
        
        ans = 1
        mod += 1
        
        for i in range(n):
            ans = ans * pow(nums[i], res[n - 1 - i], mod) % mod
        
        print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, mod = 1e9 + 7;
	long long k;
	cin >> n >> k;

	vector<int> nums(n);
	for (auto &x: nums) cin >> x;

	vector<vector<int>> grid(n, vector<int>(n, 0));
	grid[0] = nums;

	for (int i = 1; i < n; i ++) grid[i][i - 1] = 1;

	if (k <= n) cout << nums[k - 1];
	else {
		auto res = matrix_pow(grid, k - n, mod - 1)[0];
		int ans = 1;

		for (int i = 0; i < n; i ++)
			ans = 1ll * ans * quickPow(nums[i], res[n - 1 - i], mod) % mod;

		cout << ans;
	}

	return 0;
}
```
