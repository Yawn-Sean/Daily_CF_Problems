**提示 1：** 考虑每个元素的权重。

设 $n=2^k$ 。

一定有 $1$ 个人赢了 $k$ 轮，其对答案的贡献是 $k$ 。

有 $1$ 个人赢了 $k-1$ 轮，输了 $1$ 轮，其对答案的贡献是 $k-2$ 。

有 $2$ 个人赢了 $k-2$ 轮，输了 $1$ 轮，其对答案的贡献是 $k-3$ 。

……

有 $2^{n-1}$ 个人赢了 $0$ 轮，输了 $1$ 轮，其对答案的贡献是 $-1$ 。

而为了使得总权值最大，应该把大的值放到前面的组别，小的值放后面的组别。只需开头逆序排序后，依次分配即可。最后的这个权值的对应构造也是存在的。

时间复杂度为 $\mathcal{O}(n\log n)$ ，如果你用快速选择的话可以达到 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    
    nums.sort(reverse=True)
    
    k = n.bit_length() - 1
    
    ans = nums[0] * k
    pt = 1
    
    for i in range(k):
        for j in range(1 << i):
            ans += nums[pt + j] * (k - i - 2)
        pt += 1 << i
    
    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	vector<int> nums(n);
	for (auto &x: nums) cin >> x;

	sort(nums.rbegin(), nums.rend());

	int k = 31 - __builtin_clz(n), pt = 1;
	long long ans = 1ll * k * nums[0];

	for (int i = 0; i < k; i ++) {
		for (int j = 0; j < (1 << i); j ++) {
			ans += 1ll * nums[pt + j] * (k - i - 2);
		}
		pt += 1 << i;
	}

	cout << ans;

	return 0;
}
```
