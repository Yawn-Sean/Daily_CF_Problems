**提示 1：** 欧拉定理。

如果 $n,m$ 不互质，则不存在。

否则 $\phi(m)$ 一定是满足条件的，即 $n^{\phi(m)}\equiv 1\pmod m$ 。

于是用素数筛预处理 $\phi(m)$ 即可。

时间复杂度为 $\mathcal{O}(M\log\log M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    M = 10 ** 6 + 5
    phi = list(range(M))
    
    for i in range(2, M):
        if phi[i] == i:
            for j in range(i, M, i):
                phi[j] = phi[j] // i * (i - 1)
    
    t = II()
    outs = []
    
    for _ in range(t):
        n, m = MII()
        
        if math.gcd(n, m) > 1: outs.append('-1')
        else: outs.append(str(phi[m]))
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int M = 1e6 + 5;
	vector<int> phi(M);

	iota(phi.begin(), phi.end(), 0);
	for (int i = 2; i < M; i ++) {
		if (phi[i] == i) {
			for (int j = i; j < M; j += i) {
				phi[j] = phi[j] / i * (i - 1);
			}
		}
	}

	int t;
	cin >> t;

	while (t --) {
		int n, m;
		cin >> n >> m;

		if (gcd(n, m) == 1) cout << phi[m] << '\n';
		else cout << -1 << '\n';
	}

	return 0;
}
```
