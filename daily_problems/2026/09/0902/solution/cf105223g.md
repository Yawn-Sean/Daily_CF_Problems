**提示 1：** 先找到其中一个。另一个可以基于前者找。

把每个位置的符号写出来，整个序列呈现出 `>>...>=<<..<>>...>=<<...<` 的形式。

我们先写个朴素的二分，即遇到 `>` 往右侧找，遇到 `<` 往左侧找。这样区间左右两端一定分别是 `>` 和 `<` （也可能是最初的 `=` ），因此我们所在区间内一定始终有一个 `=` ，因此我们这样二分一定能找到其中一个 `=` 。

接下来咋办呢？一个自然的想法是，分别对这个等号的两侧分别使用二分，尝试找到另一个等号。

直接二分可行吗？虽然看起来分为了很多段，不满足二段性，但是中间的 `<<..<` 和 `>>..>` 的长度的量级相同，因此考虑第一次走到那一段影响二段性区间的时刻，前面那一轮的二分查询一定与之方向相反，产生矛盾。所以直接二分不影响答案。

所以两侧分别二分就好。

时间复杂度为 $\mathcal{O}((n+q)\log M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    
    cnt = [0] * 30
    
    for x in nums:
        for i in range(30):
            cnt[i] += x >> i & 1
    
    mod = 10 ** 9 + 7
    pw3 = [1] * (n + 1)
    
    for i in range(n):
        pw3[i + 1] = pw3[i] * 3 % mod
    
    rev2 = (mod + 1) // 2
    
    q = II()
    outs = []
    
    for _ in range(q):
        idx, val = MII()
        idx -= 1
        
        for i in range(30):
            cnt[i] -= nums[idx] >> i & 1
    
        nums[idx] = val
        
        for i in range(30):
            cnt[i] += nums[idx] >> i & 1
        
        ans = 0
        
        for i in range(29, -1, -1):
            ans = (ans * 2 + (pw3[n] - pw3[n - cnt[i]])) % mod
        
        outs.append(ans * rev2 % mod)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	auto query = [&] (int x) -> char {
		cout << x << endl;
		char c; cin >> c;
		return c;
	};

	auto answer = [&] (int x1, int x2) -> void {
		cout << "! " << x1 << ' ' << x2 << endl;
	};

	auto search = [&] (int l, int r) -> int {
		while (l <= r) {
			int mid = (l + r) / 2;
			auto res = query(mid);

			if (res == '=') return mid;
			if (res == '>') l = mid + 1;
			else r = mid - 1;
		}

		return -1;
	};

	int n;
	cin >> n;

	auto v1 = search(1, n);
	auto v2 = max(search(1, v1 - 1), search(v1 + 1, n));

	if (v1 > v2) swap(v1, v2);
	answer(v1, v2);

	return 0;
}
```
