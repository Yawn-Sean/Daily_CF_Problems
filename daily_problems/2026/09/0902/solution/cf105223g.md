**提示 1：** 位对答案的贡献。每一位的计数。

首先，每一位对答案的贡献是可拆分的。于是我们分别计算每一位为 $1$ 的情况总数，再乘以 $2^i$ 加总即答案。

假设这一位总共有 $k$ 个为 $1$ ，则如果我们选取了其中大小为 $i$ 的子集，则其作为子序列 $A$ 的中对 $f(A)$ 的贡献次数为 $C_k^i\times 2^{k-i}\times 3^{n-k}$ ，其中第一个 $2^{k-i}$ 表示 $k$ 个为 $1$ 的元素中，剩余元素可以任意选择是否在 $A$ 内，第二个 $3^{n-k}$ 表示这一位是 $0$ 的元素可以任意选择是不在 $A$ 中，在 $A$ 中但不在选取的 $A$ 的子序列中，或者是在 $A$ 中且在选取的 $A$ 的子序列中，共三种选择

所以我们就是要对所有奇数 $i$ ，求 $3^{n-k}\sum\limits_{i}C_k^i\times 2^{k-i}$ 。

这个东西怎么做呢？

我们设 $f(x)=\sum\limits_{i=0}^{k}C_k^i x^i 2^{k-i}$ ，由二项式定理 $f(x)=(x+2)^k$ 。

则 $3^k=f(1)=\sum\limits_{i=0}^{k}C_k^i 1^i 2^{k-i}$ ，同时 $1^k=f(-2)=\sum\limits_{i=0}^{k}C_k^i (-1)^i 2^{k-i}$ 。

其中 $i$ 为奇数的位置，元素为相反数，偶数的位置，元素相等。

于是两式相减，即可得到 $i$ 为奇数的位置的和的两倍。即 $\frac{3^k-1}{2}$ 。

于是，这一位的贡献就是 $3^{n-k}\frac{3^k-1}{2}=\frac{3^n-3^{n-k}}{2}$ 。于是在修改数组的时候，只需维护每一位的 $1$ 的个数即可。

时间复杂度为 $\mathcal{O}((n+q)\log M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    
    cnt = [0] * 30
    
    for x in nums:
        for i in range(30):
            cnt[i] += x >> i & 1
    
    mod = 10 ** 9 + 7
    pw3 = [1] * (n + 1)
    
    for i in range(n):
        pw3[i + 1] = pw3[i] * 3 % mod
    
    rev2 = (mod + 1) // 2
    
    q = II()
    outs = []
    
    for _ in range(q):
        idx, val = MII()
        idx -= 1
        
        for i in range(30):
            cnt[i] -= nums[idx] >> i & 1
    
        nums[idx] = val
        
        for i in range(30):
            cnt[i] += nums[idx] >> i & 1
        
        ans = 0
        
        for i in range(29, -1, -1):
            ans = (ans * 2 + (pw3[n] - pw3[n - cnt[i]])) % mod
        
        outs.append(ans * rev2 % mod)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	vector<int> nums(n), cnt(30, 0);

	for (auto &x: nums) {
		cin >> x;
		for (int i = 0; i < 30; i ++) {
			cnt[i] += x >> i & 1;
		}
	}

	int mod = 1e9 + 7, rev2 = (mod + 1) / 2;
	vector<int> pw3(n + 1, 1);
	for (int i = 0; i < n; i ++) pw3[i + 1] = 3ll * pw3[i] % mod;

	int q;
	cin >> q;

	while (q --) {
		int idx, val;
		cin >> idx >> val;
		idx --;

		for (int i = 0; i < 30; i ++) cnt[i] -= nums[idx] >> i & 1;
		nums[idx] = val;
		for (int i = 0; i < 30; i ++) cnt[i] += nums[idx] >> i & 1;

		int ans = 0;
		for (int i = 29; i >= 0; i --) {
			ans = 2 * ans % mod;
			ans = (ans + pw3[n]) % mod;
			ans = (ans + mod - pw3[n - cnt[i]]) % mod;
		}

		cout << 1ll * ans * rev2 % mod << '\n';
	}

	return 0;
}
```
