**提示 1：** 单个操作实在是无法优化了。多个操作如何优化？

**提示 2：** 把多个操作理解成几乎一样的操作。

我们相当于要进行 $n-k+1$ 轮逻辑类似的排列打乱。

首先，题中给出的操作，实质上就是把已知序列关于某个规则打乱，我们可以理解为一个排列 $p$ ，让原序列嵌套上这个 $p=[p_1,p_2,\dots,p_n]$ 后得到新序列 $[s_{p_1},s_{p_2},\dots,s_{p_n}]$ 。

但这题需要对不同的位置进行 $n-k+1$ 轮这样的操作，我们没办法模拟这么多次，怎么办呢？

本质难点在需要对不同的位置操作，这样我们对应的 $p$ 就是不同的了，就不方便我们合并类似的操作。

为此，我们可以在进行一次操作后，将 $[p_1,p_2,\dots,p_n]$ 变为 $[p_2,p_3,\dots,p_n,p_1]$ ，这样，第二次操作相当于仍然在开头进行。

这样所有的操作就都一样了，只需最后恢复一下我们多做的这些移位即可。

我们总共执行 $n-k+1$ 次上述排列打乱操作，为此可以先维护 $1,2,4,\dots$ 次打乱后的效果，用倍增的方法得到对应次数后的结果。最后根据排列的结果，生成这次打乱的结果字符串。

时间复杂度为 $\mathcal{O}(nm\log n)$ 。

这里的倍增也可以用先找到排列中的每个环，然后直接跳到环上的第 $n-k+1$ 个位置替换，但实现相对麻烦一点点。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    s = I()
    n = len(s)
    
    q = II()
    outs = []
    
    def prod(x, y):
        return [y[i] for i in x]
    
    for _ in range(q):
        k, d = MII()
        
        p = list(range(n))
        
        tmp = []
        
        for i in range(d):
            for j in range(i, k, d):
                tmp.append(j)
        
        for i in range(k):
            p[tmp[i]] = i
        
        for i in range(n):
            p[i] = (p[i] - 1) % n
        
        res = list(range(n))
        steps = n - k + 1
        
        for i in range(20):
            if steps >> i & 1: res = prod(res, p)
            p = prod(p, p)
        
        ans = [0] * n
        for i in range(n):
            ans[res[i]] = i
        
        idx = ans.index(0)
        ans = ans[idx:] + ans[:idx]
        
        s = ''.join(s[x] for x in ans)
        
        outs.append(s)
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	string s;
	cin >> s;

	int n = s.size();

	int q;
	cin >> q;

	auto prod = [&] (vector<int> &v1, vector<int> &v2) -> vector<int> {
		vector<int> res;
		for (auto &x: v1) res.emplace_back(v2[x]);
		return res;
	};

	while (q --) {
		int k, d;
		cin >> k >> d;

		vector<int> p(n), tmp;
		iota(p.begin(), p.end(), 0);

		for (int i = 0; i < d; i ++) {
			for (int j = i; j < k; j += d) {
				tmp.emplace_back(j);
			}
		}

		for (int i = 0; i < k; i ++) p[tmp[i]] = i;

		for (int i = 0; i < n; i ++) p[i] = (p[i] + n - 1) % n;

		vector<int> res(n);
		iota(res.begin(), res.end(), 0);

		int steps = n - k + 1;

		for (int i = 0; i < 20; i ++) {
			if (steps >> i & 1) res = prod(res, p);
			p = prod(p, p);
		}

		vector<int> ans(n);
		for (int i = 0; i < n; i ++) ans[res[i]] = i;

		for (int i = 0; i < n; i ++) {
			if (ans[i] == 0) {
				string ns;
				for (int j = 0; j < n; j ++) {
					ns += s[ans[(i + j) % n]];
				}
				s = ns;
				break;
			}
		}

		cout << s << '\n';
	}

	return 0;
}
```
