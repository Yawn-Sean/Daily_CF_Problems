**提示 1：** $u,k$ 的查询能得到什么信息？

**提示 2：** 环上的点有啥特点？

$u,k$ 的结果为 Yes ，当且仅当走 $k$ 步时已经足够从 $u$ 入环再走一圈了。

所以考虑使得结果为 Yes 的最小的 $k'$ ，则结果为 Yes 当且仅当 $k\geq k'$ 。

而那些在环上的点， $k'$ 是最小的。

综上，我们只需确定 $k'(u)$ 数组的最小值，以及最小值在哪些位置出现即可。

所以我们可以初始情况下，假定最小值为 $mn=n$ ，不断用 $mn-1$ 尝试，枚举 $i=1,\dots,n$ 看 $k'(i)$ 是否小于等于 $mn-1$ ，如果更小，就更新 $mn$ ，因为每个元素遍历 $1$ 次，同时，重复查询次数不超过 $mn$ 的减少次数，也就不超过 $n-1$ 次。

最后，再检查每个 $k'(i)$ 是否等于刚刚得到的最小值即可，重新遍历 $n$ 个位置即可。

查询次数控制在了 $3n$ 内。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    def query(i, step):
        print('?', i, step, flush=True)
        return I() == 'Yes'
    
    n = II()
    
    cycle_size = n
    
    for i in range(1, n + 1):
        while cycle_size > 1 and query(i, cycle_size - 1):
            cycle_size -= 1
    
    ans = []
    
    for i in range(1, n + 1):
        if query(i, cycle_size):
            ans.append(i)
    
    print('!', len(ans), ' '.join(map(str, ans)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	int cycle_size = n;

	for (int i = 1; i <= n; i ++) {
		while (cycle_size > 1) {
			cout << "? " << i << ' ' << cycle_size - 1 << endl;
			string x; cin >> x;
			if (x == "Yes") cycle_size --;
			else break;
		}
	}

	vector<int> ans;

	for (int i = 1; i <= n; i ++) {
		cout << "? " << i << ' ' << cycle_size << endl;
		string x; cin >> x;
		if (x == "Yes") ans.emplace_back(i);
	}

	cout << "! " << ans.size();
	for (auto &v: ans) cout << ' ' << v;

	return 0;
}
```
