**提示 1：** 求下面积就行。

最后面积长啥样呢？

实际上就是原图形往外拓出去一个半径 $r$ 。

此时，原图形的面积 $Area$ 肯定仍然在。

而除了圆角的部分，剩余部分刚好是周长 $Perimeter$ 乘以 $r$ ，因为是一些矩形。

而那些圆角，它们的分别的角度等于外角，所以整体可以拼成一个圆，所以这部分是 $\pi r^2$ 。

综上，总面积是 $\pi r^2+Perimeter r+Area$ ，我们要求它大于等于 $k$ 。

此时如果原本面积就够大了，输出 $0$ 即可。

否则，就是求解一个二次方程了。

如果你想有更高的精度，可以用分子有理化，即 $\frac{-2c}{b+\sqrt{b^2-4ac}}$ ，因为减法损失精度。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n, k = MII()
        xs = []
        ys = []
        
        for _ in range(n):
            x, y = MII()
            xs.append(x)
            ys.append(y)
        
        area = 0
        
        for i in range(n - 2):
            x1, y1 = xs[i + 1] - xs[0], ys[i + 1] - ys[0]
            x2, y2 = xs[i + 2] - xs[0], ys[i + 2] - ys[0]
            
            area += x1 * y2 - x2 * y1
        
        area = abs(area)
        
        perimeter = 0
        
        for i in range(n):
            dx, dy = xs[(i + 1) % n] - xs[i], ys[(i + 1) % n] - ys[i]
            perimeter += math.hypot(dx, dy)
        
        if area >= k * 2: outs.append('0')
        else:
            a = math.pi
            b = perimeter
            c = area / 2 - k
    
            outs.append(f'{-2 * c / (b + math.sqrt(b * b - 4 * a * c)):.10f}')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	cout << fixed << setprecision(10);

	while (t --) {
		int n;
		long long k;
		cin >> n >> k;

		vector<pair<int, int>> pts(n);
		for (auto &[x, y]: pts) cin >> x >> y;

		long long area = 0;

		for (int i = 0; i < n - 2; i ++) {
			auto [x1, y1] = pts[0];
			auto [x2, y2] = pts[(i + 1) % n];
			auto [x3, y3] = pts[(i + 2) % n];

			int dx1 = x2 - x1, dy1 = y2 - y1;
			int dx2 = x3 - x1, dy2 = y3 - y1;

			area += abs(1ll * dx1 * dy2 - 1ll * dx2 * dy1);
		}

		long double perimeter = 0;

		for (int i = 0; i < n; i ++) {
			auto [x1, y1] = pts[i];
			auto [x2, y2] = pts[(i + 1) % n];
			perimeter += hypot(x1 - x2, y1 - y2);
		}

		if (area >= 2 * k) cout << 0 << '\n';
		else {
			long double a = acosl(-1), b = perimeter, c = (long double)(area - 2 * k) / 2;
			cout << -2 * c / (b + sqrtl(b * b - 4 * a * c)) << '\n';
		}
	}

	return 0;
}
```
