**提示 1：** 这个博弈本质上是个图上选起点后交替走未访问点的问题。可以用完美匹配。

**提示 2：** 一般图完美匹配是不好做的，这个图有啥特点？

先看提示 1 。在有完美匹配的情况下，无论 Ana 如何选择，Beto 选择完美匹配中的另一结点就行，因此 Beto 必胜；否则，可以找到最大匹配 M 和不在最大匹配内的点 $v$ ，Ana 先走 $v$ ，接下来 Beto 无论如何操作， Ana 都能找到对应的匹配点——不然的话存在增广路，与 M 是最大匹配矛盾。

但一般图最大匹配是不好解决的。

这题首先是二分图，因为匹配的结点奇偶性不同所以连边的点奇偶性不同。

而事实上，这是个森林。如果 $x+y=2^k-1$ ，且 $x\lt y$ ，则 $y$ 已知的话， $x$ 唯一确定——也就是任意一个数只会往比它小的数连一条边（除非 $x=0$ ）。转化为森林是否存在完美匹配就很好做了，直接从叶子节点开始进行树 DP ，贪心匹配即可。

时间复杂度为 $\mathcal{O}(n\log n)$ ，如果先建图，且用哈希表的话可以优化到 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    d = {}

    for _ in range(n):
        a, c = MII()
        d[a] = c


    for x in sorted(d, reverse=True):
        if d[x]:
            v = (1 << x.bit_length()) - 1 - x
            if v not in d or d[v] < d[x]:
                exit(print('Ana'))
            d[v] -= d[x]

    print('Beto')
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	map<int, int> mp;

	for (int i = 0; i < n; i ++) {
		int a, c;
		cin >> a >> c;
		mp[-a] = c;
	}

	for (auto &[k, v]: mp) {
		if (v) {
			int cur = -k;
			int target = -((1 << 32 - __builtin_clz(cur)) - 1 - cur);

			if (mp.find(target) == mp.end() || mp[target] < v)
				return cout << "Ana", 0;

			mp[target] -= v;
		}
	}

	cout << "Beto";

	return 0;
}
```
