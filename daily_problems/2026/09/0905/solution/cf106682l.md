**提示 1：** 假设当前匹配到 $x$ 位置，下一次最多匹配到哪？贪心。

首先，我们可以得到目标序列。即所有不同元素的升序排列。

接下来，假设我们已经匹配了目标数组的前 $x$ 个位置，接下来从 $x+1$ 个位置开始匹配。

分别考虑顺序和倒序最多匹配多少。

以顺序为例。假设已经用了前 $i$ 个数组中的元素，匹配到了目标数组 $p$ 的位置，对于 $p+1$ ，我们在其出现位置中二分找到第一个大于 $i$ 的元素，也就是这个元素对应需要的位置了。

于是不断二分就能确定这一轮匹配多少。

顺序倒序逻辑是类似的，我们取两种匹配方式的最大值即可。

因为每一轮都贪心取了最长的一段，所以轮数已经是最小的了。

复杂度呢？每一轮假设往前挪了 $k$ 个位置，则最多进行了 $2k$ 次二分。所以二分总次数是不超过 $2m$ 的，复杂度为 $\mathcal{O}(m\log n)$ 。

时间复杂度为 $\mathcal{O}(n+m\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, m = MII()
    nums = LII()
    
    pos = [[] for _ in range(m + 1)]
    for i in range(n):
        pos[nums[i]].append(i)
    
    target = [i for i in range(m + 1) if pos[i]]
    
    k = len(target)
    start = 0
    ans = 0
    
    while start < k:
        nstart1 = 0
        cur1 = 0
        for j in range(start, k):
            p = bisect.bisect_left(pos[target[j]], cur1)
            if p == len(pos[target[j]]): break
            nstart1 = j
            cur1 = pos[target[j]][p]
        
        nstart2 = 0
        cur2 = n
        for j in range(start, k):
            p = bisect.bisect_left(pos[target[j]], cur2) - 1
            if p == -1: break
            nstart2 = j
            cur2 = pos[target[j]][p]
        
        start = fmax(nstart1, nstart2) + 1
        ans += 1
    
    print(k, ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, m;
	cin >> n >> m;

	vector<int> nums(n), target;
	vector<vector<int>> pos(m + 1);

	for (int i = 0; i < n; i ++) {
		cin >> nums[i];
		pos[nums[i]].emplace_back(i);
	}

	for (int i = 0; i <= m; i ++) {
		if (!pos[i].empty()) {
			target.emplace_back(i);
		}
	}

	int k = target.size(), start = 0, ans = 0;

	while (start < k) {
		int nstart1 = 0, cur1 = 0;

		for (int j = start; j < k; j ++) {
			int p = lower_bound(pos[target[j]].begin(), pos[target[j]].end(), cur1) - pos[target[j]].begin();
			if (p == pos[target[j]].size()) break;
			nstart1 = j;
			cur1 = pos[target[j]][p];
		}

		int nstart2 = 0, cur2 = n;

		for (int j = start; j < k; j ++) {
			int p = lower_bound(pos[target[j]].begin(), pos[target[j]].end(), cur2) - pos[target[j]].begin() - 1;
			if (p == -1) break;
			nstart2 = j;
			cur2 = pos[target[j]][p];
		}

		start = max(nstart1, nstart2) + 1;
		ans ++;
	}

	cout << k << ' ' << ans;

	return 0;
}
```
