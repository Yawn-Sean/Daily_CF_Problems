**提示 1：** 如果分配房间，肯定分最大的几个。

**提示 2：** 条件实际上是什么？

先将房间按照从大到小的顺序排序。

我们按照人数从大到小排列各个组。假设对于某个组的前缀，我们塞进去了 $x$ 个组，产生了 $y$ 的收益。

此时新来了一个大小更小的组，此时可能有新的房间可以给这个组使用，于是更新对应的 $x$ ，再把对应的组的收益加入进去。

如果此时组数已经超标，应当删去目前收益最小的组。这也就是个类似反悔贪心的过程。

时间复杂度为 $\mathcal{O}(n\log n+k\log k)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, k = MII()
    
    caps = LII()
    nums = LII()
    pays = LII()
    
    caps.sort(reverse=True)
    
    pt = 0
    total = 0
    pq = []
    
    for i in sorted(range(k), key=lambda x: -nums[x]):
        while pt < n and caps[pt] >= nums[i]:
            pt += 1
        
        heappush(pq, pays[i])
        total += pays[i]
        
        if len(pq) > pt:
            total -= heappop(pq)
    
    print(total)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, k;
	cin >> n >> k;

	vector<int> caps(n);
	for (auto &x: caps) cin >> x;

	vector<pair<int, int>> groups(k);
	for (auto &[x, y]: groups) cin >> x;
	for (auto &[x, y]: groups) cin >> y;

	sort(caps.rbegin(), caps.rend());
	sort(groups.rbegin(), groups.rend());

	long long ans = 0, pt = 0;
	priority_queue<int> pq;

	for (auto &[x, y]: groups) {
		while (pt < n && caps[pt] >= x) pt ++;
		pq.push(-y), ans += y;
		if (pq.size() > pt) ans += pq.top(), pq.pop();
	}

	cout << ans;

	return 0;
}
```
