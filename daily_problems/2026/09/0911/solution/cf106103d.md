**提示 1：** 可以从后往前推，一步步剥离开。

这题这个立方体不知道是何意味，明明只有 $x,y$ 轴两个操作。

就看成一个 $n\times n$ 的正方形就行。接下来咋办呢？

最开头的操作对最后结果的影响不明确，但是最靠后的操作是明确的。

假设最后进行了一行的操作，则这行就可以删掉了，把问题转化为了行数更小的问题；否则把问题转化为了列数更小的问题——这都能推出一个 DP 的结构。

而如果进行了连续的行操作，那么这几次行操作是可以交换顺序的，所以只能一起考虑。

因此考虑最后一步是行 / 列操作的 $i$ 行 $j$ 列的矩形有 $dp_1[i][j],dp_2[i][j]$ 种方案。

则对于前者的转移，考虑最后一批操作的行的数量，不妨设为 $x$ ，则相当于要从 $i$ 行里选 $x$ 行作为最后操作的行，将这些行去掉后，剩下 $i-x$ 行 $j$ 列的矩形，且这个矩形的最后一次操作是列操作。

因此 $dp_1[i][j]=\sum\limits_{x=1}^i C_i^x dp_2[i-x][j]$ 。

另一侧也是类似的。

时间复杂度为 $\mathcal{O}(n^3)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    mod = 10 ** 9 + 7
    
    combs = [[0] * (n + 1) for _ in range(n + 1)]
    
    for i in range(n + 1):
        combs[i][0] = 1
        combs[i][i] = 1
        
        for j in range(1, i):
            combs[i][j] = (combs[i - 1][j] + combs[i - 1][j - 1]) % mod
    
    ans = 0
    
    dp1 = [[0] * (n + 1) for _ in range(n + 1)]
    dp2 = [[0] * (n + 1) for _ in range(n + 1)]
    
    dp1[0][0] = 1
    dp2[0][0] = 1
    
    for i in range(n + 1):
        for j in range(n + 1):
            for k in range(i + 1, n + 1):
                dp2[k][j] += dp1[i][j] * combs[k][i]
                dp2[k][j] %= mod
            
            for k in range(j + 1, n + 1):
                dp1[i][k] += dp2[i][j] * combs[k][j]
                dp1[i][k] %= mod
    
    print((dp1[n][n] + dp2[n][n]) % mod)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, mod = 1e9 + 7;
	cin >> n;

	vector<vector<int>> combs(n + 1, vector<int>(n + 1, 0));

	for (int i = 0; i <= n; i ++) {
		combs[i][0] = 1, combs[i][i] = 1;
		for (int j = 1; j < i; j ++) {
			combs[i][j] = (combs[i - 1][j] + combs[i - 1][j - 1]) % mod;
		}
	}

	vector<vector<int>> dp1(n + 1, vector<int>(n + 1, 0));
	vector<vector<int>> dp2(n + 1, vector<int>(n + 1, 0));

	dp1[0][0] = 1, dp2[0][0] = 1;

	for (int i = 0; i <= n; i ++) {
		for (int j = 0; j <= n; j ++) {
			for (int k = i + 1; k <= n; k ++) {
				dp2[k][j] = (dp2[k][j] + 1ll * dp1[i][j] * combs[k][i]) % mod;
			}
			for (int k = j + 1; k <= n; k ++) {
				dp1[i][k] = (dp1[i][k] + 1ll * dp2[i][j] * combs[k][j]) % mod;
			}
		}
	}

	cout << (dp1[n][n] + dp2[n][n]) % mod;

	return 0;
}
```
