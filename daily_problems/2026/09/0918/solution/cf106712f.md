**提示 1：** 先不处理进位。

**提示 2：** 中间一批都相等——不如模拟。

首先，我们原数拆成 $a_0+a_1\times 10+\dots+a_k\times 10^k$ 。

我们把原问题理解为 $x,10x,100x$ 列竖式相加。

我们先不处理进位，则中间的一串都是 $\sum a_i$ 。而在进位下，中间这边会形成连续的一段相同的数，且这一段很长。

你可以从数学角度考虑其结果。但既然你会写代码，你不如就模拟——模拟个 $\mathcal{O}(n)$ 的长度就足够你得出中间的稳定数值了。毕竟读入也要 $\mathcal{O}(n)$ ，所以无所谓。

复杂度前面提到了。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    s = [int(c) for c in I()]
    n = len(s)
    s.reverse()
    
    for i in range(2 * n):
        s.append(0)
    
    for i in range(1, 3 * n):
        s[i] += s[i - 1]
    
    carry = 0
    for i in range(3 * n):
        s[i] += carry
        carry = s[i] // 10
        s[i] %= 10
    
    print(s[-1])
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	string s;
	cin >> s;

	int n = s.size();
	vector<int> nums(3 * n);

	for (int i = 0; i < n; i ++) nums[i] = s[i] - '0';

	for (int i = 1; i < 3 * n; i ++) nums[i] += nums[i - 1];

	int carry = 0;

	for (int i = 0; i < 3 * n; i ++) {
		nums[i] += carry;
		carry = nums[i] / 10;
		nums[i] %= 10;
	}

	cout << nums.back();

	return 0;
}
```
