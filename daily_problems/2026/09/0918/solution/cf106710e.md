**提示 1：** 考虑拆分。

考虑第 $i$ 层（初始状态是第 $0$ 层）的第 $j$ 个子数组对结果的贡献。则这些加总就是答案。

其产生贡献，当且仅当其不是升序。而不升序的情况下，也一定有机会走到这边。

于是，我们用总方案数 $k^{2^{n-i}}$ ，减去升序的方案数。

即 $1\leq a_1\leq a_2\leq\dots\leq a_{2^{n-i}}\leq k$ ，于是：

$1\leq a_1\lt a_2+1\lt\dots\lt a_{2^{n-1}}+2^{n-1}-1\leq k+2^{n-1}-1$

也就相当于在 $1,2,\dots,k+2^{n-1}-1$ 中选取 $2^{n-1}$ 个数，分别赋值给 $a_1, a_2+1,\dots, a_{2^{n-1}}+2^{n-1}-1$ ，因此总共有 $C_{k+2^{n-1}-1}^{2^{n-1}}=C_{k+2^{n-1}-1}^{k-1}$ 种方案。

因此这一块不升序的概率就是 $1-\frac{C_{k+2^{n-1}-1}^{k-1}}{k^{2^{n-i}}}$ 。

走到这个子数组的概率是 $\frac{1}{2^i}$ ，而总共有 $2^i$ 个子数组，因此这一层的总贡献就是上面那个式子。

再关于各层求和即可。

这里你需要注意一个细节：在求 $k^{2^{n-i}}$ 的时候，你应当对幂次关于 $mod-1$ 取模，而非 $mod$ ，因为 $k^{p-1}\equiv k^{0}=1\pmod p$ 。

时间复杂度为 $\mathcal{O}(n(\log M+k))$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, k = MII()
    mod = 998244353
    
    ans = 0
    cur_len = 1
    cur_len1 = 1
    
    for _ in range(n):
        cur_len = cur_len * 2 % mod
        cur_len1 = cur_len1 * 2 % (mod - 1)
        
        a = 1
        b = pow(k, cur_len1, mod)
        
        for i in range(1, k):
            a = a * (k + cur_len - i) % mod
            b = b * i % mod
        
        prob = (mod + 1 - a * pow(b, -1, mod) % mod) % mod
        
        ans = (ans + prob) % mod
    
    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, k, mod = 998244353;
	cin >> n >> k;

	int ans = 0, cur_len = 1, cur_len1 = 1;

	while (n --) {
		cur_len = cur_len * 2 % mod;
		cur_len1 = cur_len1 * 2 % (mod - 1);

		int a = 1, b = quickPow(k, cur_len1, mod) % mod;

		for (int i = 1; i < k; i ++) {
			a = 1ll * a * (k + cur_len - i) % mod;
			b = 1ll * b * i % mod;
		}

		int prob = (mod + 1 - a * quickPow(b, mod - 2, mod) % mod) % mod;
		ans = (ans + prob) % mod;
	}

	cout << ans;

	return 0;
}
```
