**提示 1：** $s+t, t+s$ 的比较取决于什么？

**提示 2：** 可以如何转化问题？

首先 $p,q$ 可以为 $0$ ，其中一个为 $0$ 时，显然就相等，先特判这件事。

接下来， $s+t$ 和 $t+s$ 的比较本质上等价于无穷个 $s$ 拼接后的字符串和无穷个 $t$ 拼接后的字符串的比较。

所以 $s^pt^q$ 和 $t^qs^p$ 的比较等价于无穷个 $s^p$ 拼接后的字符串和无穷个 $t^q$ 拼接后的字符串的比较，即无穷个 $s$ 和无穷个 $t$ 拼接后的比较，也就等价于 $s+t$ 和 $t+s$ 的比较。

于是做这件事即可。

时间复杂度为 $\mathcal{O}(|s|+|t|)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    s1, s2 = LI()
    p, q = MII()
    
    if not p or not q: print('=')
    else:
        v1 = s1 + s2
        v2 = s2 + s1
        
        if v1 < v2: print('<')
        elif v1 > v2: print('>')
        else: print('=')
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	string s, t;
	int p, q;
	cin >> s >> t >> p >> q;

	if (!p || !q) cout << '=';
	else {
		string s1 = s + t;
		string s2 = t + s;

		if (s1 < s2) cout << '<';
		else if (s1 > s2) cout << '>';
		else cout << '=';
	}

	return 0;
}
```
