**提示 1：** 考虑 DP 状态。

我们求两个人之间的硬币差，将其作为状态。

设到第 $i$ 个位置时，当前数值为 $x$ 的情况下，中间状态达到过的绝对值的最大值最小为 $dp[i][x]$ 。

则枚举新的一个数分给哪个人，状态会变成 $x-v$ 或 $x+v$ ，于是可以更新 $dp[i][x-v]$ 为 $\max(dp[i][x], |x-v|)$ ，更新 $dp[i][x+v]$ 为 $\max(dp[i][x],|x+v|)$ 。

因为总可以找到办法使得答案不超过 $\max a_i$ ，所以第二个状态的数据范围定为 $[-100,100]$ 即可。当然你也可以把正负合并。

时间复杂度为 $\mathcal{O}(nM)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        nums = LII()
        
        dp = [inf] * 201
        dp[100] = 0
        
        for x in nums:
            ndp = [inf] * 201
            
            for i in range(201):
                if i - x >= 0:
                    ndp[i] = fmin(ndp[i], dp[i - x])
                if i + x <= 200:
                    ndp[i] = fmin(ndp[i], dp[i + x])
                ndp[i] = fmax(ndp[i], abs(i - 100))
            
            dp = ndp
        
        outs.append(min(dp))
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n;
		cin >> n;

		vector<int> dp(201, (int)1e9);
		dp[100] = 0;

		while (n --) {
			int x;
			cin >> x;

			vector<int> ndp(201, (int)1e9);

			for (int i = 0; i <= 200; i ++) {
				if (i - x >= 0) ndp[i] = min(ndp[i], dp[i - x]);
				if (i + x <= 200) ndp[i] = min(ndp[i], dp[i + x]);
				ndp[i] = max(ndp[i], abs(i - 100));
			}

			dp.swap(ndp);
		}

		cout << *min_element(dp.begin(), dp.end()) << '\n';
	}

	return 0;
}
```
