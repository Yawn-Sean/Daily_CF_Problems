**提示 1：** 你最少要买多少个呢？可以只买这么多吗？对应的最小成本呢？

我们最多可以获得 $\sum b_i$ 个宝石，而这些最多能兑换 $\sum b_i$ 瓶液体。而如果要使用宝石，你至少需要购入一个附带宝石的商品，所以你最少的购入数量为 $\max(1, n-\sum b_i)$ 。

当 $\sum b_i=0$ 时，没办法兑换，所以全买。

否则，你至少得购入一个附带宝石的商品。你先挑选最便宜的那个。接下来，你再凑齐前面 $\max(1, n-\sum b_i)$ 个需要买的商品（也就是多买 $\max(1, n-\sum b_i)$ 个最便宜的商品）。这些购入之后，剩余的你可以不断用你获得的宝石去换附带宝石的商品，这样你就可以获得所有需要获得的宝石，换完所有商品。

综上，先找到 $b_i\gt 0$ 的 $a_i$ 的最小值，再找剩余元素的最小的若干个元素的数值之和。

时间复杂度为 $\mathcal{O}(n\log n)$ ，如果你用快速选择的话可以优化到 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    outs = []
    
    while True:
        n = II()
        if n == 0: break
        
        items = []
        
        for _ in range(n):
            w1, w2 = MII()
            items.append((w1, w2))
        
        must_buy = n - fmin(n - 1, sum(x[1] for x in items))
        
        items.sort()
        
        chosen = -1
        ans = 0
        
        for i in range(n):
            if items[i][1]:
                chosen = i
                must_buy -= 1
                ans += items[i][0]
                break
        
        for i in range(n):
            if must_buy and i != chosen:
                must_buy -= 1
                ans += items[i][0]
        
        outs.append(ans)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	while (true) {
		int n;
		cin >> n;

		if (!n) break;

		vector<pair<int, int>> items(n);
		int must_buy = n;

		for (auto &[a, b]: items) {
			cin >> a >> b;
			must_buy = max(must_buy - b, 1);
		}

		sort(items.begin(), items.end());

		int chosen = -1;
		long long ans = 0;

		for (int i = 0; i < n; i ++) {
			auto [a, b] = items[i];
			if (b) {
				chosen = i;
				must_buy --;
				ans += a;
				break;
			}
		}

		for (int i = 0; i < n; i ++) {
			auto [a, b] = items[i];
			if (must_buy && i != chosen) {
				must_buy --;
				ans += a;
			}
		}

		cout << ans << '\n';
	}

	return 0;
}
```
