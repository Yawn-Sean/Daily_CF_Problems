**提示 1：** 如果路径已经确定了，如何给 $w_i$ 分配数值最优？

**提示 2：** 基于可能的 $w_i$ 方案，给出最优化结果。

假设我们已经确定了我们选择的最短路的边集，我们应该如何分配边权呢？

分子是 $w_{i_1}+w_{i_2}+\dots+w_{i_x}$ ， $i_1\lt i_2\lt\dots\lt i_x$ ，分母是 $w_1+w_2+\dots+w_k$ 。

整个比值关于每一项 $w_i$ 都是单调的，无论其他元素取何值都是越大越好 / 越小越好——因此每个数值都取在边界上。

不妨令 $w_k=M$ ，则其它每个元素要么取趋于 $0$ 的数值，要么取 $M$ 。

因此，本质上等价于，对于边集的后缀，令其边权为固定值，其余边边权为 $0$ 。

这就是所有可能的边权分配了，因此，枚举非 $0$ 边权的出现数量，产生一个图，在这个图上跑最短路。这个图上总共只有两种边权 $0$ 和 $M$ ，于是可以用 01-BFS 完成。

时间复杂度为 $\mathcal{O}(m(n+m))$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, m = MII()
    
    us = []
    vs = []
    
    path = [[] for _ in range(n)]
    
    for eid in range(m):
        u, v = GMI()
        us.append(u)
        vs.append(v)
        path[u].append(eid)
        path[v].append(eid)
    
    dis = [n] * n
    que = [0] * (4 * n)
    ans = [n] * m
    
    for i in range(m):
        l = r = 2 * n
    
        dis[0] = 0
        que[l] = 0
        
        while l <= r:
            u = que[l]
            l += 1
            
            for eid in path[u]:
                v = us[eid] + vs[eid] - u
                if eid >= i: nd = dis[u] + 1
                else: nd = dis[u]
                
                if dis[v] > nd:
                    if eid >= i:
                        dis[v] = nd
                        r += 1
                        que[r] = v
                    else:
                        dis[v] = nd
                        l -= 1
                        que[l] = v
    
        for j in range(i, m):
            ans[j] = fmin(ans[j], dis[n - 1] / (j - i + 1))
    
        for u in range(n):
            dis[u] = n
    
    print('\n'.join(f'{x:.9f}' for x in ans))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, m;
	cin >> n >> m;

	vector<vector<pair<int, int>>> path(n);

	for (int i = 0; i < m; i ++) {
		int u, v;
		cin >> u >> v;
		u --, v --;
		path[u].emplace_back(i, v);
		path[v].emplace_back(i, u);
	}

	vector<long double> ans(m, n);

	for (int i = 0; i < m; i ++) {
		deque<int> que = {0};
		vector<int> dis(n, n);
		dis[0] = 0;

		while (!que.empty()) {
			int u = que.front(); que.pop_front();

			for (auto &[eid, v]: path[u]) {
				int nd = dis[u] + (eid >= i);

				if (dis[v] > nd) {
					dis[v] = nd;

					if (eid >= i) que.emplace_back(v);
					else que.emplace_front(v);
				}
			}
		}

		for (int j = i; j < m; j ++)
			ans[j] = min(ans[j], (long double)dis[n - 1] / (j - i + 1));
	}

	cout << fixed << setprecision(10);
	for (auto &x: ans) cout << x << '\n';

	return 0;
}
```
