**提示 1：** 如果我钦定了 $k$ 个长度为 $3$ 的回文串的位置，有多少种字母分配呢？

如果 $n\leq 2$ ， $k=0$ 才有答案，输出 $a^n$ 即可，否则输出 $0$ ，下面认为 $n\geq 3$ 。

如果我们选定了 $k$ 个长度为 $3$ 的回文串，则：

- 前两项可以任意选，方案数是 $a^2$ 。

- 接下来依次确定每个位置填什么字母。

    - 接下来的的位置中，如果某个位置是长度为 $3$ 的回文串的结尾，则这个位置只有 $1$ 种选法，这种情况出现 $k$ 次。

    - 否则，这个位置需要跟两个位置前的位置字母不相同，方案共 $a-1$ 种。

因此，总方案数是 $a^{n-k}$ 种。而回文串有 $C_{n-2}^k$ 种不同的选择，因此答案就是 $C_{n-2}^k\times a^{n-k}$ 。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, k, a = MII()
    mod = 998244353
    
    f = Factorial(n, mod)
    
    if n <= 2:
        if k > 0: print(0)
        else: print(pow(a, n, mod))
    else:
        print(a * a * f.combi(n - 2, k) % mod * pow(a - 1, n - 2 - k, mod) % mod)
```

C++ 做法如下——

```cpp []
long long quickPow(long long base, long long power, long long mod) {
	if (power == 0) return 1 % mod;
	long long cur = quickPow(base, power / 2, mod);
	return power & 1 ? base * cur % mod * cur % mod : cur * cur % mod; 
}

int factorial(int x, int mod) {
	int res = 1;
	for (int i = 1; i <= x; i ++) {
		res = 1ll * res * i % mod;
	}
	return res;
}

int ifactorial(int x, int mod) {
	return quickPow(factorial(x, mod), mod - 2, mod);
}

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, k, a, mod = 998244353;
	cin >> n >> k >> a;

	if (n == 1) {
		if (k) cout << 0;
		else cout << a;
	}
	else if (n == 2) {
		if (k) cout << 0;
		else cout << a * a;
	}
	else {
		if (k > n - 2) cout << 0;
		else cout << 1ll * a * a * factorial(n - 2, mod) % mod * ifactorial(k, mod) % mod * ifactorial(n - 2 - k, mod) % mod * quickPow(a - 1, n - 2 - k, mod) % mod;
	}

	return 0;
}
```
