**提示 1：** 如何统计 $X$ 以下有多少个满足条件的数。

直接算第 $x$ 个数是不方便的。所以考虑二分，如果我们能统计 $X$ 以下有多少个符合条件的数，我们只需找到这样的 $X$ 的最小值即可。

而这件事儿可以用容斥来做。先分别减去 $2^2,3^2,5^2,\dots$ 等质数的平方的倍数。

但至少有两个质数平方的因子的数会被多算，于是减掉 $(p_1p_2)^2$ 形式的数的倍数。

但三个质因子的又被多加了，于是应该减去。

类似地，得到多个质因子的情况，因子个数为奇数的情况下系数为负，否则为正。

而开根号后的范围在 $\sqrt{M}$ 量级，因此我们统计这个范围内每个元素的质因子个数——注意上面开根号后因子个数都是 $1$ ，所以一旦有一个因子有超过 $1$ 次，则这个数对应的系数为 $0$ 。

整体系数类似莫比乌斯反演那一套。

最后根据上述逻辑统计即可。如果有不清楚的细节可以看后面的代码。

时间复杂度为 $\mathcal{O}(\sqrt{M}\log M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    M = 200000
    
    is_prime = [1] * M
    is_prime[0] = 0
    is_prime[1] = 0
    
    miu = [1] * M
    
    for i in range(M):
        if is_prime[i]:
            for j in range(i, M, i):
                is_prime[j] = 0
                miu[j] *= -1
                
                if j // i % i == 0:
                    miu[j] = 0
    
    chosen = [i for i in range(1, M) if miu[i]]
    
    t = II()
    outs = []
    
    for _ in range(t):
        x = II()
        
        l, r = 1, 4 * 10 ** 10
        while l <= r:
            mid = (l + r) // 2
            
            cnt = 0
            
            for i in chosen:
                cnt += miu[i] * (mid // i // i)
            
            if cnt >= x: r = mid - 1
            else: l = mid + 1
        
        outs.append(l)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int M = 2e5;

	vector<int> is_prime(M, 1);
	is_prime[0] = 0, is_prime[1] = 0;

	vector<int> miu(M, 1);

	for (int i = 1; i <= M; i ++) {
		if (is_prime[i]) {
			for (int j = i; j <= M; j += i) {
				is_prime[j] = 0;
				miu[j] *= -1;
				if (j / i % i == 0) miu[j] = 0;
			}
		}
	}

	vector<int> chosen;
	for (int i = 1; i < M; i ++) if (miu[i]) chosen.emplace_back(i);

	int t;
	cin >> t;

	while (t --) {
		long long target;
		cin >> target;

		long long l = 1, r = 4e10;

		while (l <= r) {
			long long mid = (l + r) / 2, cnt = 0;
			for (auto &x: chosen) {
				cnt += miu[x] * (mid / x / x);
			}
			if (cnt >= target) r = mid - 1;
			else l = mid + 1;
 		}

		cout << l << '\n';
	}

	return 0;
}
```
