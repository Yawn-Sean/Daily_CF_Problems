**提示 1：** 依次确定每个元素是否要选。

首先 $1$ 或者 $-1$ 要不要选呢？直接只看 $k$ 是否是奇数就行。如果取了，从 $k$ 中去掉这个元素。

此时 $k$ 和剩余元素都是 $2$ 的倍数，同时除以 $2$ 不影响答案。

此时就可以判断原本是 $2$ 或者 $-2$ 的这个数要不要选了，只需看此时的 $k$ 是否是 $2$ 的倍数。

以此类推可以确定每一位要不要。最后所有元素遍历完了，只要 $k$ 仍然不是 $0$ 就输出 $-1$ ，否则输出方案即可。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n, k = MII()
        nums = [1 if c == '+' else -1 for c in I()]
        
        ans = []
        
        for i in range(n):
            if k % 2: k -= nums[i]; ans.append('#')
            else: ans.append('.')
            k //= 2
        
        outs.append(''.join(ans) if k == 0 else '-1')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n, k;
		cin >> n >> k;

		string s;
		cin >> s;

		string ans;
		for (auto &c: s) {
			if (k & 1) k -= (c == '+' ? 1 : -1), ans += '#';
			else ans += '.';
			k >>= 1;
		}

		cout << (k == 0 ? ans : "-1") << '\n';
	}

	return 0;
}
```
