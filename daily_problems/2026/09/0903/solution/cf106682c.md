**提示 1：** 博弈。考虑清楚状态和决策。

首先，你可以在两个数组的开头分别加上 $0$ ，这样初始状态就加入到问题中了。

接下来怎么办呢？

假设从 $i$ 开始的后缀， Alice 的最优结果为 $dp_a[i]$ ，Bob 的最优结果为 $dp_b[i]$ 。

则考虑从 $i-1$ 开始的后缀， Alice 有两种选择：

- 选择 $i$ 开始的后缀，结果为 $dp_a[i]$ ，

- 选择 $i-1$ ，此时 Bob 可以选择 $i$ 开始的后缀，如果选的话，结果是 $dp_b[i]$ ，Bob 在选不选之间做最小化的规划，因此此时结果是 $\min(A[i], dp_b[i])$ 。

- 注意第二种情况，如果 Bob 不选一个新的状态，则此时 Alice 可能进一步选 $i$ 开始的后缀吗？可以，但没必要，因为如果这样有利，就直接进入第一种状态了。

因此， $dp_a[i-1]=\max(dp_a[i], \min(A[i], dp_b[i]))$ 。

类似地 $dp_b[i-1]=\min(dp_b[i], \max(B[i], dp_a[i]))$ 。

不断更新到数组开头即可。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    v1 = [0] + LII()
    v2 = [0] + LII()

    w1, w2 = v1[n], v2[n]

    for i in range(n - 1, -1, -1):
        w1, w2 = fmax(w1, fmin(v1[i], w2)), fmin(w2, fmax(v2[i], w1))

    print(w1)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	vector<int> v1(n + 1, 0), v2(n + 1, 0);

	for (int i = 1; i <= n; i ++) cin >> v1[i];
	for (int i = 1; i <= n; i ++) cin >> v2[i];

	int w1 = v1[n], v2[n];

	for (int i = n - 1; i >= 0; i --) {
		int nw1 = max(w1, min(v1[i], w2)), nw2 = min(w2, max(v2[i], w1));
		w1 = nw1, w2 = nw2;
	}

	cout << w1;

	return 0;
}
```
