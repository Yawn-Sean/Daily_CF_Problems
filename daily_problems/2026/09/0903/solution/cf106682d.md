**提示 2：** 可以尝试简单证明一下。

本质上是最少用多少个货币可以凑齐 $n$ 的背包问题，但传统背包问题不可能给这么大数据范围，不妨猜测是直接从大往小贪心。

但即便是这样也不算好做：你没办法一个个做除法——效率太低了。

怎么办呢？除以 $11\dots 1$ 不好做，但是除以 $99\dots 9$ 就好办了：我们可以一个一个除。就先将整个数 $+1$ ，再减去 $10^k$ 就行了。

那怎么把 $11\dots 1$ 的问题转化为 $99\dots 9$ 的问题呢？整个数乘 $9$ 即可。

但这个结论为啥对呢？实际上可以用另一种理解了：

你先把整个数乘以 $9$ ，就等价于用一堆 $10^k-1$ 去凑 $9n$ 了。

这样，你就可以从小到大枚举答案：不断对整个数 $+1$ ，假设加了 $k$ 次，就看剩余元素能否用 $k$ 个 $10^i$ 形式的数的和表示。我们可以用数位和求个数的下界 $M$ ，同时拆掉一个 $10^i$ 变为 $10$ 个 $10^{i-1}$ 会新增 $9$ 个元素，因此 $k$ 需要满足条件 $k\geq M, (k-M)\bmod 9=0$ 。

这个模拟就完全有证明了，规避了前面的没证明的结论。

时间复杂度为 $\mathcal{O}(nB)$ ，其中 $B$ 表示每一位的最大数值，也就是 $9$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    s = [int(c) for c in I()]
    s.reverse()

    n = len(s)
    carry = 0

    for i in range(n):
        s[i] = s[i] * 9 + carry
        carry = s[i] // 10
        s[i] %= 10

    if carry: s.append(carry)
    s.append(0)

    n = len(s)
    ans = 0

    for i in range(n - 1, -1, -1):
        while s[i]:
            ans += 1
            s[0] += 1
            
            for j in range(n):
                if s[j] >= 10:
                    s[j + 1] += s[j] // 10
                    s[j] %= 10
                else:
                    break
            
            if s[i + 1] == 1: s[i + 1] -= 1
            else: s[i] -= 1

    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	string s;
	cin >> s;

	vector<int> vals;
	for (auto &c: s) vals.emplace_back(c - '0');

	reverse(vals.begin(), vals.end());

	int carry = 0;

	for (int i = 0; i < vals.size(); i ++) {
		vals[i] = vals[i] * 9 + carry;
		carry = vals[i] / 10;
		vals[i] %= 10;
	}

	vals.emplace_back(carry);
	vals.emplace_back(0);

	int ans = 0;

	for (int i = vals.size() - 1; i >= 0; i --) {
		while (vals[i]) {
			ans ++;
			vals[0] ++;

			for (int j = 0; j < vals.size(); j ++) {
				if (vals[j] > 9) vals[j] -= 10, vals[j + 1] ++;
				else break;
			}

			if (vals[i + 1]) vals[i + 1] --;
			else vals[i] --;
		}
	}

	cout << ans;

	return 0;
}
```
