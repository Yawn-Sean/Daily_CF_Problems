**提示 1：** 可以先猜一个。尝试证明一下。

我们相当于交换匹配后，距离的平方和单调不减。

为此肯定找尽可能远的点匹配，所以一个升序排列一个降序排列，再两两匹配。

为啥这样成立呢？因为我们相当于要最优化 $\sum(x_i-y_{p_i})^2=\sum x_i^2+\sum y_i^2-2\sum x_iy_{p_i}$ 。

前两项是常数，第三项根据排序不等式，应该逆向匹配。

时间复杂度 $\mathcal{O}(n^2)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        v1 = LII()
        v2 = LII()
        
        p1 = sorted(range(n), key=lambda x: v1[x])
        p2 = sorted(range(n), key=lambda x: -v2[x])
        
        ans = [0] * n
        
        for i in range(n):
            ans[p1[i]] = p2[i] + 1
        
        outs.append(' '.join(map(str, ans)))
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n;
		cin >> n;

		vector<int> v1(n), v2(n);
		for (auto &x: v1) cin >> x;
		for (auto &x: v2) cin >> x;

		vector<int> p1(n), p2(n);
		iota(p1.begin(), p1.end(), 0);
		iota(p2.begin(), p2.end(), 0);
		sort(p1.begin(), p1.end(), [&] (int i, int j) {return v1[i] < v1[j];});
		sort(p2.begin(), p2.end(), [&] (int i, int j) {return v2[i] < v2[j];});

		vector<int> p(n);
		for (int i = 0; i < n; i ++) p[p1[i]] = p2[n - 1 - i];

		for (int i = 0; i < n; i ++) cout << p[i] + 1 << " \n"[i == n - 1];
	}

	return 0;
}
```
