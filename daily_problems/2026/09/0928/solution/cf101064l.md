**提示 1：** 传统的背包 DP 咋做？

**提示 2：** 如何找到 $dp[S]$ 的子问题？

传统的 DP 直接求 $i$ 的重量内的最大成本为 $dp[i]$ ，枚举最后一次使用的物品是什么即可，即 $dp[i]=\max_j (dp[i-w_j]+c_j)$ 。

但这题 $S$ 特别大，那就得想办法变小，且变小的速度不能太慢。

所以可以考虑砍半，但 $dp[S/2]$ 不一定是最优的，怎么办呢？

考虑 $dp[S]=\max_i (dp[i]+dp[S-i])$ ，把你选择的物品排成一列，此时，中间 $S/2$ 附近一定存在一个商品刚用完的一个分界线。具体而言， $[S/2-500,S/2+500]$ 之间一定有一个商品刚用完，不然相当于跳过了 $1001$ 个整数的区间，这做不到。

因此，我们将 $S$ 的问题转化为 $[S/2-500,S/2+500]$ 的问题，就这样递归 $\mathcal{O}(\log S)$ 层就能来到足够小的数据范围，再利用前面我们预处理的 DP 就能解决问题。

为啥这样不会有一层的区间太长呢？我们可以证明，区间长度最多变成原本区间长度的 $\frac{1}{2}$ 再加 $1000$ ，因此，可以用数学归纳法证明每层区间的长度都不超过 $2000$ 。

时间复杂度为 $\mathcal{O}(M^2\log S)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, S = MII()
    
    dp = [0] * 2001
    
    for _ in range(n):
        w, c = MII()
        for i in range(w, 2001):
            dp[i] = fmax(dp[i], dp[i - w] + c)
    
    def f(l, r):
        if r <= 2000: return dp[l:r + 1]
        
        nl = fmax(l // 2 - 500, 0)
        nr = r // 2 + 500
        
        v = f(nl, nr)
        ans = [0] * (r - l + 1)
        
        for i in range(nl, nr + 1):
            for j in range(i, nr + 1):
                if l <= i + j <= r:
                    ans[i + j - l] = fmax(ans[i + j - l], v[i - nl] + v[j - nl])
        
        return ans
    
    print(f(S, S)[0])
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n, S;
	cin >> n >> S;

	vector<long long> dp(2001, 0);
	
	while (n --) {
		int w, c;
		cin >> w >> c;

		for (int i = w; i <= 2000; i ++)
			dp[i] = max(dp[i], dp[i - w] + c);
	}

	auto dfs = [&] (auto &self, int l, int r) -> vector<long long> {
		if (r <= 2000)
			return vector<long long>(dp.begin() + l, dp.begin() + r + 1);

		int nl = max(l / 2 - 500, 0);
		int nr = r / 2 + 500;

		auto v = self(self, nl, nr);

		vector<long long> ans(r - l + 1, 0);

		for (int i = nl; i <= nr; i ++) {
			for (int j = i; j <= nr; j ++) {
				if (i + j >= l && i + j <= r) {
					ans[i + j - l] = max(ans[i + j - l], v[i - nl] + v[j - nl]);
				}
			}
		}

		return ans;
	};

	cout << dfs(dfs, S, S)[0];

	return 0;
}
```
