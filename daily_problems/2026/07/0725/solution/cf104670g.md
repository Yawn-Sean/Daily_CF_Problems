**提示 1：** 并非几何题。精度要求低，数据范围小。

先看提示。

我们不用任何几何知识。

我们在 $-10\leq x\leq 20,-10\leq x\leq 20$ 的范围内进行随机采样，则其在图形内的概率是面积 / 900 。

所以我们采样足够多次时，频率可以用于估计概率，也就是类似蒙特卡洛的方法估计面积。

具体需要多少次，可以使用中心极限定理推一下，用正态分布进行最后估计。

### 具体代码如下——

```Python []
        for i in range(n):
            vx = xs[i]
            vy = ys[i]
            r = rs[i]

                freq += 1
                break
    
    print(freq / total * 900)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int n;
	cin >> n;

	vector<array<int, 3>> circles(n);
	for (auto &[x, y, r]: circles) cin >> x >> y >> r;

	auto start = chrono::steady_clock::now();

	int freq = 0, total = 0;

	auto random_value = [&] () -> long double {
		auto val = rngl();
		long double ret = (long double)val / (1ull << 63) / 2;
		return ret;
	};

	while (true) {
		auto now = chrono::steady_clock::now();
		if (chrono::duration<double>(now - start).count() >= 2.5) break;

		double x = random_value() * 30 - 10;
		double y = random_value() * 30 - 10;
		total++;

		for (auto &[vx, vy, r]: circles) {
			if ((x - vx) * (x - vx) + (y - vy) * (y - vy) <= r * r) {
				freq ++; 
				break;
			}
		}
	}

	cout << fixed << setprecision(15) << (long double)freq / total * 900;

	return 0;
}
```
