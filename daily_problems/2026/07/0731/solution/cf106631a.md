**提示 1：** 找到一个策略。什么时候 Bob 必胜？剩余情况 Alice 可以赢吗？

首先，Bob 选择的那个字符不能是 Alice 的第一个字符，不然 Alice 直接选自己的字符串就行。

而 Bob 选择的字符串的第一个字符也必须和 Alice 的字符串的第一个字符不相同，否则 Alice 只需在第一个字符后加上自己的字符串就已经赢了。

此时 Alice 策略如何呢？我们这里为了简单，假设 Alice 选的是 H 开头的， Bob 选的是 T 开头的。

Alice 下一个不如放自己的开头字符，因为放 Bob 的开头字符没有用， Bob 可以把这个位置当作自己放的。

这样，如果 Bob 选择的字符串不是 T + $n-1$ 个 H ，Alice 总是可以选择构造 T + $n-1$ 个 H + 自己的字符串从第二位开始，这样总是 Alice 自己的字符串先出现。

所以 Bob 只能选择 T + $n-1$ 个 H 。

而如果 Alice 的字符串开头是 $n-1$ 个 H ，Alice 赢不了，因为在第一次 $n-1$ 个 H 出现前，一定是一个字符 T ，也就是说 Bob 的字符串出现了，而 Alice 的字符串此时还没出现。

否则，直接输出 T + Alice 的字符串 Alice 就赢了。

综上，Bob 能赢当且仅当前 $n-1$ 个字符相同。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        s = I()
        
        flg = True
        for i in range(n - 1):
            if s[i] != s[0]:
                flg = False
        
        outs.append('Bob' if flg else 'Alice')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n; string s;
		cin >> n >> s;

		bool flg = true;
		for (int i = 0; i < n - 1; i ++) {
			if (s[i] != s[0]) {
				flg = false;
			}
		}

		cout << (flg ? "Bob" : "Alice") << '\n';
	}

	return 0;
}
```
