**提示 1：** 先找到基准，再在基准上做事。

开头的时候，你显然可以查 MUL 1 ，得到 $a,b$ 的最小公倍数 $l$ 。这一步的好处是你可以得到一个跟初始状态最相关的信息。

为了让下次查询获得独立于这个最小公倍数的信息，我们进行 MUL $l$ 的查询，此时的最小公倍数应该是 $l\times a$ （同时这个数字也不会越界），所以可以得到 $a$ 。

最后，我们要确认 $b$ 的取值，也就是把 $a$ 变成无关变量，即 $1$ ，于是查询 DIV $l\times a$ ，这样查询结果就是 $b$ 了。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    
    for _ in range(t):
        print('MUL', 1, flush=True)
        lcm_val = II()
        print('MUL', lcm_val, flush=True)
        lcm_val_a = II()
        a = lcm_val_a // lcm_val
        print('DIV', lcm_val_a, flush=True)
        b = II()
        print('ANS', a, b, flush=True)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int lcm_val, lcm_val_a, a, b;
		cout << "MUL " << 1 << endl;
		cin >> lcm_val;
		cout << "MUL " << lcm_val << endl;
		cin >> lcm_val_a;
		a = lcm_val_a / lcm_val;
		cout << "DIV " << lcm_val_a << endl;
		cin >> b;
		cout << "ANS " << a << ' ' << b << endl;
	}

	return 0;
}
```
