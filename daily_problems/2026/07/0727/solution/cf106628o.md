**提示 1：** 用相近的查询推出一些东西。

如果我们的查询太没有章法，显然就很不好做了。

考虑查询长度为 $2,3,\dots, n$ 的前缀，这样次数恰好满足要求。

我们可以用 $n,n-1$ 的查询，得到最后一项比前面的多少项小，也就确认了最后一项到底是啥，也可以在备选数字中去掉它。

于是问题转化为 $n-1$ 的子问题，如此不断确定第 $i$ 项是前 $i$ 项中第几大的，也就能确定其取值了。

时间复杂度为 $\mathcal{O}(n^2)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    def query(idxs):
        print('?', len(idxs), *idxs, flush=True)
        return II()
    
    def answer(p):
        print('!', *p, flush=True)
    
    t = II()
    
    for _ in range(t):
        n = II()
        cur = 0
        
        ans = [0] * n
        ans[0] = 1
        
        for i in range(2, n + 1):
            ncur = query(list(range(1, i + 1)))
            val = i - (ncur - cur)
            
            for j in range(i):
                if ans[j] >= val:
                    ans[j] += 1
            ans[i - 1] = val
            
            cur = ncur
    
        answer(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t;
	cin >> t;

	while (t --) {
		int n;
		cin >> n;

		long long cur = 0;
		vector<int> ans(n, 0);

		ans[0] = 1;

		for (int i = 2; i <= n; i ++) {
			cout << "? " << i;
			for (int j = 1; j <= i; j ++) cout << ' ' << j;
			cout << endl;

			long long ncur;
			cin >> ncur;

			int v = i - (ncur - cur);

			for (int j = 0; j < i; j ++) {
				if (ans[j] >= v) {
					ans[j] ++;
				}
			}
			ans[i - 1] = v;

			cur = ncur;
		}

		cout << "!";
		for (auto &x: ans) cout << ' ' << x;
		cout << endl;
	}

	return 0;
}
```
