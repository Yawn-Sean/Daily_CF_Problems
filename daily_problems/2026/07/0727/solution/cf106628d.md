**提示 1：** 先考虑固定的 $k$ 个数如何求解。剩下的好像很好办。

如果有固定的 $k$ 个数，MST 边权和怎么求呢？

$LSB(|a_u-a_v|)$ 也就是 $a_u, a_v$ 最低的不同的位。

如果这 $k$ 个数的最低的 $i$ 位都相同，则 $LSB$ 肯定取不到那个位。

所以 $LSB(|a_u-a_v|)$ 最小只能取到最小的有不同的位，设为 $x$ 。

而我们根据这一位把数字分为两类，则两类间的边边权都是 $x$ 。

而这些 $x$ 边权的边已经能形成一个连通图了，因此 MST 的边权和是 $(k-1)x$ 。

所以综上，我们只需找到一个 $k$ 元子集，使得其最低的不同的位尽可能高。

我们可以二分这一个位 $x$ ，这样我们只需统计更低的位的各种数字的出现频率，看是否有不小于 $k$ 的，如果有， $x$ 就是可行的了。

时间复杂度为 $\mathcal{O}(n\log\log M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    rnd = random.getrandbits(30)
    
    for _ in range(t):
        n, k = MII()
        nums = LII()
        
        l = 0
        r = 29
        
        while l <= r:
            mid = (l + r) // 2
            
            msk = (1 << mid) - 1
            cnt = Counter()
            
            for x in nums:
                cnt[(x & msk) ^ rnd] += 1
            
            if max(cnt.values()) >= k: l = mid + 1
            else: r = mid - 1
        
        outs.append((k - 1) << r)
        
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t, rnd = rng();
	cin >> t;

	while (t --) {
		int n, k;
		cin >> n >> k;

		vector<int> nums(n);
		for (auto &v: nums) cin >> v;

		int l = 0, r = 29;

		while (l <= r) {
			int mid = (l + r) / 2;

			int msk = (1 << mid) - 1;
			unordered_map<int, int> cnt;

			for (auto &v: nums)
				cnt[(v & msk) ^ rnd] ++;
			
			int max_cnt = 0;
			for (auto &[k, v]: cnt) max_cnt = max(max_cnt, v);

			if (max_cnt >= k) l = mid + 1;
			else r = mid - 1;
		}

		cout << ((long long)(k - 1) << r) << '\n';
	}

	return 0;
}
```
