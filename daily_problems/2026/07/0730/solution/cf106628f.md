**提示 1：** 考虑记录第 $i$ 个位置作为子序列最后一个位置的所有子序列，我们需要存哪些东西？

**提示 2：** 如何用前面的结果推第 $i+1$ 个位置的结果？

考虑记录第 $i$ 个位置结尾的子序列，我们显然最多只需要记录其中权值最大的 $k$ 个子序列。

对于第 $i+1$ 个位置的，应该如何处理呢？

相当于对于第 $idx$ 个序列整体加上 $\mathrm{gcd}(a_{idx},a_{i+1})$ ，最后我需要知道整体的前 $k$ 大的结果。

这件事可以用 $k$ 个序列的归并完成。每个序列我们先取最大的元素，然后再用堆不断取出其中最大元素，取 $k$ 次。取完一个元素后，将对应序列的下一个元素加入到堆中即可。

最后，如果序列长度不到 $k$ ，再在序列末尾加上一个 $0$ ，表示只包含第 $i+1$ 个元素的序列。

最后的最后，把所有 $nk$ 个元素考虑进来，取其中的第 $k$ 大即可。

时间复杂度为 $\mathcal{O}(nk\log k)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n, k = MII()
        nums = LII()
        
        cur = [[] for _ in range(n)]
        pts = [0] * n
        
        def msk(x, y): return x * n + y
        
        for i in range(n):
            pq = [msk(-(cur[j][0] + math.gcd(nums[j], nums[i])), j) for j in range(i)]
            heapify(pq)
            
            for _ in range(k):
                if pq:
                    x, y = divmod(heappop(pq), n)
                    cur[i].append(-x)
                    pts[y] += 1
                    
                    if pts[y] < len(cur[y]):
                        heappush(pq, msk(-(cur[y][pts[y]] + math.gcd(nums[y], nums[i])), y))
            
            if len(cur[i]) < k: cur[i].append(0)
            
            for idx in range(i): pts[idx] = 0
        
        total_pq = []
        for x in cur:
            for y in x:
                heappush(total_pq, y)
                if len(total_pq) > k: heappop(total_pq)
        
        if len(total_pq) < k: outs.append(0)
        else: outs.append(total_pq[0])
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

	int t, inf = 1e9;
	cin >> t;

	while (t --) {
		int n, k;
		cin >> n >> k;

		vector<int> nums(n);
		for (auto &x: nums) cin >> x;

		vector<vector<long long>> cur(n);
		vector<int> pts(n, 0);

		for (int i = 0; i < n; i ++) {
			priority_queue<pair<long long, int>> pq;
	
			for (int j = 0; j < i; j ++)
				pq.push({cur[j][0] + gcd(nums[j], nums[i]), j});
			
			for (int j = 0; j < k; j ++) {
				if (!pq.empty()) {
					auto [x, y] = pq.top(); pq.pop();
					cur[i].emplace_back(x);
					pts[y] ++;

					if (pts[y] < cur[y].size())
						pq.push({cur[y][pts[y]] + gcd(nums[y], nums[i]), y});
				}
			}

			if (cur[i].size() < k) cur[i].emplace_back(0);

			for (int j = 0; j < i; j ++) pts[j] = 0;
		}

		{
			priority_queue<long long, vector<long long>, greater<long long>> pq;
			for (auto &x: cur) {
				for (auto &y: x) {
					pq.push(y);
					if (pq.size() > k) pq.pop();
				}
			}

			if (pq.size() < k) cout << 0 << '\n';
			else cout << pq.top() << '\n';
		}
	}

	return 0;
}
```
