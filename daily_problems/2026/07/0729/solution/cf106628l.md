**提示 1：** 如何检查一个 $k+1$ 元子集是否满足要求？

**提示 2：** 提取一些公共的部分。

我们先看如何判断一个 $k+1$ 元子集是否满足要求。

设 $f(i)$ 是满足除了第 $i$ 个数据点外所有点的 $k$ 次多项式。

则用拉格朗日插值，有：

$$
f(i)=\sum\limits_{j=1,2,\dots,k+2; j\neq i}y_j\frac{\prod\limits_{v=1,2,\dots,k+2;v\neq i,j}(x-x_v)}{\prod\limits_{v=1,2,\dots,k+2;v\neq i,j}(x_j-x_v)}
$$

而要满足题目要求，这得是一个 $k-1$ 次多项式，所以我们要求最高次项系数为 $0$ ，即：

$$
0=\sum\limits_{j=1,2,\dots,k+2; j\neq i}y_j\frac{1}{\prod\limits_{v=1,2,\dots,k+2;v\neq i,j}(x_j-x_v)}
$$

直接暴力算每一个数，时间复杂度会达到 $\mathcal{O}(k^3)$ ，并不符合要求。但是上述乘积实际上很多部分是重复的。我们可以将其转化为：

$$
0=\sum\limits_{j=1,2,\dots,k+2; j\neq i}(x_j-x_i)\frac{y_j}{\prod\limits_{v=1,2,\dots,k+2;v\neq j}(x_j-x_v)}
$$

于是，我们先预处理，计算所有 $\frac{y_j}{\prod\limits_{v=1,2,\dots,k+2;v\neq j}(x_j-x_v)}$ ，分别计算分子分母，再用逆元求出这个数值。这样预处理复杂度是 $\mathcal{O}(k^2)$ 的。

接下来，枚举 $i$ ，看上面那个等式是否成立，这件事是 $\mathcal{O}(k^2)$ 的。

如果成立，我们只需求 $f(i)$ 在 $x=0$ 位置的取值，即

$$
\sum\limits_{j=1,2,\dots,k+2; j\neq i}y_j\frac{\prod\limits_{v=1,2,\dots,k+2;v\neq i,j}(0-x_v)}{\prod\limits_{v=1,2,\dots,k+2;v\neq i,j}(x_j-x_v)}
$$

每一项都可以求分子分母，再逆元组合，最后 $\mathcal{O}(k)$ 求出，最后加总起来即可。

时间复杂度为 $\mathcal{O}(k^2)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        s = I()
        n = len(s)
        
        z = z_algorithm(s)
        rev_z = z_algorithm(s[::-1])
        rev_z.reverse()
        
        ans = 0
        
        for i in range(n - 1, 1, -1):
            x = fmin(i - 1, z[i])
            y = fmin(n - i, rev_z[i - 1])
            y = fmin(i - 1, y)
            ans += fmax(0, x + y - i + 1)
        
        outs.append(ans)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

    int t;
    cin >> t;

    while (t --) {
        string s;
        cin >> s;

        int n = s.size();

        auto z = z_algorithm(s);
        reverse(s.begin(), s.end());
        auto rev_z = z_algorithm(s);
        reverse(rev_z.begin(), rev_z.end());

        long long ans = 0;
        for (int i = n - 1; i > 0; i --) {
            int x = min(i - 1, z[i]), y = min({i - 1, n - i, rev_z[i - 1]});
            ans += max(0, x + y - i + 1);
        }
        cout << ans << '\n';
    }

	return 0;
}
```
