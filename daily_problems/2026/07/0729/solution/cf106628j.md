**提示 1：** $A,B$ 的条件都是基于 $C$ 的，所以枚举 $C$ 。

**提示 2：** 对于某个 $C$ ，如何看哪些 $A,B$ 是合法的？

枚举 $C$ 。设 $s=D+C$ ，则 $D=A+B$ 。

接下来 $A$ 的最大长度如何呢？也就是 $C$ 和 $s$ 的最长公共前缀的长度和 $D$ 的长度 $-1$ 取最小值。这件事可以用 z 函数直接得到。

$B$ 的最大长度如何呢？就是 $D$ 和 $s$ 的最长公共真后缀（也就是不能等于 $D$ ）的长度。可以将 $s$ 反转后，转化为 $D',s'$ 的最长公共前缀，也可以用 $z$ 函数直接得到。

接下来就相当于选定 $A,B$ 的长度使得其总长等于 $D$ 的长度。 $A,B$ 的长度区间都有了，这个数量也就很好求了。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        s = I()
        n = len(s)
        
        z = z_algorithm(s)
        rev_z = z_algorithm(s[::-1])
        rev_z.reverse()
        
        ans = 0
        
        for i in range(n - 1, 1, -1):
            x = fmin(i - 1, z[i])
            y = fmin(n - i, rev_z[i - 1])
            y = fmin(i - 1, y)
            ans += fmax(0, x + y - i + 1)
        
        outs.append(ans)
    
    print('\n'.join(map(str, outs)))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);

    int t;
    cin >> t;

    while (t --) {
        string s;
        cin >> s;

        int n = s.size();

        auto z = z_algorithm(s);
        reverse(s.begin(), s.end());
        auto rev_z = z_algorithm(s);
        reverse(rev_z.begin(), rev_z.end());

        long long ans = 0;
        for (int i = n - 1; i > 0; i --) {
            int x = min(i - 1, z[i]), y = min({i - 1, n - i, rev_z[i - 1]});
            ans += max(0, x + y - i + 1);
        }
        cout << ans << '\n';
    }

	return 0;
}
```
