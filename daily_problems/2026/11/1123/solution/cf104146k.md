**提示 1：** 如果可以任选位置交换，怎么做？

**提示 2：** 转化为上面的问题。

如果只是交换且可以选任何位置，那你只需每一轮执行一次往后的冒泡排序即可。总共进行 $n-1$ 轮。

对于每一轮，为了执行交换操作，你可以旋转数组，那就相当于把要交换的位置往前挪到你可以操作的地方。

于是边旋转边操作即可。最后记得恢复位置。

操作次数是 $\mathcal{O}(n^2)$ 的。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n = II()
    nums = LII()
    
    ans = []
    
    for _ in range(n - 1):
        for i in range(n - 1):
            if nums[i] > nums[i + 1]:
                nums[i], nums[i + 1] = nums[i + 1], nums[i]
                ans.append('S')
            ans.append('P')
        ans.append('P')
    
    print(''.join(ans))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	vector<int> nums(n);
	for (auto &x: nums) cin >> x;

	for (int i = 0; i < n - 1; i ++) {
		for (int j = 0; j < n - 1; j ++) {
			if (nums[j] > nums[j + 1]) {
				swap(nums[j], nums[j + 1]);
				cout << 'S';
			}
			cout << 'P';
		}
		cout << 'P';
	}

	return 0;
}
```
