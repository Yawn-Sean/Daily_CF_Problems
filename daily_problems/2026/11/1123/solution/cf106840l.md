**提示 2：** 拆分为若干部分，计算三角形的面积。

首先 $a=b$ 时只会越走越远。

$a\lt b$ 时，考虑从第二步起，整个流程跟 $a,b$ 交换后的结果是对称的。所以不妨设 $a\gt b$ 。

此时图形一定是个 $n$ 角星。关键就在于求出 $n$ 。

考虑把凹进去的点连起来，我们只需求出每个内角的度数即可。

每个内角加上两侧等腰三角形的底角是 $180+b$ 度，而两个底角之和等于外角 $a$ ，因此砍掉外侧的等腰三角形后的正 $n$ 边形内角度数是 $180+b-a$ ，外角是 $a-b$ ，因此边数是 $\frac{360}{a-b}$ 。

而外侧的等腰三角形的面积因为知道腰和腰间的夹角，很容易求出。内侧多边形的底边可以先求，然后用多边形中心点向多边形各个顶点连边，形成的三角形的面积是好求的——因为你知道底边和等腰三角形每个角的度数。

综上，每个成分都好求，问题解决。

时间复杂度为 $\mathcal{O}(1)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    t = II()
    outs = []
    
    for _ in range(t):
        a, b = MII()
        
        if a < b: a, b = b, a
        
        if a == b: outs.append('-1')
        elif 360 % (a - b): outs.append('-1')
        else:
            n = 360 // (a - b)
            
            area = 0
            area += math.sin(a / 180 * math.pi) / 2
            area += math.cos(a / 2 / 180 * math.pi) ** 2 / math.tan(math.pi / n)
            area *= n
            
            outs.append(f'{area:.10f}')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int t;
	cin >> t;

	long double pi = acosl(-1);
	cout << fixed << setprecision(15);

	while (t --) {
		int a, b;
		cin >> a >> b;
		if (a < b) swap(a, b);

		if (a == b || 360 % (a - b)) cout << -1 << '\n';
		else {
			int n = 360 / (a - b);
			long double area = 0;
			area += sinl(pi * a / 180) / 2;
			area += cosl(pi * a / 2 / 180) * cosl(pi * a / 2 / 180) / tanl(pi / n);
			cout << area * n << '\n';
		}
	}

	return 0;
}
```
