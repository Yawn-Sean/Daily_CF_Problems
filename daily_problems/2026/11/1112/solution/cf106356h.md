**提示 1：** $u,v$ 需要满足什么条件？

**提示 2：** 如何预处理一个 “图” ？

首先 $a_u,a_v$ 的最高位不能相同，不然异或起来一定比两者的最小值小。

考虑更小的那个数 $a_u$ ，则 $a_v$ 在 $a_u$ 的最高位一定为 $1$ ，否则异或起来比 $a_v$ 大。而这两件事都成立就足够了。

接下来考虑最长路——假设最后一项为 $x$ 的最大序列长度为 $dp[x]$，实则我们只在乎 $x$ 的最高位，这样下一个选的数只需最高位更高且包含这个位就行。

所以综上，我们只需分最高位 DP 最长序列长度，并且预处理所有可能的转移即可（即从某个数的其它位转移到最高位）。这个 DP 很容易。

时间复杂度为 $\mathcal{O}(n\log M+\log^2 M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        nums = LII()
        
        path = [[0] * 61 for _ in range(61)]
        
        vis = [0] * 61
        dp = [1] * 61
        
        for x in nums:
            if x:
                k = x.bit_length() - 1
                vis[k] = 1
        
        for x in nums:
            k = x.bit_length() - 1
            for j in range(k):
                if x >> j & 1 and vis[j]:
                    path[j][k] = 1
        
        for i in range(61):
            for j in range(61):
                if path[i][j]:
                    dp[j] = fmax(dp[j], dp[i] + 1)
        
        outs.append(f'{max(dp)}')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int t;
	cin >> t;

	while (t --) {
		int n;
		cin >> n;

		vector<long long> nums(n);
		for (auto &x: nums) cin >> x;

		vector<vector<int>> path(61, vector<int>(61, 0));
		vector<int> vis(61, 0), dp(61, 1);

		for (auto &x: nums) {
			if (x) {
				int k = 63 - __builtin_clzll(x);
				vis[k] = 1;
			}
		}

		for (auto &x: nums) {
			if (x) {
				int k = 63 - __builtin_clzll(x);
				for (int i = 0; i < k; i ++) {
					if ((x >> i & 1) && vis[i]) {
						path[i][k] = 1;
					}
				}
			}
		}

		for (int i = 0; i <= 60; i ++) {
			for (int j = 0; j <= 60; j ++) {
				if (path[i][j]) {
					dp[j] = max(dp[j], dp[i] + path[i][j]);
				}
			}
		}

		cout << *max_element(dp.begin(), dp.end()) << '\n';
	}

	return 0;
}
```
