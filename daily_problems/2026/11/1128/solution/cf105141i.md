**提示 1：** 对于每个队伍，你的题需要满足什么要求？

首先，你不能把自己也放飞了，所以你的题有一个难度上界。

我们根据当前情况可以求出你自己做对了多少个题（因为你必然做对了自己的题）。不妨设为 $x$ 。

考虑别的目前还没被放飞的队伍。

如果他们过题数不超过 $x-2$ ，则已经必胜了，无需处理。

如果他们过题数已经达到了 $x$ ，那么就不得不放飞他们了，就可以给出一个上下界——下界是他们得飞起来，上界是他们得做出来。

如果他们过题数恰好是 $x-1$ ，则可以有两种选择：

- 让他们做不出这个题，也就是不小于他们的能力 $+1$ 。

- 让他们飞起来，这也可以提供一个下界。

因为两个条件只需满足一个就行，所以取最小值即可作为下界即可。

时间复杂度为 $\mathcal{O}(n+M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n, s0, w0 = MII()
    
    M = 10 ** 5
    total = [0] * (M + 1)
    cnt = [0] * (M + 1)
    
    ss = []
    ws = []
    ds = []
    
    for _ in range(n):
        s, w, d = MII()
        ss.append(s)
        ws.append(w)
        ds.append(d)
        
        total[d] += d
        cnt[d] += 1
    
    for i in range(1, M + 1):
        total[i] += total[i - 1]
        cnt[i] += cnt[i - 1]
    
    cnt0 = cnt[s0] + 1
    l, r = 1, w0 - total[s0]
    
    for i in range(n):
        cur = total[ss[i]]
        cur_cnt = cnt[ss[i]]
        
        if ds[i] > ss[i]:
            cur += ds[i]
            cur_cnt += 1
        
        if ws[i] >= cur:
            if cur_cnt >= cnt0:
                l = fmax(ws[i] - cur + 1, l)
                r = fmin(r, ss[i])
    
            elif cur_cnt == cnt0 - 1:
                l = fmax(l, fmin(ws[i] - cur + 1, ss[i] + 1))
    
    print('Yes' if l <= r else 'No')
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n, s0, w0;
	cin >> n >> s0 >> w0;

	int M = 1e5;

	vector<long long> total(M + 1, 0);
	vector<int> cnt(M + 1, 0);

	vector<array<int, 3>> teams(n);
	for (auto &[s, w, d]: teams) {
		cin >> s >> w >> d;
		total[d] += d;
		cnt[d] ++;
	}

	for (int i = 1; i <= M; i ++) {
		total[i] += total[i - 1];
		cnt[i] += cnt[i - 1];
	}

	int cnt0 = cnt[s0] + 1;
	long long l = 1, r = w0 - total[s0];

	for (auto &[s, w, d]: teams) {
		auto cur = total[s];
		auto cur_cnt = cnt[s];

		if (d > s) {
			cur += d;
			cur_cnt ++;
		}

		if (w >= cur) {
			if (cur_cnt >= cnt0) {
				l = max(l, w - cur + 1);
				r = min(r, (long long)s);
			}
			else if (cur_cnt == cnt0 - 1) {
				l = max(l, min(w - cur + 1, (long long)s + 1));
			}
		}
	}

	cout << (l <= r ? "Yes" : "No");

	return 0;
}
```
