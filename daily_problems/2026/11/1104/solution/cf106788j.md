**提示 1：** 想个办法，统一处理最便宜的 $k$ 条边。

其实有点不好想到。

那些便宜的边实际上变成等价的了，所以应当被同等看待。同时如果这些边取 $0$ ，其他边仍然取 $w_i$ ，在最短路中实际上不可比。

所以考虑第 $k+1$ 长的边为 $W$ ，则我们将这些边取 $\max(w_i,W)$ ，则在新图中求最短路。这样的好处在，把不同最短路的边权和变得可比，同时用这个数值减去 $kW$ 可以得到原始状况下的最短路。

接下来我们说明这个转化是对的。

首先，真正的去掉 $k$ 条最短边的最短路一定会在上面被枚举到，因为其中第 $k / k+1$ 条边被枚举时，得到的答案就包含了这一个。

同时，上述过程得到的答案一定不小于最短路。因为如果一条路径

- 有小于 $k$ 条边边权小于 $W$ ，则更大的 $W$ 可以得到更小的总权值，因为可以让更多的边被省下来。

- 有大于 $k$ 条边边权小于 $W$ ，则更小的 $W$ 可以得到更小的权值，因为第 $k+1$ 及往后的边，实际计入答案的部分 $W$ 偏大了。

本质上是一个递增序列，我们取 $\sum\max(a_i, W)-kW$ 这个函数，可以保证在 $W$ 等于第 $k$ 大的数时整个序列数值最小化，且最小化结果是第 $k+1$ 项往后的所有项的和。

注意在最短路长度不超过 $k$ 时，上面算法可能算出负数，此时输出 $0$ 即可。

时间复杂度为 $\mathcal{O}(m(n+m\log n))$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n, m, k = MII()
    inf = 10 ** 9
    
    path = [[] for _ in range(n)]
    ws = []
    
    for _ in range(m):
        u, v, w = MII()
        path[u].append(w * n + v)
        ws.append(w)
    
    ans = inf
    
    for w0 in ws:
        dis = [inf] * n
        dis[0] = 0
        
        pq = [0]
        while pq:
            d, u = divmod(heappop(pq), n)
            
            if dis[u] == d:
                for msk in path[u]:
                    w, v = divmod(msk, n)
                    nd = d + fmax(w, w0)
                    
                    if nd < dis[v]:
                        dis[v] = nd
                        heappush(pq, dis[v] * n + v)
        
        ans = fmin(ans, dis[n - 1] - w0 * k)
    
    print(fmax(ans, 0))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n, m, k, inf = 1e9;
	cin >> n >> m >> k;

	vector<vector<pair<int, int>>> path(n);
	vector<int> ws;

	while (m --) {
		int u, v, w;
		cin >> u >> v >> w;
		path[u].emplace_back(v, w);
		ws.emplace_back(w);
	}

	int ans = inf;

	for (auto &w0: ws) {
		vector<int> dis(n, inf);
		dis[0] = 0;

		priority_queue<pair<int, int>> pq;
		pq.push({0, 0});

		while (!pq.empty()) {
			auto [d, u] = pq.top(); pq.pop();
			d = -d;

			if (dis[u] == d) {
				for (auto &[v, w]: path[u]) {
					int nd = d + max(w, w0);
					if (dis[v] > nd) {
						dis[v] = nd;
						pq.push({-dis[v], v});
					}
				}
			}
		}

		ans = min(ans, dis[n - 1] - w0 * k);
	}

	cout << max(ans, 0);

	return 0;
}
```
