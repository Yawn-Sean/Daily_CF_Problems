**提示 1：** 根据距 $1$ 的距离分层，假设每层的点数一致，则最多的最短路数量是多少？

**提示 2：** 如何分配每层点数。

先看提示 1 。

假设每一层的点数分别是 $c_0,c_1,c_2,\dots,c_k$ ，其中 $c_0=1$ ，因为只有 $1$ 这么一个结点。

接下来，假设 $1,n$ 的距离为 $v$ ，则考虑从 $1$ 到 $n$ 一步步走最短路，第一步最多有 $c_1$ 种选择，第二步最多有 $c_2$ 种选择，……，第 $v-1$ 步有 $c_{v-1}$ 种选择，第 $v$ 步走到 $n$ 一种选择。

（不能走到别的层——首先不能从第 $x$ 层走到 $x+k\ (k\geq 2)$ 层，不然分层就矛盾了；也不能走到 $x-k\ (k\geq 0)$ 层，不然就没法最短路走到 $n$ 了——可以根据分号前面的那段推。）

所以最短路的总方案数最多是 $c_1c_2\dots c_{v-1}$ 。且这是可以取到的，只需相邻两层的任意两个点都连边即可。

所以我们要求 $c_1c_2\dots c_{v-1}$ 的最大值，且 $c_1+c_2+\dots+c_{v-1} =n-2$ ，所以就相当于把 $n-2$ 拆成若干个数，使得乘积最大化。

最优选择是拆成尽可能多的 $3$ 。

- $n-2$ 是 $3$ 的倍数时，直接拆。

- $n-2$ 除以 $3$ 模 $1$ 时，先拆两个 $2$ ，剩下用 $3$ 。特别的，如果是 $1$ ，需要直接输出 $1$ 。

- $n-2$ 除以 $3$ 模 $1$ 时，先拆一个 $2$ ，剩下用 $3$ 。

这里需要使用快速幂。

时间复杂度为 $\mathcal{O}(\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n = II()
    mod = 998244353
    
    n -= 2
    
    if n == 1: print(1)
    elif n % 3 == 0: print(pow(3, n // 3, mod))
    elif n % 3 == 2: print(2 * pow(3, n // 3, mod) % mod)
    else: print(4 * pow(3, n // 3 - 1, mod) % mod)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n, mod = 998244353;
	cin >> n;

	n -= 2;
	if (n == 1) cout << 1;
	else if (n % 3 == 0) cout << quickPow(3, n / 3, mod);
	else if (n % 3 == 1) cout << 4 * quickPow(3, n / 3 - 1, mod) % mod;
	else cout << 2 * quickPow(3, n / 3, mod) % mod;

	return 0;
}
```
