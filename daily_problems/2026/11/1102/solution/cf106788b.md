**提示 1：** 假设前缀 $i$ 的操作把 $[1,2,\dots, n]$ 打乱成 $p_i$ ，则 $l,r$ 满足条件需要什么？

**提示 2：** 如何快速判断？

先看提示 1 ，我们先做前缀变换。则 $[l,r]$ 的操作把 $p_{l-1}$ 变成了 $p_r$ 。在这种情况下，我们要求排列不变，也就是 $p_{l-1}$ 和 $p_r$ 相等。

如何快速判断呢？用哈希， $\sum x_i\times V^i$ 关于一个大质数取模即可，就是最经典的字符串哈希的方法。我们就只需查询有多少整数对相等，这就是很经典的题了。

交换两个元素对哈希数值的更新也是可以 $\mathcal{O}(1)$ 完成的，因此问题解决。

时间复杂度为 $\mathcal{O}(n+k)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n, k = MII()
    
    pw = random.randint(10 ** 6, 2 * 10 ** 6)
    
    def gen():
        while True:
            x = random.getrandbits(40)
            if math.gcd(x, pw) == 1:
                return x
    
    rnd1 = gen()
    rnd2 = gen()
    
    pw1 = [1] * (k + 1)
    pw2 = [1] * (k + 1)
    
    for i in range(k):
        pw1[i + 1] = pw1[i] * pw % rnd1
        pw2[i + 1] = pw2[i] * pw % rnd2
    
    p = list(range(k))
    
    v1 = 0
    v2 = 0
    
    for i in range(k):
        v1 += pw1[i] * p[i]
        v2 += pw2[i] * p[i]
        
        v1 %= rnd1
        v2 %= rnd2
    
    cnt = Counter()
    cnt[(v1, v2)] = 1
    
    ans = 0
    
    for _ in range(n):
        x, y = GMI()
        
        v1 += (p[y] - p[x]) * (pw1[x] - pw1[y])
        v1 %= rnd1
        
        v2 += (p[y] - p[x]) * (pw2[x] - pw2[y])
        v2 %= rnd2
        
        p[x], p[y] = p[y], p[x]
        
        ans += cnt[(v1, v2)]
        cnt[(v1, v2)] += 1
    
    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n, k;
	cin >> n >> k;

	mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
	uniform_int_distribution<int> pwDist(1'000'000, 2'000'000);
	long long pw = pwDist(rng);

	auto gen = [&]() -> long long {
		while (true) {
			long long x = static_cast<long long>(rng() & ((1ULL << 40) - 1));
			if (gcd(x, pw) == 1) return x;
		}
	};

	long long rnd1 = gen();
	long long rnd2 = gen();

	vector<long long> pw1(k + 1, 1), pw2(k + 1, 1);
	for (int i = 0; i < k; i ++) {
		pw1[i + 1] = pw1[i] * pw % rnd1;
		pw2[i + 1] = pw2[i] * pw % rnd2;
	}

	vector<int> p(k);
	iota(p.begin(), p.end(), 0);

	long long v1 = 0, v2 = 0;
	for (int i = 0; i < k; i ++) {
		v1 = (v1 + pw1[i] * p[i]) % rnd1;
		v2 = (v2 + pw2[i] * p[i]) % rnd2;
	}

	map<pair<long long, long long>, int> cnt;
	cnt[{v1, v2}] = 1;

	long long ans = 0;

	while (n --) {
		int x, y;
		cin >> x >> y;
		x --, y --;

		v1 = (v1 + (p[y] - p[x]) * (pw1[x] - pw1[y])) % rnd1;
		v2 = (v2 + (p[y] - p[x]) * (pw2[x] - pw2[y])) % rnd2;
		if (v1 < 0) v1 += rnd1;
		if (v2 < 0) v2 += rnd2;

		swap(p[x], p[y]);

		pair<long long, long long> key = {v1, v2};
		ans += cnt[key];
		cnt[key] ++;
	}

	cout << ans << '\n';
	
	return 0;
}
```
