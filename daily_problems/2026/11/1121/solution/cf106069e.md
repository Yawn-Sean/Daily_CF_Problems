**提示 1：** 答案不可能很大。

**提示 2：** 分类讨论。

答案是不会超过 $2$ 的。只需考虑如下策略：

- 依次遍历，每次添加给最小的元素。

这样可以用数学归纳法证明极差不会超过 $2$ 。

所以我们只需判 $0$ 或 $1$ 能否取到即可。

- 如果答案是 $0$ ，那么只可能总量 $x+2y$ 能被 $n$ 整除。此时先计算平均分配的结果 $w$ 。如果 $w$ 是偶数，则把 $1$ 两两打包进行分配即可；否则我们需要先分出 $n$ 个 $1$ 再两两打包。于是只需判 $1$ 的数量够不够用。

    - 这种情况下，一旦没办法达到 $0$ ，就一定有人高于平均，也一定有人低于平均，因此极差大于等于 $2$ ，最小值是 $2$ 。

- 如果答案是 $1$ ，因为一部分大于均值一部分小于均值，因此只能是一部分等于 $\lfloor (x+2y)/n\rfloor$ ，一部分多一个。也采用刚刚相似的策略，先分出 $1$ ，再两两打包，只需统计 $1$ 够不够用即可。

    - 如果不够，则此时最小值显然是 $2$ 。

时间复杂度为 $\mathcal{O}(1)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    t = II()
    outs = []
    
    for _ in range(t):
        x, y, n = MII()
        
        total = x + 2 * y
        
        if total % n == 0:
            w = total // n
            
            if w % 2 * n <= x:
                outs.append('0')
                continue
        
        else:
            w, v = divmod(total, n)
            
            if w % 2 * (n - v) + (w + 1) % 2 * v <= x:
                outs.append('1')
                continue
        
        outs.append('2')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int t;
	cin >> t;

	int n = t / 2, cur = 0;
	vector<int> timestamps(n + 1), stk;

	for (int i = 1; i <= t; i ++) {
		char op; int x;
		cin >> op >> x;

		vector<pair<int, int>> ops;

		if (op == '+') timestamps[++cur] = x;
		else ops.emplace_back(2, stk.back()), stk.pop_back();

		int w = 2 * (i & -i) - 1;

		vector<int> tmp;
		if (op == '+') tmp.emplace_back(cur);

		while (w && !stk.empty()) {
			w --;
			int u = stk.back();
			ops.emplace_back(2, u);
			tmp.emplace_back(u);
			stk.pop_back();
		}

		sort(tmp.begin(), tmp.end(), [&] (int i, int j) {return timestamps[i] > timestamps[j];});

		for (auto &x: tmp) {
			ops.emplace_back(1, x);
			stk.emplace_back(x);
		}

		cout << ops.size() << '\n';
		for (auto &[t, x]: ops) cout << t << ' ' << x << '\n';
		cout.flush();
	}

	return 0;
}
```
