**提示 1：** 先考虑最值。

**提示 2：** 转化为好求的问题。

如果 $n$ 是偶数，显然整个矩阵可以全是 $3$ ，输出 $1$ 即可。

否则，每行每列至少需要有 $1$ 个 $1$ ， $1$ 个 $2$ 。

此时怎么求方案数呢？

我们把行重排，使得第 $1$ 行第 $1$ 个是 $1$ 。则此时 $2$ 的位置构成了一个错排，用 $n!(1-\frac{1}{2!}+\frac{1}{3!}-\dots+(-1)^n\frac{1}{n!})$ 可以求，后面这个式子也可以预处理。

而行的排列有 $n!$ ，因此乘上它就是答案。

时间复杂度为 $\mathcal{O}(1)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    mod = 998244353
    M = 10 ** 6
    f = Factorial(M, mod)
    
    ans = [0] * (M + 1)
    ans[0] = 1
    
    for i in range(1, M + 1):
        if i % 2: ans[i] = ans[i - 1] - f.fac_inv(i)
        else: ans[i] = ans[i - 1] + f.fac_inv(i)
        ans[i] %= mod
    
    for i in range(M + 1):
        ans[i] = ans[i] * f.fac(i) % mod * f.fac(i) % mod
    
    t = II()
    outs = []
    
    for _ in range(t):
        n = II()
        outs.append(f'{ans[n]}' if n % 2 else '1')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
using mint = atcoder::modint998244353;

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);
 
	int M = 1e6;
	vector<mint> f(M + 1), g(M + 1);
 
	f[0] = 1;
	for (int i = 1; i <= M; i ++) f[i] = i * f[i - 1];
	
	g[M] = 1 / f[M];
	for (int i = M; i >= 1; i --) g[i - 1] = i * g[i];
 
	vector<mint> ans(M + 1);
	ans[0] = 1;
	
	for (int i = 1; i <= M; i ++) {
		if (i & 1) ans[i] = ans[i - 1] - g[i];
		else ans[i] = ans[i - 1] + g[i];
	}
 
	for (int i = 0; i <= M; i ++) ans[i] *= f[i] * f[i];
 
	int t;
	cin >> t;
 
	while (t --) {
		int n;
		cin >> n;
		cout << ((n & 1) ? ans[n].val() : 1) << '\n';
	}
 
	return 0;
}
```
