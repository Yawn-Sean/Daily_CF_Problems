**提示 1：** 相当于求角度区间的交。

**提示 2：** 计算区间？求交？

如果本身飓风点就在圆内或边界上，答案是 $1$ ，直接输出（我觉得这个点很无聊）。

假设在圆外，则求出两条切线的角度，则我们要计算的就是这个角度之间的区间和题中给出的区间的角度的交集，求交集占的比例。

前面角度区间怎么算呢？先算出中间位置的角度，可以用 atan2 函数；再求两侧的分离角度，那个角度的正弦值为 $\frac{1}{dis(H,C)}$ 用反三角函数也能算。所以问题解决。

求角度交集，可以让其中一个角度区间旋转若干圈，就可以直接用每一组的交集的长度之和，来作为答案了。

时间复杂度为 $\mathcal{O}(1)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    hx, hy = MII()
    cx, cy = MII()
    d, u = MII()
    
    if abs(hx - cx) + abs(hy - cy) <= 1:
        print(1)
    else:
        mid = math.atan2(hy - cy, hx - cx)
        delta = math.asin(1 / math.hypot(hy - cy, hx - cx))
    
        l1, r1 = mid - delta, mid + delta
        l2, r2 = (d - u) / 180 * math.pi, (d + u) / 180 * math.pi
    
        overlap = 0
    
        for i in range(-1, 2):
            overlap += fmax(0, fmin(r1, r2 + i * math.pi * 2) - fmax(l1, l2 + i * math.pi * 2))
    
        print(overlap / (2 * u / 180 * math.pi))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int hx, hy, cx, cy, d, u;
	cin >> hx >> hy >> cx >> cy >> d >> u;

	long double pi = acosl(-1);

	if (abs(hx - cx) + abs(hy - cy) <= 1) cout << 1;
	else {
		long double mid = atan2l(hy - cy, hx - cx);
		long double delta = asinl(1 / hypotl(hy - cy, hx - cx));

		long double l1 = mid - delta, r1 = mid + delta;
		long double l2 = pi * (d - u) / 180, r2 = pi * (d + u) / 180;

		long double overlap = 0;

		for (int i = -1; i <= 1; i ++) {
			overlap += max((long double)0, min(r1, r2 + i * pi * 2) - max(l1, l2 + i * pi * 2));
		}

		cout << fixed << setprecision(20) << overlap / (pi * 2 * u / 180);
	}

	return 0;
}
```
