**提示 2：** 这个性质成立时，一定有图吗？

把每个圆看成一个点，将其指向另一个点，当且仅当在另一个点对应的圆周上。

则每个点至少一个出度。在这个条件下，整个图必然有环。

而一个环意味着对应的边形成了多边形，所以至少有一个子集的半径可以拼成多边形。

这件事儿成立时，可以先拼出这个多边形，再把剩余的所有圆心放在某个圆的圆周上就行，因此给出构造发现是充要的。（可以是退化的多边形）

怎么判断呢？只需看非最长边的边长之和是否不小于最长边即可。为此，直接将数组排序，枚举最长边，剩余边的最大和就是比它短 / 一样长的边的长度之和，于是将两者比较即可。

时间复杂度为 $\mathcal{O}(n+\log M\log\log M)$ ，如果你利用值域下，要不构成多边形，只能最多选 $\log M$ 量级的元素。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n = II()
    nums = LII()
    
    nums.sort()
    
    cur = 0
    flg = False
    
    for x in nums:
        if cur >= x: flg = True
        cur += x
    
    print('possible' if flg else 'impossible')
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	vector<int> nums(n);
	for (auto &x: nums) cin >> x;

	sort(nums.begin(), nums.end());

	long long cur = 0;
	bool flg = false;

	for (auto &x: nums) {
		if (cur >= x) flg = true;
		cur += x;
	}

	cout << (flg ? "possible" : "impossible");

	return 0;
}
```
