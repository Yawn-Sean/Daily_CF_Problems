**提示 1：** 每条边要么走要么不走。于是只需判这件事。

**提示 2：** 其实只有一种可能。

注意，树上的边只允许最多走一次。

所以我们只需判断每条边是否要走。

对于 $m$ 个桥，每个端点都进行标记。对于树上的一条边，如果两侧标记的点的数量都是计奇数，则这条边不得不用；否则，这条边只能用。

综上，每条边是否计入答案都是确定的，直接求其一侧的标记数量即可。

时间复杂度为 $\mathcal{O}(n+m)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    path = [[] for _ in range(n)]
    
    for _ in range(n - 1):
        u, v, w = MII()
        u -= 1
        v -= 1
        path[u].append(w * n + v)
        path[v].append(w * n + u)
    
    parent = [-1] * n
    que = [0]
    
    for u in que:
        for msk in path[u]:
            w, v = divmod(msk, n)
            
            if u == 0 or parent[u] % n != v:
                parent[v] = w * n + u
                que.append(v)
    
    sz = [0] * n
    
    m = II()
    
    for _ in range(m):
        u, v = GMI()
        sz[u] ^= 1
        sz[v] ^= 1
    
    ans = 0
    
    for u in reversed(que):
        if u:
            w, p = divmod(parent[u], n)
            sz[p] ^= sz[u]
            ans += sz[u] * w
    
    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	vector<vector<pair<int, int>>> path(n);

	for (int i = 0; i < n - 1; i ++) {
		int u, v, w;
		cin >> u >> v >> w;
		u --, v --;
		path[u].emplace_back(v, w);
		path[v].emplace_back(u, w);
	}

	vector<int> tag(n, 0);

	int m;
	cin >> m;

	while (m --) {
		int u, v;
		cin >> u >> v;
		u --, v --;
		tag[u] ^= 1;
		tag[v] ^= 1;
	}

	long long ans = 0;

	auto dfs = [&] (auto &self, int u, int p) -> int {
		int ret = tag[u];

		for (auto &[v, w]: path[u]) {
			if (v != p && self(self, v, u)) {
				ans += w;
				ret ^= 1;
			}
		}

		return ret;
	};

	dfs(dfs, 0, -1);

	cout << ans;

	return 0;
}
```
