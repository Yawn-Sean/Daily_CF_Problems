**提示 1：** 很明显是一个二分问题。接下来要判断一个答案可不可行。

**提示 2：** 存着汤，用不了了把它变成饺子。

因为越大的 $E$ 会留出越大的操作空间，所以这个问题可以二分。

接下来的问题就是一个 $E$ 如何判定是否可行了。

因为能量换汤是最便宜的，所以先换汤——在汤用不掉的时候，我们再将其转化为饺子留后面再用。

基于这个想法，假设遍历到某个位置时，有 $S$ 份汤， $D$ 份饺子，现在来了 $A$ 个客人。

如果 $A\geq S$ ，那就消耗完所有的汤。今天的能量也尽可能先换成汤，接下来客人应该尽可能消耗汤，再消耗保质期更长的饺子。

否则，意味着我们的汤存多了——我们该把之前的汤转化为饺子了。首先我们先拿存的汤给客人吃。接下来再把存的汤两份并作一份饺子。

但这样可能会剩一份汤 $x$ 导致浪费，咋办呢？

如果你用了一份剩的汤，你可以选择把那份汤和 $x$ 合并成一份饺子，再用今天的能量换一份汤替代原有那份汤——这样的效果是把一份汤换成了一份未来能用的饺子，血赚。

所以在上述贪心过程中模拟即可。如果某次即使用了饺子都不够，那就不合法。

上界给 $10^9$ 就够了，毕竟这么多就算全做汤也够了。

时间复杂度为 $\mathcal{O}(n\log M)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    
    l, r = 0, 10 ** 9
    
    while l <= r:
        mid = (l + r) // 2
        
        flg = True
        
        soup = 0
        dumpling = 0
    
        for x in nums:
            if x < soup:
                w = fmin(soup // 2, (soup - x + 1) // 2)
                dumpling += w
                soup = fmin(mid, soup - x + mid - 2 * w)
            
            else:
                x -= soup
                
                if mid >= x:
                    soup = mid - x
                else:
                    soup = 0
                    if x - mid > dumpling:
                        flg = False
                        break
                    dumpling -= x - mid
        
        if flg: r = mid - 1
        else: l = mid + 1
    
    print(l)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;
	
	vector<int> nums(n);
	for (auto &x: nums) cin >> x;

	int l = 0, r = 1e9;

	while (l <= r) {
		int mid = (l + r) / 2;

		int soup = 0;
		long long dumpling = 0;
		bool flg = true;

		for (auto x: nums) {
			if (x < soup) {
				int w = min(soup / 2, (soup - x + 1) / 2);
				dumpling += w;
				soup = min(mid, soup - x + mid - 2 * w);
			}
			else {
				x -= soup;
				if (mid >= x) soup = mid - x;
				else {
					soup = 0;
					if (x - mid > dumpling) {
						flg = false;
						break;
					}
					dumpling -= x - mid;
				}
			}
		}

		if (flg) r = mid - 1;
		else l = mid + 1;
	}

	cout << l;

	return 0;
}
```
