**提示 1：** 最大操作次数？

**提示 2：** 分类讨论。

首先 $[1,2n],[n+1,3n],[1,2n]$ 可以完成任务，因为第一步可以保证 $2n+1\sim 3n$ 全部到最后 $2n$ 个数中，于是第二步操作可以让 $2n+1\sim 3n$ 归位，最后一次操作也就足够使得整体排序了。

于是我们只需看什么时候能 $0/1/2$ 次操作完成任务，剩余的输出上面的方案即可。

$0$ 次只需判是否升序。

$1$ 次只需判和最终位置不同的元素跨度是否达到了 $2n$ ，也就是不得不经过排序的元素的下标差是否不小于 $2n$ ，如果是，操作这个区间即可。

$2$ 次呢？先选出必须参与操作的段落的左右端点（前面 $1$ 次的时候求过了）。

假设此时区间长度为 $k$ ，则第二次操作要么没办法改变前 $k-2n$ 项，要么没法改变后 $k-2n$ 项。因此第一次操作要让这样的前缀 / 后缀无需进一步排序。

于是，只需看前 $k-2n$ 项元素能否一次操作变成后 $k-2n$ 项，或者后 $k-2n$ 项元素能否一次操作变成前 $k-2n$ 项，否则第二次操作做不到。（这里 $k-2n$ 是基于中间那个左右端点都不得不操作的子数组而言的）

所以判下这个，第二步操作剩余的区间即可。

不过这种情况更容易的做法是，枚举先操作 $[l, l+2n-1]$ 还是先操作 $[r-2n+1,r]$ ，然后再操作另一个，看最后数组是否排序，这样就不用动脑了。

时间复杂度为 $\mathcal{O}(n)$ 。

这题样例是比较弱的，可以试试这个 case，应该两次操作就够了。

```
5     
1 3 2 11 12 6 7 8 9 10 4 5 14 13 15
```

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()

    if all(nums[i] > nums[i - 1] for i in range(1, 3 * n)):
        print(0)
        exit()

    l = 3 * n
    r = 0

    for i in range(3 * n):
        if nums[i] != i + 1:
            l = fmin(l, i)
            r = fmax(r, i)

    if r - l < 2 * n:
        print(1)
        print(l + 1, r + 1)
        exit()

    ma_left = 0

    for i in range(l, 3 * n):
        if nums[i] <= r - 2 * n + 1:
            ma_left = fmax(ma_left, i)

    if ma_left - l < 2 * n:
        print(2)
        print(l + 1, ma_left + 1)
        print(r - 2 * n + 2, r + 1)
        exit()

    mi_right = 3 * n

    for i in range(r + 1):
        if nums[i] >= l + 2 * n + 1:
            mi_right = fmin(mi_right, i)

    if r - mi_right < 2 * n:
        print(2)
        print(mi_right + 1, r + 1)
        print(l + 1, l + 2 * n)
        exit()

    print(3)
    print(1, 2 * n)
    print(n + 1, 3 * n)
    print(1, 2 * n)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	vector<int> nums(3 * n);
	for (auto &x: nums) cin >> x;

	int l = 3 * n, r = 0;

	for (int i = 0; i < 3 * n; i ++) {
		if (nums[i] != i + 1) {
			l = min(l, i);
			r = max(r, i);
		}
	}

	if (l > r) return cout << 0, 0;

	if (r - l < 2 * n) {
		cout << 1 << '\n';
		cout << l + 1 << ' ' << r + 1 << '\n';
		return 0;
	}

	int ma_left = 0;

	for (int i = l; i < 3 * n; i ++) {
		if (nums[i] <= r - 2 * n + 1) {
			ma_left = max(ma_left, i);
		}
	}

	if (ma_left - l < 2 * n) {
		cout << 2 << '\n';
		cout << l + 1 << ' ' << ma_left + 1 << '\n';
		cout << r - 2 * n + 2 << ' ' << r + 1 << '\n';
		return 0;
	}

	int mi_right = 3 * n;

	for (int i = 0; i <= r; i ++) {
		if (nums[i] >= l + 2 * n + 1) {
			mi_right = min(mi_right, i);
		}
	}

	if (r - mi_right < 2 * n) {
		cout << 2 << '\n';
		cout << mi_right + 1 << ' ' << r + 1 << '\n';
		cout << l + 1 << ' ' << l + 2 * n << '\n';
		return 0;
	}

	cout << 3 << '\n';
	cout << 1 << ' ' << 2 * n << '\n';
	cout << n + 1 << ' ' << 3 * n << '\n';
	cout << 1 << ' ' << 2 * n << '\n';

	return 0;
}
```
