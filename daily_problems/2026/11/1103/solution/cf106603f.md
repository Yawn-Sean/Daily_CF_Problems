**提示 2：** 有用的物品数期望是多少？

如果有物品占据空间更大，但价值更低，则这个物品是废了。

所以我们将所有物品关于空间大小排序（这里空间不超过 $n$ 可以基数排序），则它们的价值仍然是随机均匀抽样得到的。

此时我们就只需看价值序列前缀的最大值更新的位置，这个数量是 $\mathcal{O}(\log n)$ 的。

怎么理解呢？每次更新最大值时，剩余的大于这个数的区间的长度期望减半，所以整体大概对数轮次结束。（这个推导不严谨，但是量级正确）

所以用这些物品做背包 DP 即可。

时间复杂度为 $\mathcal{O}(n\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n = II()
    vals = [0] * (n + 1)
    
    for _ in range(n):
        s, v = MII()
        vals[s] = fmax(vals[s], v)
    
    dp = [0] * (n + 1)
    cur = 0
    
    for i in range(1, n + 1):
        if vals[i] > cur:
            cur = vals[i]
            for j in range(i, n + 1):
                dp[j] = fmax(dp[j], dp[j - i] + vals[i])
    
    print(' '.join(map(str, dp[1:])))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	vector<int> vals(n + 1);

	for (int i = 0; i < n; i ++) {
		int s, v;
		cin >> s >> v;
		vals[s] = max(vals[s], v);
	}

	int cur = 0;
	vector<long long> dp(n + 1, 0);

	for (int i = 1; i <= n; i ++) {
		if (vals[i] > cur) {
			cur = vals[i];
			for (int j = i; j <= n; j ++) {
				dp[j] = max(dp[j], dp[j - i] + vals[i]);
			}
		}
		cout << dp[i] << " \n"[i == n];
	}

	return 0;
}
```
