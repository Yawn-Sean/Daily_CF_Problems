**提示 1：** 每个时刻，对应的状态是什么？怎么转移？

假设某个时刻，你放了 $S$ 这个集合的物品，此时什么状态是重要的呢？

$S$ 这个集合本身。除此之外，唯一重要的是两堆东西的重量之差 $x$ 。而最优化的目标是过程中出现的最大差值，设为 $dp[S][x]$ 。

而来了一个新物品的情况下， $S$ 新增一个元素，差值要么变大要么变小，也就是 $x+w$ 或者 $|x-w|$ ，转移的过程中记得用 $dp[S][x]$ 和这个数值的最大值来进行更新

注意 $x\leq\max w_i$ ，因为你总有办法使得两堆东西的质量之差不超过 $\max w_i$ ，只需顺序遍历不断把东西放到质量少的那堆就好。

所以总状态数量是 $\mathcal{O}(2^n\times M)$ ，转移需要枚举新物品，因此时间复杂度为 $\mathcal{O}(n2^nM)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n = II()
    nums = LII()
    
    inf = 100000
    dp = [[inf] * (1 << n) for _ in range(1001)]
    dp[0][0] = 0
    
    for msk in range(1 << n):
        to_add = [j for j in range(n) if msk >> j & 1 == 0]
        
        for j in to_add:
            nmsk = msk | (1 << j)
            
            for k in range(1001):
                if dp[k][msk] < inf:
                    nk = k + nums[j]
                    nv = fmax(nk, dp[k][msk])
                    
                    if nk <= 1000:
                        dp[nk][nmsk] = fmin(dp[nk][nmsk], nv)
                    
                    nk = abs(k - nums[j])
                    nv = fmax(nk, dp[k][msk])
                    
                    dp[nk][nmsk] = fmin(dp[nk][nmsk], nv)
    
    print(min(x[-1] for x in dp))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	vector<int> nums(n);
	for (auto &x: nums) cin >> x;

	int inf = 1e5;
	vector<vector<int>> dp(1001, vector<int>(1 << n, inf));

	dp[0][0] = 0;

	for (int msk = 0; msk < (1 << n); msk ++) {
		for (int j = 0; j < n; j ++) {
			if (msk >> j & 1) continue;
			int nmsk = msk | (1 << j);
			for (int k = 0; k <= 1000; k ++) {
				if (dp[k][msk] < inf) {
					int nk, nv;
					nk = k + nums[j];
					nv = max(nk, dp[k][msk]);
					if (nk <= 1000) dp[nk][nmsk] = min(dp[nk][nmsk], nv);

					nk = abs(k - nums[j]);
					nv = max(nk, dp[k][msk]);
					if (nk <= 1000) dp[nk][nmsk] = min(dp[nk][nmsk], nv);
				}
			}
		}
	}

	int ans = inf;
	for (auto &x: dp) ans = min(ans, x.back());

	cout << ans;

	return 0;
}
```
