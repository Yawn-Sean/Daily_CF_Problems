**提示 1：** 考虑组合起来凑。

我们每个物品都可以关于 $5$ 取模，不影响答案。

假设我们最后按照批次排列各个物品，则最优的购买策略是什么呢？

直接从某个位置不断贪心往后找，一旦发生可以省钱的地方就划一段。

同时，每个本来就可以省钱的物品单独买一定会不劣。

而因此，剩余的省钱组合只可能是某一组 $3$ 分 $4$ 分凑成的前缀，只可能是：

- $2$ 个 $3$ 分。省 $1$ 分。

- $1$ 个 $3$ 分、一个 $4$ 分。省 $2$ 分。

- $3$ 个 $4$ 分。省 $2$ 分。

在这种情况下，枚举第三组的数量。接下来一定是 $3,4$ 匹配越多越好，最后多出来的 $3$ 分尽可能多凑第一组，这样一定使得结果最优。

枚举的情况数恰好是线性的，所以复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    
    cnt = [0] * 5
    
    for x in nums:
        cnt[x % 5] += 1
    
    orig = cnt[1] + 2 * cnt[2]
    c4 = cnt[4]
    
    res = -n * 5
    
    for i in range(cnt[4] // 3 + 1):
        w3 = cnt[3]
        w4 = cnt[4] - i * 3
        cur = i * 2
        
        w = fmin(w3, w4)
        w3 -= w
        w4 -= w
        cur += w * 2
        
        w = w3 // 2
        cur += w
        w3 -= w * 2
        
        cur -= w3 * 2 + w4
        
        res = fmax(res, cur)
    
    print(res + orig)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	vector<int> cnt(5, 0);
	for (int i = 0; i < n; i ++) {
		int x; cin >> x;
		cnt[x % 5] ++;
	}

	int orig = cnt[1] + 2 * cnt[2], res = -5 * n;

	for (int i = 0; i <= cnt[4] / 3; i ++) {
		int w3 = cnt[3], w4 = cnt[4] - 3 * i, cur = 2 * i;

		int w;
		w = min(w3, w4);
		w3 -= w, w4 -= w, cur += 2 * w;

		w = w3 / 2;
		w3 -= 2 * w, cur += w;

		cur -= 2 * w3 + w4;
		res = max(res, cur);
	}

	cout << orig + res;

	return 0;
}
```
