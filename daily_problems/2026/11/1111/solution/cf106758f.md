**提示 1：** 整体是异或关系，先求线性基。

**提示 2：** 线性基被删去 $1$ / $2$ 个元素的情况下，要满足什么条件？

首先，我们可达的状态取决于线性基是否改变，因此我们需要先求线性基。同时我们预处理每个别的元素可以由线性基中的哪些元素异或得到。

考虑删除两元素后线性基是否改变。

- 如果删除元素不涉及线性基，则显然不影响。

- 如果删掉了一个线性基元素——就意味着至少你需要有 $2$ 个非线性基元素在线性基表示中有这个线性基元素，否则删掉其中的一个就可能导致这一位无法表示。

- 如果删掉了两个线性基元素——则至少需要 $2$ 个非线性基的元素，在这两个线性基元素上的表示不相同。

（这里表示指的是用线性基元素去异或得到非线性基元素）

假设线性基中有 $M$ 个元素。为了满足最后的那个条件，我们考虑线性基中每个元素在非线性基元素中的贡献，如果贡献完全一致就进入了第三个情况，因此需要处理，将它们放到一起。

（这里我们可以枚举元素，然后用每个非线性基元素筛选，用位运算取出子集，最终得到跟这一个线性基元素贡献相同的线性基元素个数）

假设某一组有 $g$ 个元素。

考虑新增 $k$ 个非线性基元素。则 $k$ 在这 $g$ 位要满足什么条件呢？

首先得两两不同。

同时，如果此前这一位在非线性基元素的表示中只出现了 $0$ 次，则我们要求 $k$ 在这 $g$ 位中至少出现两次，因此最多有 $2^k-k-1$ 个数可以分配给这 $g$ 位。因为要两两不同，所以 $2^k-k-1\geq g$ 。

如果此前这一位在非线性基元素的表示中只出现了 $1$ 次，则我们要求 $k$ 在这 $g$ 位中至少出现 $1$ 次，因此最多有 $2^k-1$ 个数可以分配给这 $g$ 位。因为要两两不同，所以 $2^k-1\geq g$ 。

如果此前这一位在非线性基元素的表示中只出现了至少 $2$ 次，则这一位没有额外的条件了，因此最多有 $2^k$ 个数可以分配给这 $g$ 位。因为要两两不同，所以 $2^k\geq g$ 。

此时，我们保证了任意两个线性基元素的表示情况不一致，且每一个线性基元素都在非线性基元素的表示中出现了 $2$ 次，因此是足够的。

综上，将所有上述不等式汇总即可得到最小的 $k$ 。

由于 $2^7-7-1\geq 60$ ，所以最大枚举到 $7$ 即可。

时间复杂度为 $\mathcal{O}(nb)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, b = MII()
    nums = LII()
    
    k = 0
    base = [0] * b
    base_msk = [0] * b
    
    msks = []
    
    for x in nums:
        if x:
            flg = True
            msk = 0
            
            for i in range(b - 1, -1, -1):
                if x >> i & 1:
                    if base[i] == 0:
                        base[i] = x
                        base_msk[i] = (1 << k) ^ msk
                        flg = False
                        k += 1
                        break
                    else:
                        x ^= base[i]
                        msk ^= base_msk[i]
            
            if flg:
                msks.append(msk)
    
    c0 = -1
    c1 = -1
    c2 = -1
    
    for i in range(k):
        total_msk = (1 << i) - 1
        total_nmsk = (1 << i) - 1
        c = 0
        
        for v in msks:
            if v >> i & 1:
                c += 1
                total_msk &= v
            else:
                total_nmsk &= ~v
        
        same = (total_msk & total_nmsk).bit_count() + 1
        
        if c == 0: c0 = fmax(c0, same)
        elif c == 1: c1 = fmax(c1, same)
        else: c2 = fmax(c2, same)
    
    for extra in range(8):
        if (1 << extra) - extra - 1 >= c0 and (1 << extra) - 1 >= c1 and 1 << extra >= c2:
            print(extra)
            break
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n, b;
	cin >> n >> b;

	vector<long long> nums(n);
	for (auto &x: nums) cin >> x;

	int k = 0;
	vector<long long> base(b, 0);
	vector<long long> base_msk(b, 0), msks;

	for (auto &x: nums) {
		bool flg = true;
		long long msk = 0;

		for (int i = b - 1; i >= 0; i --) {
			if (x >> i & 1) {
				if (!base[i]) {
					base[i] = x;
					base_msk[i] = (1ll << k) ^ msk;
					flg = false;
					k ++;
					break;
				}
				else {
					x ^= base[i];
					msk ^= base_msk[i];
				}
			}
		}

		if (flg) msks.emplace_back(msk);
	}

	int c0 = -1, c1 = -1, c2 = -1;

	for (int i = 0; i < k; i ++) {
		long long total_msk = (1ll << i) - 1;
		long long total_nmsk = (1ll << i) - 1;

		int c = 0;

		for (auto &v: msks) {
			if (v >> i & 1) c ++, total_msk &= v;
			else total_nmsk &= ~v;
		}

		int same = __builtin_popcountll(total_msk & total_nmsk) + 1;
		if (c == 0) c0 = max(c0, same);
		else if (c == 1) c1 = max(c1, same);
		else c2 = max(c2, same);
	}

	for (int extra = 0; extra < 8; extra ++) {
		if ((1 << extra) - extra - 1 >= c0 && (1 << extra) - 1 >= c1 && (1 << extra) >= c2) {
			cout << extra;
			break;
		}
	}

	return 0;
}
```
