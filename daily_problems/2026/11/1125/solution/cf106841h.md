**提示 1：** 整体是个计数器的模式。

**提示 2：** 每个位置返回多少次？

考虑从当前的 $01$ 状态出发，到达最终能直接通行的全 $0$ 状态，发生了什么？

发现整体逻辑就是：把第一个 $1$ 改成 $0$ ，前面的 $0$ 改成 $1$ 。这恰好是二进制减法减去 $1$ 的效果。

所以把整个 $01$ 序列从后往前看，形成的二进制数，则每一轮相当于对这个二进制数执行减 $1$ 操作。

而每个位置折返，就是这一位进行 $1\to 0$ 操作的次数。

某个数 $x$ 的第 $2^i$ 那一位位会经历的变动数量等于 $\lfloor x/2^{i+1}\rfloor +(x 的 2^i 为 1)$ ，所以维护这个变量即可。可以从高位往低位遍历，这样每次的结果就是翻倍加上后面的这一位的调整。（具体可见代码）

每一位的次数乘以距离，再加上最后走到 $x_n+1$ 的距离就是答案了。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n = II()
    
    xs = []
    ss = []
    
    mod = 998244353
    
    for _ in range(n):
        x, s = MII()
        xs.append(x)
        ss.append(s)
    
    ans = 0
    cur = 0
    
    for i in range(n - 1, -1, -1):
        ans += (cur + ss[i]) * xs[i]
        ans %= mod
        cur = 2 * cur + ss[i]
        cur %= mod
    
    print((ans + xs[-1] + 1) % mod)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	vector<pair<int, int>> nodes(n);
	for (auto &[x, s]: nodes) cin >> x >> s;

	int ans = 0, cur = 0, mod = 998244353;
	for (int i = n - 1; i >= 0; i --) {
		ans = (ans + 1ll * (cur + nodes[i].second) * nodes[i].first) % mod;
		cur = (cur * 2 + nodes[i].second) % mod;
	}

	cout << (ans + nodes.back().first + 1) % mod;

	return 0;
}
```
