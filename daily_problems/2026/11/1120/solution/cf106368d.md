**提示 1：** 如果你只在意快速取出 / 快速放入，那其实很好办。所以我们要平衡。

**提示 2：** 理解为懒排序。

如果你只想快速取出数，你只需不断插入对应的位置；如果你只要快速放入，你只需取数的时候把要取的数的上方一起弹出来。

所以你需要平衡这两点：你的序列不能完全不有序，这样弹出来需要的时间就太久了；也不能完全有序，这样维护的成本就太高了。

所以我们需要让整个序列是“部分有序的”，至少每一段都比较有序。

因此考虑每次选取一部分栈顶元素进行排序。可以选择长度不一样的，两次大规模排序之间的间隔可以久一点，因为大范围的排序可以使得后面很长一段时间的序列有序。

基于这个直觉，我们设定第 $i$ 轮操作，我们设 $i$ 的二进制表示的最低位为 $2^k$ ，则我们将除了新加入 / 删除的元素的顶端的 $2^{k+1}-1$ 个元素进行排序。（这样可以在加入足够多元素的时候进行整体重排，同时维持之前的排序的部分结果）

下面我们认为一开始栈里加入了足够多不会被删掉的元素，方便说明。

首先，这样的总操作次数是足够小的。

同时，最小元素一定在栈顶的这些元素中。

我们说明，在某次对栈顶的 $2^{k+1}$ 个元素操作时，这些元素中包含了最小的 $2^k$ 个元素。（这里算上了即将被加入 / 删除的元素）

可以用数学归纳法。首先，第一次更新时，显然满足要求。

考虑第 $j$ 次更新，则设此时操作的是 $2^{k_0}$ 个元素，则往前推到第 $j-2^{k_0}$ 次更新，这次更新是操作的 $2^{k_0+1}$ 个元素，其中栈顶是当时元素中最小的 $2^{k_0}$ 个。

而这 $2^{k_0}$ 次操作后，这 $2^{k_0}$ 个元素仍然在栈顶的 $2^{k_0+1}$ 个元素之中，同时你新增的一些元素也在栈顶中，所以此时最小的 $2^{k_0+1}$ 个元素一定包含了此时最小的 $2^{k_0}$ 个元素，因此排序后仍然维持了性质。

综上，正确性得到验证。总操作次数是 $\mathcal{O}(n\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    t = II()
    
    stk = []
    
    n = t // 2
    cur = 0
    timestamps = [0] * (n + 1)
    
    for i in range(1, t + 1):
        op, x = LI()
        x = int(x)
        
        ops = []
        
        if op == '+':
            cur += 1
            timestamps[cur] = x
        else:
            ops.append(f'2 {stk.pop()}')
        
        w = 2 * (i & -i) - 1
        tmp = [cur] if op == '+' else []
        
        while w and stk:
            w -= 1
            ops.append(f'2 {stk[-1]}')
            tmp.append(stk.pop())
        
        tmp.sort(lambda x: -timestamps[x])
        
        for x in tmp:
            ops.append(f'1 {x}')
            stk.append(x)
        
        print(len(ops))
        print('\n'.join(ops), flush=True)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int t;
	cin >> t;

	int n = t / 2, cur = 0;
	vector<int> timestamps(n + 1), stk;

	for (int i = 1; i <= t; i ++) {
		char op; int x;
		cin >> op >> x;

		vector<pair<int, int>> ops;

		if (op == '+') timestamps[++cur] = x;
		else ops.emplace_back(2, stk.back()), stk.pop_back();

		int w = 2 * (i & -i) - 1;

		vector<int> tmp;
		if (op == '+') tmp.emplace_back(cur);

		while (w && !stk.empty()) {
			w --;
			int u = stk.back();
			ops.emplace_back(2, u);
			tmp.emplace_back(u);
			stk.pop_back();
		}

		sort(tmp.begin(), tmp.end(), [&] (int i, int j) {return timestamps[i] > timestamps[j];});

		for (auto &x: tmp) {
			ops.emplace_back(1, x);
			stk.emplace_back(x);
		}

		cout << ops.size() << '\n';
		for (auto &[t, x]: ops) cout << t << ' ' << x << '\n';
		cout.flush();
	}

	return 0;
}
```
