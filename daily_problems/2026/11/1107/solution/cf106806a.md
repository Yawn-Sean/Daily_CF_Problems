**提示 1：** 考虑递推关系。

一个深度为 $k$ 的子树答案是 $a_k=b_k+0.5$ 。

则深度为 $k+1$ 的子树，就要求 $3$ 个 $k$ 大小的子树，至少有两个是满足要求的，因此：

$a_{k+1}=a_k^3+3a_k^2(1-a_k)$

于是可以推出 $b_{k+1}=b_k(1.5-2b_k^2)$

这就意味着和 $0.5$ 的偏差是指数级增长的，即使 $b_0$ 很小，最后也可能膨胀得很大。

因此，你只能维护 $b_k=v_k\times 10^w_k$ 中的 $v_k,w_k$ ，这样才能保证精度不出问题。

这里乘法的精度损失较小，而减法在 $b_k$ 很小时求解的结果是 $1.5$ ，较大时 $b_k^2$ 也不超过 $0.5$ ，因此精度损失也很小，所以这样维护没问题。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    p = I()
    
    v1, v2 = p.split('e')
    v1 = float(v1)
    v2 = -int(v2)
    
    for _ in range(n):
        v1 *= 1.5 - 2 * (v1 * pow(0.1, v2)) ** 2
        while abs(v1) >= 10:
            v1 /= 10
            v2 -= 1
    
    print(f'{0.5 + v1 * pow(0.1, v2):.20f}')
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	string s;
	cin >> s;

	int idx;
	for (int i = 0; i < s.size(); i ++) {
		if (s[i] == 'e') {
			idx = i;
		}
	}

	long double v1 = stold(s.substr(0, idx));
	int v2 = stoll(s.substr(idx + 2));

	while (n --) {
		v1 *= 1.5 - 2 * powl(v1 * powl(0.1, v2), 2);
		while (abs(v1) >= 10) {
			v1 /= 10;
			v2 --;
		}
	}

	cout << fixed << setprecision(20) << 0.5 + v1 * powl(0.1, v2);

	return 0;
}
```
