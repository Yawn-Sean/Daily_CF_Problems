**提示 1：** 不得不放的地方再放。

我们应该把点放在尽可能浅的地方，这样可以让更多位置得到满足。

所以考虑贪心。从深往浅遍历，考虑每个点对应的最深的需要照亮的结点，如果深度已经是 $k-1$ 了，就不得不放了，放上去。不断往浅推。

最后注意根节点是需要的。

时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n, k = MII()
    parent = [-1] + LGMI()
    
    chosen = [0] * n
    dis = [0] * n
    
    for i in range(n - 1, 0, -1):
        if dis[i] == k - 1:
            chosen[i] = 1
        else:
            dis[parent[i]] = fmax(dis[parent[i]], dis[i] + 1)
    
    chosen[0] = 1
    
    print(sum(chosen))
    print(' '.join(f'{i + 1}' for i in range(n) if chosen[i]))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n, k;
	cin >> n >> k;

	vector<int> parent(n + 1);
	for (int i = 2; i <= n; i ++) cin >> parent[i];

	vector<int> dis(n + 1), chosen(n + 1);

	for (int i = n; i > 1; i --) {
		if (dis[i] == k - 1) chosen[i] = 1;
		else dis[parent[i]] = max(dis[parent[i]], dis[i] + 1);
	}

	chosen[1] = 1;

	int ans = 0;
	for (auto &x: chosen) ans += x;

	cout << ans << '\n';
	for (int i = 1; i <= n; i ++) if (chosen[i]) cout << i << ' ';

	return 0;
}
```
