**提示 1：** 想想策略。

首先先手是不会输的，因为把两个人分别操作一次视为一轮，则每轮先手都不低于后手的分数。

如果序列本身 MEX = 0 ，则显然双方分数都是 $0$ ，打平了。

否则，如果 $n$ 是奇数——

- 如果序列中只有一个 $0$ ，则先手拿走它就好。

- 否则，拿走一个别的数，后手无论如何操作，都会进入 $n$ 为奇数且 MEX 非 $0$ 的序列状态 —— 也就可以用数学归纳法证明此时先手必胜。

接下来认为 $n$ 是偶数。

如果此时小于 MEX 的数中有一个数只出现了一次，那么先手操作它可以在第一轮获得严格更多的分，之后每轮先手分数都不比后手低，因此总分一定严格更高。

其它情况下，我们可以把小于 MEX 的元素的偶数次出现两两配对，剩余元素两两配对，可以使得先手拿到任何数，后手操作对应元素也能得到一样的 MEX ，因此后手可以保证平手。

综上分类即可，时间复杂度为 $\mathcal{O}(n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n = II()
    nums = LII()
    
    cnt = [0] * (n + 1)
    
    for x in nums:
        if x < n:
            cnt[x] += 1
    
    mex = 0
    
    while cnt[mex]:
        mex += 1
    
    if mex and (n % 2 or min(cnt[:mex]) == 1): print('Dinny')
    else: print('Tie')
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	vector<int> nums(n), cnt(n + 1, 0);
	for (auto &x: nums) {
		cin >> x;
		if (x < n) cnt[x] ++;
	}

	int mex = 0;
	while (cnt[mex]) mex ++;

	if (mex && (*min_element(cnt.begin(), cnt.begin() + mex) == 1 || n % 2)) cout << "Dinny";
	else cout << "Tie";

	return 0;
}
```
