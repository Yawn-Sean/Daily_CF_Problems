**提示 1：** 分列计数。

对于交点在哪一列，只取决于两侧的段落的长度的比例。

所以令两侧长度互质（如果不互质，设有公因子 $g$ ，则取左边下侧的 $1/g$ 和右边上侧的 $1/g$ ，交点位置不变），不妨设左侧长度是 $x$ ，右侧长度是 $y$ 。

则令两段都取最上侧的交点位置是 $A$ ，则左边往下一格， $A$ 往下 $x/(x+y)$ 格，右边往下一格， $A$ 往下 $y/(x+y)$ 格。

也就是我们想知道 $(xv_1+yv_2)/(x+y)$ （ $0\leq v_1\lt n-x,0\leq v_2\lt m-y$ ）可以有多少种取值，也就是 $xv_1+yv_2$ 有多少个不同的取值

这件事儿就相对好做了。

设 $A=n-x,B=m-y$ ，则总共有 $AB$ 个组合。但同时也有一些等价类，比方说 $(v_1-y,v_2+x)$ 和 $(v_1,v_2)$ 结果一致。在这些点之间连边，可以形成一系列的链，则我们最后要求的就是不同链的数量。

为此可以用总点数减去添加的边数，添加的边数显然是 $\max(A-x,0)\max(B-y,0)$ ，于是问题解决。

时间复杂度为 $\mathcal{O}(nm\log(n,m))$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main():
    n, m = MII()
    
    ans = 0
    
    for i in range(1, n):
        for j in range(1, m):
            if math.gcd(i, j) == 1:
                l = fmin(n - i, i)
                r = fmin(m - j, j)
                ans += l * (m - j) + (n - i) * r - l * r
    
    print(ans)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n, m;
	cin >> n >> m;

	long long ans = 0;

	for (int i = 1; i < n; i ++) {
		for (int j = 1; j < m; j ++) {
			if (gcd(i, j) == 1) {
				int x = min(i, n - i), y = min(j, m - j);
				ans += x * (m - j) + (n - i) * y - x * y; 
			}
		}
	}

	cout << ans;

	return 0;
}
```
