**提示 1：** 钦定 $k$ 个人，概率如何求？

**提示 2：** 容斥。

先钦定 $k$ 个人，问最后是这 $k$ 个人被选中的概率。

则直接恰好 $k$ 个人太难了，我们求最后被选中的人在这 $k$ 个人之中的概率。

这也就要求了每个人要么选的就是 $k$ 个人之一，要么没生效。所以概率是 $1-p\times (n-k)/n$ 。（这里 $p$ 已经转成概率了）总共 $n$ 个人，合起来是 $(1-p\times (n-k)/n)^n$

但这样会多算更小的子集。对于大小为 $i$ 的子集，概率是 $(1-p\times (n-i)/n)^n$ 。

而这个子集会被算到 $\binom{n}{i}$ 次，所以答案就是求 $\sum\limits_{i=0}^k(-1)^{k-i}(1-p\times (n-i)/n)^n\times\binom{n}{i}$ 。本质是二项式反演。

最后结果乘以 $\binom{n}{k}$ 表示选定 $k$ 人子集即可。

时间复杂度为 $\mathcal{O}(k\log n)$ 。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    mod = 998244353
    f = Factorial(10 ** 5, mod)
    
    t = II()
    outs = []
    
    for _ in range(t):
        n, k, p = MII()
        p = p * f.inv(100) % mod
        
        ans = 0
        for i in range(k + 1):
            prob = (1 - p * (n - i) % mod * f.inv(n) % mod) % mod
            cur = f.combi(k, i) * pow(prob, n, mod) % mod
            ans += cur if (k - i) % 2 == 0 else -cur
            ans %= mod
        
        ans = ans * f.combi(n, k) % mod
        outs.append(f'{ans}')
    
    print('\n'.join(outs))
```

C++ 做法如下——

```cpp []
using mint = atcoder::modint998244353;

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int M = 1e5;
	vector<mint> f(M + 1), g(M + 1);

	f[0] = 1;
	for (int i = 1; i <= M; i ++) f[i] = i * f[i - 1];
	g[M] = 1 / f[M];
	for (int i = M; i >= 1; i --) g[i - 1] = i * g[i];

	int t;
	cin >> t;

	while (t --) {
		int n, k, P;
		cin >> n >> k >> P;

		mint p = P; p /= 100;
		mint ans = 0;

		for (int i = 0; i <= k; i ++) {
			mint prob = 1 - mint(n - i) / n * p;
			mint cur = f[k] * g[i] * g[k - i] * prob.pow(n);
			if ((k - i) % 2 == 0) ans += cur;
			else ans -= cur;
		}
		
		ans = ans * f[n] * g[k] * g[n - k];
		cout << ans.val() << '\n';
	}

	return 0;
}
```
