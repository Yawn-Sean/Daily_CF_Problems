**提示 1：** 实际上答案只有很少量的情况。

首先，如果字符串本身没有循环节，则直接返回 $1$ 即可。

接下来讨论有循环节的情况。

- 如果循环节长度为 $1$ ，则只能拆成 $|s|$ 个字符串。

- 否则，其实你第一个字符串取第一个字符，剩余的部分做第二个字符串就符合要求了——不然一定存在更短的循环节。此时答案为 $2$ 。

时间复杂度为 $\mathcal{O}(nd(n))$ ，其中 $d(n)$ 表示 $n$ 的因子个数。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    s = I()
    n = len(s)
    
    if min(s) == max(s):
        print(n)
        print(' '.join(s))
    else:
        for i in range(2, n):
            if n % i == 0:
                flg = True
                for j in range(n):
                    if s[j] != s[j % i]:
                        flg = False
                        break
                
                if flg:
                    print(2)
                    print(s[0], s[1:])
                    exit()
        
        print(1)
        print(s)
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	string s;
	cin >> s;

	int n = s.size();

	for (int i = 1; i < n; i ++) {
		if (n % i == 0) {
			bool flg = true;
			for (int j = 0; j < n; j ++) {
				if (s[j] != s[j % i]) {
					flg = false;
				}
			}

			if (flg) {
				if (i == 1) {
					cout << n << '\n';
					for (int i = 0; i < n; i ++) cout << s[i] << " \n"[i == n - 1];
				}
				else {
					cout << 2 << '\n';
					cout << s.substr(0, 1) << ' ' << s.substr(1) << '\n';
				}
				return 0;
			}
		}
	}

	cout << 1 << '\n' << s << '\n';

	return 0;
}
```
