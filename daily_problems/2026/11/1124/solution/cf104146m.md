**提示 2：** 复杂的情况转化。

本题有多个构造策略，下面解释一种。

首先，一个 $1\times x$ 的块显然满足条件，且占地面积很小，所以应该比较好用。从这里入手。

我们很容易发现 $n$ 是奇数的情况下，可以直接第一行放 $1,n-1$ ，第二行放 $2,n-1$ ，这样放 $(n-1)/2$ 行后，刚好放了 $n-1$ 个长方形，剩下的 $(n+1)/2$ 行满足 $\gcd((n+1)/2,n)=1$ ，可以用 $(n+1)/2\times 2-n=1$ 说明。

接下来考虑偶数。

手动可以检验 $2,4$ 是不可行的。

对于更大的 $n$ ，我们尝试把问题转化为前面的奇数的情况。

那就还是前面几排按照 $1,n-1$ ， $2,n-2$ 的排开来。

但如果最后一块只剩下了两个长方形，自由度就太低了，不一定能构造。所以我们留出四个矩形的空间。此时设 $n=2k$ ，则剩下了 $2k\times (k+2)$ 。

此时我们最好只有一个矩形，而外层只有一些宽度比较小的矩形，不然各个矩形边长如果数值都不小的话，就会更容易不互质。

而找和 $2k$ 互质的数就不好找了，所以考虑 $2k-1$ ， $k$ 和 $k-1$ 都跟它互质。枚举两种情况可以发现一个合法的构造：

第一排放一个 $1\times 2k$ 的。

剩余的第一列放一个 $(k+1)\times 1$ 的。

剩余的部分前两行和最后 $k-1$ 行分别成一个矩形。

但这种构造在 $n=6$ 不合法，需要手动构造。

### 具体代码如下——

Python 做法如下——

```Python []
def main(): 
    n = II()
    
    if n == 2 or n == 4:
        print('NO')
    
    else:
        print('YES')
    
        if n == 6:
            print('AABBBB')
            print('CDDEEE')
            print('CDDFFF')
            print('CDDFFF')
            print('CDDFFF')
            print('CDDFFF')
    
        elif n % 2:
            ans = [['E'] * n for _ in range(n)]
            
            for i in range(n // 2):
                for j in range(i + 1):
                    ans[i][j] = 'A' if i % 2 == 0 else 'C'
                for j in range(i + 1, n):
                    ans[i][j] = 'B' if i % 2 == 0 else 'D'
            
            print('\n'.join(''.join(x) for x in ans))
    
        else:
            ans = [['H'] * n for _ in range(n)]
            for i in range(n // 2 - 2):
                for j in range(i + 1):
                    ans[i][j] = 'A' if i % 2 == 0 else 'C'
                for j in range(i + 1, n):
                    ans[i][j] = 'B' if i % 2 == 0 else 'D'
            
            for j in range(n):
                ans[n // 2 - 2][j] = 'E'
            
            for i in range(n // 2 - 1, n):
                ans[i][0] = 'F'
            
            for i in range(n // 2 - 1, n // 2 + 1):
                for j in range(1, n):
                    ans[i][j] = 'G'
            
            print('\n'.join(''.join(x) for x in ans))
```

C++ 做法如下——

```cpp []
int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	if (n == 2 || n == 4) return cout << "NO", 0;

	cout << "YES\n";

	if (n == 6) {
		cout << "ABBBBB\n";
		cout << "ADDEEE\n";
		cout << "CDDFFF\n";
		cout << "CDDFFF\n";
		cout << "CDDFFF\n";
		cout << "CDDFFF\n";
	}
	else if (n & 1) {
		vector<string> grid(n, string(n, 'E'));

		for (int i = 0; i < n / 2; i ++) {
			for (int j = 0; j <= i; j ++) grid[i][j] = (i & 1) ? 'A' : 'C';
			for (int j = i + 1; j < n; j ++) grid[i][j] = (i & 1) ? 'B' : 'D';
		}

		for (auto &s: grid) cout << s << '\n';
	}
	else {
		vector<string> grid(n, string(n, 'H'));

		for (int i = 0; i < n / 2 - 2; i ++) {
			for (int j = 0; j <= i; j ++) grid[i][j] = (i & 1) ? 'A' : 'C';
			for (int j = i + 1; j < n; j ++) grid[i][j] = (i & 1) ? 'B' : 'D';
		}

		for (int i = 0; i < n; i ++) grid[n / 2 - 2][i] = 'E';
		for (int i = n / 2 - 1; i < n; i ++) grid[i][0] = 'F';

		for (int i = n / 2 - 1; i <= n / 2; i ++) {
			for (int j = 1; j < n; j ++) {
				grid[i][j] = 'G';
			}
		}

		for (auto &s: grid) cout << s << '\n';
	}

	return 0;
}
```
